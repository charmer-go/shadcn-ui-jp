<Callout className="mb-6 border-emerald-600 bg-emerald-100 dark:border-emerald-400 dark:bg-emerald-900">

**新しいプロジェクトを始めますか？** カスタム テーマ、Base UI または Radix、アイコン ライブラリを備えた完全構成済みの TanStack Start アプリには、[shadcn/create](/create?template=start&base=base&rtl=true) を使います。

</Callout>

<Steps>

### プロジェクトの作成

`--rtl` フラグと `start` テンプレートを使用して、新しいプロジェクトを作成します。

**[shadcn/create](/create?template=start&base=base&rtl=true) を使ってプロジェクトを作成済みの場合、この手順は省略できます。**

```bash
npx shadcn@latest create --template start --rtl
```

これにより、`rtl: true` フラグを持つ `components.json` ファイルが作成されます。

```json title="components.json" showLineNumbers {4}
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "base-nova",
  "rtl": true
}
```

### DirectionProvider を追加

`dir="rtl"` 属性と `lang="ar"` 属性を `html` タグに追加します。 `lang="ar"` をターゲット言語に更新します。

次に、`__root.tsx` で `direction="rtl"` prop を持つ `DirectionProvider` コンポーネントでアプリをラップします。

```tsx title="src/routes/__root.tsx" showLineNumbers {1,9,14-16}
import { DirectionProvider } from "@/components/ui/direction"

export const Route = createRootRoute({
  component: RootComponent,
})

function RootComponent() {
  return (
    <html lang="ar" dir="rtl">
      <head>
        <Meta />
      </head>
      <body>
        <DirectionProvider direction="rtl">{children}</DirectionProvider>
        <Scripts />
      </body>
    </html>
  )
}
```

### フォントの追加

最適な RTL 体験のため、対象言語を適切にサポートするフォントの使用を推奨します。[Noto](https://fonts.google.com/noto) はこの用途に適したフォント ファミリーで、Inter や Geist ともよく合います。

[フォントソース](https://fontsource.org/fonts/noto-sans-arabic) を使用してフォントをインストールします。

```bash
npm install @fontsource-variable/noto-sans-arabic
```

`styles.css` でフォントをインポートします。

```css title="src/styles.css" showLineNumbers {4,7}
@import "tailwindcss";
@import "tw-animate-css";
@import "shadcn/tailwind.css";
@import "@fontsource-variable/noto-sans-arabic";

@theme inline {
  --font-sans: "Noto Sans Arabic Variable", sans-serif;
}
```

その他の言語、たとえばヘブライ語には `@fontsource-variable/noto-sans-hebrew` を使えます。

### コンポーネントの追加

これでプロジェクトにコンポーネントを追加する準備ができました。CLI が RTL サポートを処理します。

```bash
npx shadcn@latest add item
```

</Steps>
