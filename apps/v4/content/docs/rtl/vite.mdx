<Callout className="mb-6 border-emerald-600 bg-emerald-100 dark:border-emerald-400 dark:bg-emerald-900">

**新しいプロジェクトを開始しますか?** カスタム テーマ、Base UI または Radix、アイコン ライブラリを備えた完全に構成された Vite アプリを作成するには、[shadcn/create](/create?template=vite&base=base&rtl=true) を使用します。

</Callout>

<Steps>

### プロジェクトの作成

`--rtl` フラグと `vite` テンプレートを使用して、新しいプロジェクトを作成します。

**[shadcn/create](/create?template=vite&base=base&rtl=true) を使ってプロジェクトを作成済みの場合、この手順は省略できます。**

```bash
npx shadcn@latest create --template vite --rtl
```

これにより、`rtl: true` フラグを持つ `components.json` ファイルが作成されます。

```json title="components.json" showLineNumbers {4}
{
  "$schema": "https://ui.shadcn.com/schema.json",
  "style": "base-nova",
  "rtl": true
}
```

### DirectionProvider を追加

`dir="rtl"` 属性と `lang="ar"` 属性を `index.html` の `html` タグに追加します。 `lang="ar"` をターゲット言語に更新します。

```html title="index.html" showLineNumbers {2}
<!doctype html>
<html lang="ar" dir="rtl">
  <head>
    <meta charset="UTF-8" />
    <meta name="viewport" content="width=device-width, initial-scale=1.0" />
    <title>Vite App</title>
  </head>
  <body>
    <div id="root"></div>
    <script type="module" src="/src/main.tsx"></script>
  </body>
</html>
```

次に、`main.tsx` で `direction="rtl"` prop を持つ `DirectionProvider` コンポーネントでアプリをラップします。

```tsx title="src/main.tsx" showLineNumbers {4,12-13}
import { StrictMode } from "react"
import { createRoot } from "react-dom/client"

import { DirectionProvider } from "@/components/ui/direction"

import App from "./App"

import "./index.css"

createRoot(document.getElementById("root")!).render(
  <StrictMode>
    <DirectionProvider direction="rtl">
      <App />
    </DirectionProvider>
  </StrictMode>
)
```

### フォントの追加

最適な RTL 体験のため、対象言語を適切にサポートするフォントの使用を推奨します。[Noto](https://fonts.google.com/noto) はこの用途に適したフォント ファミリーで、Inter や Geist ともよく合います。

[フォントソース](https://fontsource.org/fonts/noto-sans-arabic) を使用してフォントをインストールします。

```bash
npm install @fontsource-variable/noto-sans-arabic
```

`index.css` でフォントをインポートします。

```css title="src/index.css" showLineNumbers {4,7}
@import "tailwindcss";
@import "tw-animate-css";
@import "shadcn/tailwind.css";
@import "@fontsource-variable/noto-sans-arabic";

@theme inline {
  --font-sans: "Noto Sans Arabic Variable", sans-serif;
}
```

その他の言語、たとえばヘブライ語には `@fontsource-variable/noto-sans-hebrew` を使えます。

### コンポーネントの追加

これでプロジェクトにコンポーネントを追加する準備ができました。CLI が RTL サポートを処理します。

```bash
npx shadcn@latest add item
```
