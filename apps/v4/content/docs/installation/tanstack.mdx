## shadcn/create

<Steps>

### プリセットのビルド

[shadcn/create](/create?template=start) を開いて、プリセットを視覚的に構築します。スタイル、色、フォント、アイコンなどを選択します。

<Button asChild size="sm">
  <Link
    href="/create?template=start"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    を使用します shadcn/create
  </Link>
</Button>

### プロジェクトの作成

`Create Project` をクリックし、パッケージ マネージャーを選択し、生成されたコマンドをコピーします。

生成されるコマンドは次のようになります。

```bash
npx shadcn@latest init --preset [CODE] --template start
```

正確なコマンドには、`--base`、`--monorepo`、`--rtl` などの選択したオプションが含まれます。

### コンポーネントの追加

`Card` コンポーネントをプロジェクトに追加します。

```bash
npx shadcn@latest add card
```

If you created a monorepo, run the command from `apps/web` or specify the workspace from the repo root:

```bash
npx shadcn@latest add card -c apps/web
```

上記のコマンドは、`Card` コンポーネントをプロジェクトに追加します。次に、次のようにインポートできます:

```tsx showLineNumbers title="src/routes/index.tsx"
import { createFileRoute } from "@tanstack/react-router"

import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

export const Route = createFileRoute("/")({
  component: App,
})

function App() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>
          Track progress and recent activity for your TanStack Start app.
        </CardDescription>
      </CardHeader>
      <CardContent>
        Your design system is ready. Start building your next component.
      </CardContent>
    </Card>
  )
}
```

If you created a monorepo, update `apps/web/src/routes/index.tsx` and import from `@workspace/ui/components/card` instead.

</Steps>

## CLI

<Steps>

### プロジェクトの作成

`init` コマンドを実行して、新しい TanStack Start プロジェクトをスキャフォールディングします。プロンプトに従って、ベース、プリセット、モノリポジトリなどのプロジェクトを構成します。

```bash
npx shadcn@latest init -t start
```

**モノリポ プロジェクトの場合は、`--monorepo` フラグを使用します。**

```bash
npx shadcn@latest init -t start --monorepo
```

### コンポーネントの追加

`Card` コンポーネントをプロジェクトに追加します。

```bash
npx shadcn@latest add card
```

If you created a monorepo, run the command from `apps/web` or specify the workspace from the repo root:

```bash
npx shadcn@latest add card -c apps/web
```

上記のコマンドは、`Card` コンポーネントをプロジェクトに追加します。次に、次のようにインポートできます:

```tsx showLineNumbers title="src/routes/index.tsx"
import { createFileRoute } from "@tanstack/react-router"

import {

  CardDescription,
```

</Steps>

## Existing Project

<Steps>

### プロジェクトの作成

If you need a new TanStack Start project, create one first. Otherwise, skip this step.

```bash
npx @tanstack/cli@latest create
```

TanStack Start、React フレームワーク、および推奨デフォルトを選択して、Tailwind CSS と `@/*` インポート エイリアスが構成されるようにします。

<Callout className="mt-6">

の開始 プロンプトが表示されたら、`shadcn` アドオンを追加しないでください。 `shadcn` CLI は、このガイドの後半で shadcn/ui を構成します。

</Callout>

TanStack CLI は、Tailwind CSS とデフォルトの `@/*` インポート エイリアスをすでに構成しています。古いまたはカスタムの TanStack Start アプリに shadcn/ui を追加する場合は、続行する前に両方が構成されていることを確認してください。

### CLI を実行します

`shadcn` init コマンドを実行して、プロジェクトに shadcn/ui をセットアップします。

```bash
npx shadcn@latest init
```

### コンポーネントの追加

これで、プロジェクトへのコンポーネントの追加を開始できます。

```bash
npx shadcn@latest add button
```

上記のコマンドは、`Button` コンポーネントをプロジェクトに追加します。次に、次のようにインポートできます:

```tsx showLineNumbers title="src/routes/index.tsx"
import { createFileRoute } from "@tanstack/react-router"

import { Button } from "@/components/ui/button"

export const Route = createFileRoute("/")({
  component: App,
})

function App() {
  return (
    <div className="flex min-h-svh items-center justify-center p-6">
      <Button>Click me</Button>
    </div>
  )
}
```

</Steps>
