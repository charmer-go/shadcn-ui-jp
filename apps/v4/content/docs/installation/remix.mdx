<Callout>

**注:** このガイドは Remix 用です。 React Router については、[React Router](/docs/installation/react-router) ガイドを参照してください。

</Callout>

<Steps>

### プロジェクトの作成

まず、`create-remix` を使用して新しい Remix プロジェクトを作成します。

```bash
npx create-remix@latest my-app
```

### CLI を実行します

`shadcn` init コマンドを実行してプロジェクトをセットアップします。

```bash
npx shadcn@latest init
```

### 以上です

これで、プロジェクトへのコンポーネントの追加を開始できます。

```bash
npx shadcn@latest add button
```

上記のコマンドは、`Button` コンポーネントをプロジェクトに追加します。次に、次のようにインポートできます:

```tsx {1,6} showLineNumbers title="app/routes/index.tsx"
import { Button } from "~/components/ui/button"

export default function Home() {
  return (
    <div>
      <Button>Click me</Button>
    </div>
  )
}
```

</Steps>
