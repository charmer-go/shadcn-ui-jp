## shadcn/create

<Steps>

### プリセットを構築する

[shadcn/create](/create?template=next) を開いて、プリセットを視覚的に構築します。スタイル、色、フォント、アイコンなどを選択します。

<Button asChild size="sm">
  <Link
    href="/create?template=next"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    shadcn/create
  </Link>
</Button>

### プロジェクトの作成

`Create Project` をクリックし、パッケージ マネージャーを選択し、生成されたコマンドをコピーします。

生成されるコマンドは次のようになります。

```bash
npx shadcn@latest init --preset [CODE] --template next
```

正確なコマンドには、`--base`、`--monorepo`、`--rtl` などの選択したオプションが含まれます。

### コンポーネントの追加

`Card` コンポーネントをプロジェクトに追加します。

```bash
npx shadcn@latest add card
```

If you created a monorepo, run the command from `apps/web` or specify the workspace from the repo root:

```bash
npx shadcn@latest add card -c apps/web
```

上記のコマンドは、`Card` コンポーネントをプロジェクトに追加します。次に、次のようにインポートできます。

```tsx showLineNumbers title="app/page.tsx"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

export default function Home() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>
          Track progress and recent activity for your Next.js app.
        </CardDescription>
      </CardHeader>
      <CardContent>
        Your design system is ready. Start building your next component.
      </CardContent>
    </Card>
  )
}
```

If you created a monorepo, update `apps/web/app/page.tsx` and import from `@workspace/ui/components/card` instead.

</Steps>

## Use the CLI

<Steps>

### プロジェクトの作成

`init` コマンドを実行して、新しい Next.js プロジェクトをスキャフォールディングします。プロンプトに従って、ベース、プリセット、モノリポジトリなどのプロジェクトを構成します。

```bash
npx shadcn@latest init -t next
```

**モノリポ プロジェクトの場合は、`--monorepo` フラグを使用します。**

```bash
npx shadcn@latest init -t next --monorepo
```

### コンポーネントの追加

`Card` コンポーネントをプロジェクトに追加します。

```bash
npx shadcn@latest add card
```

If you created a monorepo, run the command from `apps/web` or specify the workspace from the repo root:

```bash
npx shadcn@latest add card -c apps/web
```

上記のコマンドは、`Card` コンポーネントをプロジェクトに追加します。次に、次のようにインポートできます。

```tsx showLineNumbers title="app/page.tsx"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

export default function Home() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>Project Overview</CardTitle>
        <CardDescription>
          Track progress and recent activity for your Next.js app.
        </CardDescription>
      </CardHeader>
      <CardContent>
        Your design system is ready. Start building your next component.
      </CardContent>
    </Card>
  )
}
```

If you created a monorepo, update `apps/web/app/page.tsx` and import from `@workspace/ui/components/card` instead.

</Steps>

## Existing Project

<Steps>

### プロジェクトの作成

If you need a new Next.js project, create one with `create-next-app`. Otherwise, skip this step.

```bash
npx create-next-app@latest
```

推奨されるデフォルトを選択すると、Tailwind CSS、App Router、およびデフォルトの `@/*` インポート エイリアスが自動的に構成されます。

If you prefer a `src/` directory, use `--src-dir` or choose `Yes` when prompted:

```bash
npx create-next-app@latest --src-dir
```

`--src-dir` を使用すると、Next.js はアプリを `src/app` に配置し、`@/*` エイリアスが `./src/*` を指すように構成します。

### Tailwind CSS の構成とエイリアスのインポート

If you created your project with the recommended `create-next-app` defaults, you can skip this step.

If you're adding shadcn/ui to an older or custom Next.js app, make sure Tailwind CSS is installed first. You can follow the official [Next.js installation guide](https://nextjs.org/docs/app/getting-started).

次に、`tsconfig.json` に `@/*` インポート エイリアスが含まれていることを確認します。

```json title="tsconfig.json" showLineNumbers
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```

If you used `--src-dir`, point the alias to `./src/*` instead.

### CLI を実行します

`shadcn` init コマンドを実行して、プロジェクトに shadcn/ui をセットアップします。

```bash
npx shadcn@latest init
```

### コンポーネントの追加

これで、プロジェクトへのコンポーネントの追加を開始できます。

```bash
npx shadcn@latest add button
```

上記のコマンドは、`Button` コンポーネントをプロジェクトに追加します。次に、次のようにインポートできます。

```tsx showLineNumbers title="app/page.tsx"
import { Button } from "@/components/ui/button"

export default function Home() {
  return (
    <div className="flex min-h-svh items-center justify-center">
      <Button>Click me</Button>
    </div>
  )
}
```

If you used `--src-dir`, add the component to `src/app/page.tsx` instead.

</Steps>
