## Use shadcn/create

<Steps>

### プリセットを作成する

 [shadcn/create](/create?template=vite)を開き、プリセットを視覚的に作成します。スタイル、色、フォント、アイコンなどを選択してください。

<Button asChild size="sm">
  <Link
    href="/create?template=vite"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    shadcn/create を開く
  </Link>
</Button>

### プロジェクトを作成する

`Create Project` をクリックし、パッケージ マネージャーを選択して、生成されたコマンドをコピーします。

生成されたコマンドは次のようになります。

```bash
npx shadcn@latest init --preset [CODE] --template vite
```

実際のコマンドには、選択した `--base`、`--monorepo`、`--rtl` などのオプションが含まれます。

### コンポーネントを追加する

プロジェクトに `Card` コンポーネントを追加します。

```bash
npx shadcn@latest add card
```

モノレポを作成した場合は `apps/web` からコマンドを実行するか、リポジトリのルートからワークスペースを指定します。

```bash
npx shadcn@latest add card -c apps/web
```

上のコマンドで `Card` コンポーネントがプロジェクトに追加されます。次のようにインポートできます。

```tsx showLineNumbers title="src/App.tsx"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

function App() {
  return (
    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>プロジェクト概要</CardTitle>
        <CardDescription>
          Vite アプリの進捗と最近のアクティビティを確認します。
        </CardDescription>
      </CardHeader>
      <CardContent>
        デザイン システムの準備ができました。次のコンポーネントの構築を始めましょう。
      </CardContent>
    </Card>
  )
}

export default App
```

モノレポを作成した場合は `apps/web/src/App.tsx` を更新し、代わりに `@workspace/ui/components/card` からインポートします。

</Steps>

## Use the CLI

<Steps>

### プロジェクトを作成する

`init` コマンドを実行して新しい Vite プロジェクトを作成します。プロンプトに従って、ベース、プリセット、モノレポなどを構成します。

```bash
npx shadcn@latest init -t vite
```

**モノレポ プロジェクトでは `--monorepo` フラグを使います。**

```bash
npx shadcn@latest init -t vite --monorepo
```

### コンポーネントを追加する

プロジェクトに `Card` コンポーネントを追加します。

```bash
npx shadcn@latest add card
```

モノレポを作成した場合は `apps/web` からコマンドを実行するか、リポジトリのルートからワークスペースを指定します。

```bash
npx shadcn@latest add card -c apps/web
```

上のコマンドで `Card` コンポーネントがプロジェクトに追加されます。次のようにインポートできます。

```tsx showLineNumbers title="src/App.tsx"
import {
  Card,
  CardContent,
  CardDescription,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"

function App() {

    <Card className="max-w-sm">
      <CardHeader>
        <CardTitle>プロジェクト概要</CardTitle>
        <CardDescription>
```

モノレポを作成した場合は `apps/web/src/App.tsx` を更新し、代わりに `@workspace/ui/components/card` からインポートします。

</Steps>

## Existing Project

<Steps>

### プロジェクトを作成する

新しい Vite プロジェクトが必要な場合は、先に作成して **React + TypeScript** テンプレートを選択します。既存のプロジェクトがある場合は、この手順を省略してください。

```bash
npm create vite@latest
```

### Tailwind CSS を追加する

プロジェクトに Tailwind CSS がすでに構成されている場合は、この手順を省略してください。

```bash
npm install tailwindcss @tailwindcss/vite
```

`src/index.css` の内容を次のものに置き換えます。

```css title="src/index.css"
@import "tailwindcss";
```

### tsconfig.json を編集する

プロジェクトに `@/*` エイリアスがすでに構成されている場合は、この手順を省略してください。

Vite は TypeScript の構成を複数のファイルに分割します。`tsconfig.json` と `tsconfig.app.json` の `compilerOptions` セクションに、`baseUrl` と `paths` プロパティを追加します。

```ts title="tsconfig.json" {11-16} showLineNumbers
{
  "files": [],
  "references": [
    {
      "path": "./tsconfig.app.json"
    },
    {
      "path": "./tsconfig.node.json"
    }
  ],
  "compilerOptions": {
    "baseUrl": ".",
    "paths": {
      "@/*": ["./src/*"]
    }
  }
}
```

### tsconfig.app.json を編集する

エディターがインポートを解決できるよう、同じエイリアスを `tsconfig.app.json` に追加します。

```ts title="tsconfig.app.json" {4-9} showLineNumbers
{
  "compilerOptions": {
    // ...
    "baseUrl": ".",
    "paths": {
      "@/*": [
        "./src/*"
      ]
    }
    // ...
  }
}
```

### vite.config.ts を更新する

`@types/node` をインストールし、Vite が `@` エイリアスを解決できるよう `vite.config.ts` を更新します。

```bash
npm install -D @types/node
```

```typescript title="vite.config.ts" showLineNumbers {1,2,8-13}
import path from "path"
import tailwindcss from "@tailwindcss/vite"
import react from "@vitejs/plugin-react"
import { defineConfig } from "vite"

// https://vite.dev/config/
export default defineConfig({
  plugins: [react(), tailwindcss()],
  resolve: {
    alias: {
      "@": path.resolve(__dirname, "./src"),
    },
  },
})
```

### CLI を実行する

`shadcn` の init コマンドを実行して、プロジェクトに shadcn/ui を設定します。

```bash
npx shadcn@latest init
```

### コンポーネントを追加する

これでプロジェクトにコンポーネントを追加できるようになりました。

```bash
npx shadcn@latest add button
```

上のコマンドで `Button` コンポーネントがプロジェクトに追加されます。次のようにインポートできます。

```tsx showLineNumbers title="src/App.tsx"
import { Button } from "@/components/ui/button"

function App() {
  return (
    <div className="flex min-h-svh flex-col items-center justify-center">
      <Button>クリック</Button>
    </div>
  )
}

export default App
```

</Steps>
