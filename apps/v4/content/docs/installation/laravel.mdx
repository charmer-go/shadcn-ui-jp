shadcn CLI は、新しい Laravel アプリをスキャフォールディングしません。まず、React スターター キットを使用して Laravel アプリを作成し、次に shadcn/ui を構成する方法を選択します。

<Steps>

### プロジェクトの作成

Laravel インストーラーを使用して新しい Laravel アプリを作成します。

```bash
laravel new my-app
```

If you already have a Laravel app with React and Inertia configured, skip this step.

プロンプトが表示されたら、**React** スターター キットを選択します。詳細については、公式の [Laravel フロントエンド ドキュメント](https://laravel.com/docs/12.x/frontend) を参照してください。

次に、プロジェクト ディレクトリに移動します:

```bash
cd my-app
```

</Steps>

## shadcn/create

<Steps>

### プリセットを構築する

[shadcn/create](/create?template=laravel) を開いてプリセットを視覚的に構築します。スタイル、色、フォント、アイコンなどを選択します。

<Button asChild size="sm">
  <Link
    href="/create?template=laravel"
    target="_blank"
    rel="noopener noreferrer"
    className="mt-6 no-underline!"
  >
    shadcn/create
  </Link>
</Button>

### コマンドを実行する

`Create Project` をクリックし、パッケージ マネージャーを選択し、生成されたコマンドをコピーします。

生成されるコマンドは次のようになります。

```bash
npx shadcn@latest init --preset [CODE] --template laravel
```

を使用する Laravel アプリのルートからコマンドを実行します。

`components.json` とコンポーネントを上書きするように求められたら、`Yes` を選択します。

### コンポーネントの追加

`Switch` コンポーネントをプロジェクトに追加します。

```bash
npx shadcn@latest add switch
```

上記のコマンドは、`Switch` コンポーネントを `resources/js/components/ui/switch.tsx` に追加します。次に、次のようにインポートできます。

```tsx title="resources/js/pages/index.tsx" showLineNumbers {1,6}
import { Switch } from "@/components/ui/switch"

const MyPage = () => {
  return (
    <div>
      <Switch />
    </div>
  )
}

export default MyPage
```

</Steps>

## Use the CLI

<Steps>

### CLI を実行します

Laravel アプリのルートから `shadcn` init コマンドを実行します。

```bash
npx shadcn@latest init
```

`components.json` とコンポーネントを上書きするように求められたら、`Yes` を選択します。
