[shadcn MCP サーバー](/docs/mcp)は shadcn 互換のレジストリであればそのまま動作します。レジストリ側で MCP サポートを有効にするために特別な対応は不要です。

---

## 前提条件

MCP サーバーはレジストリインデックスをリクエストして動作します。レジストリのルートに `registry` という名前のレジストリアイテムファイルがあることを確認してください。

たとえば、レジストリが `https://acme.com/r/[name].json` でホストされている場合、`https://acme.com/r/registry.json` にファイルが必要です。JSON 拡張子を使わない形式の場合は `https://acme.com/r/registry` にファイルを配置してください。

このファイルは[レジストリスキーマ](/docs/registry/registry-json)に準拠した有効な JSON ファイルでなければなりません。

---

## ベストプラクティス

MCP 対応レジストリ向けのベストプラクティスを紹介します:

1. **明確な説明**: AI アシスタントがレジストリアイテムの用途や使い方を理解できるよう、簡潔で分かりやすい説明を追加します。
2. **適切な依存関係**: MCP が自動インストールできるよう、すべての `dependencies` を正確に列挙します。
3. **レジストリ依存関係**: アイテム間の関係を示すために `registryDependencies` を使用します。
4. **一貫した命名**: コンポーネント名には kebab-case を使い、レジストリ全体で一貫性を保ちます。
