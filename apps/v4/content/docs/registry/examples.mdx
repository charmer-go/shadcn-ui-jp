## registry:style

### shadcn/ui を拡張するカスタムスタイル

以下のレジストリアイテムは、shadcn/ui を拡張するカスタムスタイルです。`npx shadcn init` を実行すると、次の処理が行われます：

- `@tabler/icons-react` を依存関係としてインストールします。
- `login-01` ブロックと `calendar` コンポーネントをプロジェクトに追加します。
- リモートレジストリから `editor` を追加します。
- `font-sans` 変数に `Inter, sans-serif` を設定します。
- ライトモードとダークモードに `brand` カラーをインストールします。

```json title="example-style.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "example-style",
  "type": "registry:style",
  "dependencies": ["@tabler/icons-react"],
  "registryDependencies": [
    "login-01",
    "calendar",
    "https://example.com/r/editor.json"
  ],
  "cssVars": {
    "theme": {
      "font-sans": "Inter, sans-serif"
    },
    "light": {
      "brand": "20 14.3% 4.1%"
    },
    "dark": {
      "brand": "20 14.3% 4.1%"
    }
  }
}
```

### スクラッチから作成するカスタムスタイル

以下のレジストリアイテムは、shadcn/ui を拡張しないカスタムスタイルです。`extends: none` フィールドを参照してください。

新しいスタイルをスクラッチから作成するために使用できます（カスタムコンポーネント、CSS変数、依存関係など）。

`npx shadcn add` を実行すると、次の処理が行われます：

- `cn` を依存関係としてインストールします。
- shadcn/ui レジストリから `utils` レジストリアイテムを追加します。
- リモートレジストリから `button`、`input`、`label`、`select` コンポーネントを追加します。
- 新しい CSS変数 `main`、`bg`、`border`、`text`、`ring` をインストールします。

```json title="example-style.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "extends": "none",
  "name": "new-style",
  "type": "registry:style",
  "dependencies": ["cn"],
  "registryDependencies": [
    "utils",
    "https://example.com/r/button.json",
    "https://example.com/r/input.json",
    "https://example.com/r/label.json",
    "https://example.com/r/select.json"
  ],
  "cssVars": {
    "theme": {
      "font-sans": "Inter, sans-serif"
    },
    "light": {
      "main": "#88aaee",
      "bg": "#dfe5f2",
      "border": "#000",
      "text": "#000",
      "ring": "#000"
    },
    "dark": {
      "main": "#88aaee",
      "bg": "#272933",
      "border": "#000",
      "text": "#e6e6e6",
      "ring": "#fff"
    }
  }
}
```

## ターゲットプレースホルダー

レジストリアイテムがユーザーの設定済み shadcn ディレクトリ配下にファイルをインストールする場合は、`files[].target` プレースホルダーを使用します。利用可能なプレースホルダーは `@components/`、`@ui/`、`@lib/`、`@hooks/` です。

プレースホルダーは `components.json` から解決されるため、同じレジストリアイテムが `@/`、カスタム TypeScript エイリアス、パッケージインポート、ワークスペースパッケージのエクスポートを使用するプロジェクトでも動作します。

プレースホルダー以降の部分は保持されます。たとえば、`@ui/ai/prompt-input.tsx` は、ユーザーの設定済み `ui` ディレクトリ配下の `ai/prompt-input.tsx` にインストールされます。

```json title="alias-child.json" showLineNumbers {9,15,21}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "alias-child",
  "type": "registry:item",
  "files": [
    {
      "path": "registry/new-york/alias/target-alias-button.tsx",
      "type": "registry:ui",
      "target": "@ui/target-alias-button.tsx",
      "content": "..."
    },
    {
      "path": "registry/new-york/alias/target-alias-helper.ts",
      "type": "registry:lib",
      "target": "@lib/target-alias-helper.ts",
      "content": "..."
    },
    {
      "path": "registry/new-york/alias/prompt-input.tsx",
      "type": "registry:ui",
      "target": "@ui/ai/prompt-input.tsx",
      "content": "..."
    }
  ]
}
```

レジストリ依存関係でもターゲットプレースホルダーを使用できます。以下の例では、子アイテムが UI コンポーネントとヘルパーをインストールし、親アイテムがアプリコンポーネントとフックをインストールします。

```json title="alias-parent.json" showLineNumbers {7,13}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "alias-parent",
  "type": "registry:item",
  "registryDependencies": ["https://example.com/r/alias-child.json"],
  "files": [
    {
      "path": "registry/new-york/alias/target-alias-panel.tsx",
      "type": "registry:component",
      "target": "@components/target-alias-panel.tsx",
      "content": "..."
    },
    {
      "path": "registry/new-york/alias/use-target-alias.ts",
      "type": "registry:hook",
      "target": "@hooks/use-target-alias.ts",
      "content": "..."
    }
  ]
}
```

`target` は、ファイルの `type` と異なる場合でも、ファイルの書き込み先を制御します。

```json title="type-mismatch.json" showLineNumbers {9}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "type-mismatch",
  "type": "registry:item",
  "files": [
    {
      "path": "registry/new-york/example/format-date.ts",
      "type": "registry:ui",
      "target": "@lib/format-date.ts",
      "content": "..."
    }
  ]
}
```

### カスタムセレクター付きフォント

全体の `html` ではなく特定の CSS セレクターにフォントを適用する場合は、`selector` フィールドを使用します。見出し用フォントなど、対象を絞ってフォントを適用したい場合に便利です。

```json title="font-playfair-display.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "font-playfair-display",
  "type": "registry:font",
  "font": {
    "family": "'Playfair Display Variable', serif",
    "provider": "google",
    "import": "Playfair_Display",
    "variable": "--font-heading",
    "subsets": ["latin"],
    "selector": "h1, h2, h3, h4, h5, h6",
    "dependency": "@fontsource-variable/playfair-display"
  }
}
```

`selector` を設定すると、フォントユーティリティクラス（例：`font-heading`）は `<html>` 要素に追加される代わりに、`@layer base` 内で指定したセレクターに対して CSS の `@apply` で適用されます。CSS変数は引き続き `<html>` に注入されるため、グローバルに利用できます。

## registry:base

### カスタムベース

`registry:base` アイテムは、完全なデザインシステムのベースです。プロジェクト向けに、依存関係一式、CSS変数、設定を定義します。`config` フィールドは `registry:base` アイテム固有のものです。

`config` フィールドでは以下のプロパティを使用できます（すべて任意です）：

| プロパティ           | 型                                                                           | 説明                                                               |
| -------------------- | ---------------------------------------------------------------------------- | ------------------------------------------------------------------ |
| `style`              | `string`                                                                     | ベースのスタイル名です。                                           |
| `iconLibrary`        | `string`                                                                     | 使用するアイコンライブラリです（例：`lucide`）。                   |
| `rsc`                | `boolean`                                                                    | React Server Components を有効化します。既定値は `false` です。    |
| `tsx`                | `boolean`                                                                    | TypeScript を使用します。既定値は `true` です。                    |
| `rtl`                | `boolean`                                                                    | 右から左（RTL）表示を有効化します。既定値は `false` です。         |
| `menuColor`          | `"default" \| "inverted" \| "default-translucent" \| "inverted-translucent"` | メニューの配色です。既定値は `"default"` です。                    |
| `menuAccent`         | `"subtle" \| "bold"`                                                         | メニューのアクセントスタイルです。既定値は `"subtle"` です。       |
| `tailwind.baseColor` | `string`                                                                     | ベースカラー名です（例：`neutral`、`slate`、`zinc`）。             |
| `tailwind.css`       | `string`                                                                     | Tailwind CSS ファイルへのパスです。                                |
| `tailwind.prefix`    | `string`                                                                     | すべての Tailwind クラスに付加するプレフィックスです。             |
| `aliases.components` | `string`                                                                     | コンポーネント用のインポートエイリアスです。                       |
| `aliases.utils`      | `string`                                                                     | ユーティリティ用のインポートエイリアスです。                       |
| `aliases.ui`         | `string`                                                                     | UI コンポーネント用のインポートエイリアスです。                    |
| `aliases.lib`        | `string`                                                                     | lib 用のインポートエイリアスです。                                 |
| `aliases.hooks`      | `string`                                                                     | hooks 用のインポートエイリアスです。                               |
| `registries`         | `Record<string, string \| object>`                                           | カスタムレジストリの URL です。キーは `@` で始める必要があります。 |

```json title="custom-base.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "custom-base",
  "type": "registry:base",
  "config": {
    "style": "custom-base",
    "iconLibrary": "lucide",
    "tailwind": {
      "baseColor": "neutral"
    }
  },
  "dependencies": [
    "class-variance-authority",
    "tw-animate-css",
    "lucide-react"
  ],
  "registryDependencies": ["utils", "font-inter"],
  "cssVars": {
    "light": {
      "background": "oklch(1 0 0)",
      "foreground": "oklch(0.141 0.005 285.823)",
      "primary": "oklch(0.21 0.006 285.885)",
      "primary-foreground": "oklch(0.985 0 0)"
    },
    "dark": {
      "background": "oklch(0.141 0.005 285.823)",
      "foreground": "oklch(0.985 0 0)",
      "primary": "oklch(0.985 0 0)",
      "primary-foreground": "oklch(0.21 0.006 285.885)"
    }
  },
  "css": {
    "@import \"tw-animate-css\"": {},
    "@layer base": {
      "*": {
        "@apply border-border outline-ring/50": {}
      },
      "body": {
        "@apply bg-background text-foreground": {}
      }
    }
  }
}
```

## CSS インポートを追加する

レジストリアイテムに CSS インポートを追加する場合は `@import` を使用します。インポートは CSS ファイルの先頭に配置されます。

### 基本的なインポート

```json title="example-import.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "custom-import",
  "type": "registry:component",
  "css": {
    "@import \"tailwindcss\"": {},
    "@import \"./styles/base.css\"": {}
  }
}
```

### url() 構文でのインポート

```json title="example-url-import.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "font-import",
  "type": "registry:item",
  "css": {
    "@import url(\"https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap\")": {},
    "@import url('./local-styles.css')": {}
  }
}
```

### メディアクエリ付きのインポート

```json title="example-media-import.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "responsive-import",
  "type": "registry:item",
  "css": {
    "@import \"print-styles.css\" print": {},
    "@import url(\"mobile.css\") screen and (max-width: 768px)": {}
  }
}
```

## カスタムプラグインを追加する

レジストリアイテムに Tailwind プラグインを追加する場合は `@plugin` を使用します。プラグインはインポートの後、その他のコンテンツの前に自動的に配置されます。

**重要：** npm パッケージのプラグインを使用する場合は、`dependencies` 配列にも追加する必要があります。

### 基本的なプラグインの使用方法

```json title="example-plugin.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "custom-plugin",
  "type": "registry:item",
  "css": {
    "@plugin \"@tailwindcss/typography\"": {},
    "@plugin \"foo\"": {}
  }
}
```

### npm 依存関係付きのプラグイン

`@tailwindcss/typography` のような npm パッケージのプラグインを使用する場合は、依存関係に含めてください。

```json title="example-typography.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "typography-component",
  "type": "registry:item",
  "dependencies": ["@tailwindcss/typography"],
  "css": {
    "@plugin \"@tailwindcss/typography\"": {},
    "@layer components": {
      ".prose": {
        "max-width": "65ch"
      }
    }
  }
}
```

### スコープ付きプラグインとファイルベースのプラグイン

```json title="example-scoped-plugin.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "scoped-plugins",
  "type": "registry:component",
  "css": {
    "@plugin \"@headlessui/tailwindcss\"": {},
    "@plugin \"tailwindcss/plugin\"": {},
    "@plugin \"./custom-plugin.js\"": {}
  }
}
```

### 複数プラグインの自動順序付け

複数のプラグインを追加すると、自動的にグループ化され、重複が除去されます。

```json title="example-multiple-plugins.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "multiple-plugins",
  "type": "registry:item",
  "dependencies": [
    "@tailwindcss/typography",
    "@tailwindcss/forms",
    "tw-animate-css"
  ],
  "css": {
    "@plugin \"@tailwindcss/typography\"": {},
    "@plugin \"@tailwindcss/forms\"": {},
    "@plugin \"tw-animate-css\"": {}
  }
}
```

## インポートとプラグインの組み合わせ

`@import` と `@plugin` の両方のディレクティブを使用する場合、インポートが先に配置され、次にプラグイン、その後にその他の CSS コンテンツが続きます。

```json title="example-combined.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "combined-example",
  "type": "registry:item",
  "dependencies": ["@tailwindcss/typography", "tw-animate-css"],
  "css": {
    "@import \"tailwindcss\"": {},
    "@import url(\"https://fonts.googleapis.com/css2?family=Inter:wght@400;500;600&display=swap\")": {},
    "@plugin \"@tailwindcss/typography\"": {},
    "@plugin \"tw-animate-css\"": {},
    "@layer base": {
      "body": {
        "font-family": "Inter, sans-serif"
      }
    },
    "@utility content-auto": {
      "content-visibility": "auto"
    }
  }
}
```

## カスタムアニメーションを追加する

注意：アニメーションを使用するには、`css` に `@keyframes` と `cssVars` の `theme` の両方を定義する必要があります。

```json title="example-component.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "custom-component",
  "type": "registry:component",
  "cssVars": {
    "theme": {
      "--animate-wiggle": "wiggle 1s ease-in-out infinite"
    }
  },
  "css": {
    "@keyframes wiggle": {
      "0%, 100%": {
        "transform": "rotate(-3deg)"
      },
      "50%": {
        "transform": "rotate(3deg)"
      }
    }
  }
}
```

## 環境変数を追加する

`envVars` フィールドを使用して環境変数を追加できます。

```json title="example-item.json" showLineNumbers {5-9}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "custom-item",
  "type": "registry:item",
  "envVars": {
    "NEXT_PUBLIC_APP_URL": "http://localhost:4000",
    "DATABASE_URL": "postgresql://postgres:postgres@localhost:5432/postgres",
    "OPENAI_API_KEY": ""
  }
}
```

環境変数は `.env.local` または `.env` ファイルに追加されます。既存の変数は上書きされません。

<Callout>

**重要：** 開発用またはサンプル用の変数を追加する場合は `envVars` を使用してください。本番用の変数の追加には使用しないでください。

</Callout>

## ユニバーサルアイテム

`2.9.0` 以降では、フレームワーク検出や components.json なしでインストールできるユニバーサルアイテムを作成できます。

アイテムをユニバーサル（フレームワーク非依存）にするには、アイテム内のすべてのファイルに明示的な target を指定する必要があります。

以下は _python_ 向けのカスタム Cursor ルールをインストールするレジストリアイテムの例です：

```json title=".cursor/rules/custom-python.mdc" showLineNumbers {9}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "python-rules",
  "type": "registry:item",
  "files": [
    {
      "path": "/path/to/your/registry/default/custom-python.mdc",
      "type": "registry:file",
      "target": "~/.cursor/rules/custom-python.mdc",
      "content": "..."
    }
  ]
}
```

以下はカスタム ESLint 設定をインストールする別の例です：

```json title=".eslintrc.json" showLineNumbers {9}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "my-eslint-config",
  "type": "registry:item",
  "files": [
    {
      "path": "/path/to/your/registry/default/custom-eslint.json",
      "type": "registry:file",
      "target": "~/.eslintrc.json",
      "content": "..."
    }
  ]
}
```

複数のファイルをインストールするユニバーサルアイテムも作成できます：

```json title="my-custom-starter-template.json" showLineNumbers {9}
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "my-custom-starter-template",
  "type": "registry:item",
  "dependencies": ["better-auth"],
  "files": [
    {
      "path": "/path/to/file-01.json",
      "type": "registry:file",
      "target": "~/file-01.json",
      "content": "..."
    },
    {
      "path": "/path/to/file-02.vue",
      "type": "registry:file",
      "target": "~/pages/file-02.vue",
      "content": "..."
    }
  ]
}
```
