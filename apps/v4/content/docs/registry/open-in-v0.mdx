---
title: v0 で開く
description: レジストリを Open in v0 と連携します。
---

レジストリが URL でホストされ、公開アクセスできる場合、`https://v0.dev/chat/api/open?url=[URL]` エンドポイントを使ってレジストリアイテムを v0 で開けます。

例: [https://v0.dev/chat/api/open?url=https://ui.shadcn.com/r/styles/new-york/login-01.json](https://v0.dev/chat/api/open?url=https://ui.shadcn.com/r/styles/new-york/login-01.json)

<Callout className="mt-6">
  **重要:** `Open in v0` は
  `cssVars`、`css`、`envVars`、名前空間付きレジストリ、高度な認証方式に対応していません。
</Callout>

## 認証

Open in v0 はクエリパラメーター認証のみに対応しています。名前空間付きレジストリや、Bearer トークン・ヘッダー内の API キーなどの高度な認証方式には対応していません。

### クエリパラメーター認証を使う

Open in v0 向けにレジストリへ認証を追加するには、`token` クエリパラメーターを使用します:

```
https://registry.company.com/r/hello-world.json?token=your_secure_token_here
```

レジストリサーバーに実装する際は:

1. `token` クエリパラメーターを確認します
2. トークンを認証システムと照合して検証します
3. トークンが無効または不足している場合は `401 Unauthorized` レスポンスを返します
4. shadcn CLI と Open in v0 はどちらも 401 レスポンスを処理し、ユーザーに適切なメッセージを表示します

### 実装例

```typescript
// Next.js API route example
export async function GET(request: NextRequest) {
  const token = request.nextUrl.searchParams.get("token")

  if (!isValidToken(token)) {
    return NextResponse.json(
      {
        error: "Unauthorized",
        message: "Invalid or missing token",
      },
      { status: 401 }
    )
  }

  // Return the registry item
  return NextResponse.json(registryItem)
}
```

<Callout className="mt-6">
  **セキュリティ注意:**
  トークンは必ず暗号化し、有効期限を設定してください。本番用トークンをドキュメントや例に公開しないでください。
</Callout>
