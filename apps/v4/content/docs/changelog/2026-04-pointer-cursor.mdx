---
title: 2026 年 4 月 - ポインター カーソル
description: プロジェクトのセットアップ中にボタンのカーソル ポインターの動作を追加します。
date: 2026-04-25
---

プロジェクトの初期化時にボタンの `cursor: pointer` を有効にできるようになりました。

```bash
npx shadcn@latest init --pointer
```

これにより、次の CSS がグローバル CSS ファイルに追加されます。

```css title="globals.css"
@layer base {
  button:not(:disabled),
  [role="button"]:not(:disabled) {
    cursor: pointer;
  }
}
```

`--pointer` オプションは、プリセット コードの一部ではありません。これは、`--rtl` と同様に、プロジェクト セットアップ オプションとして適用されます。
