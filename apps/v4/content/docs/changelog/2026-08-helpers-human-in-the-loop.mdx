**@shadcn/helpers** は、AI SDK の人間参加フローをモックできるようになりました。あ
スクリプト化された会話は、実際のユーザー入力のために一時停止したり、承認を待ったりすることができます。
ユーザーが決定した内容をそのまま続行します。

すべてが現実を流れていく
`useChat` ライフサイクル、つまりツール カード、承認プロンプト、質問フロー
本番環境とまったく同じように動作します。

```ts showLineNumbers
import { createChat } from "@shadcn/helpers/ai-sdk"

const chat = createChat<ChatMessage>()
  .user("Help me plan the next prototype.")
  .assistant(({ writer }) => {
    writer.text("A couple of questions before I start.")
    writer.tool("askQuestions", { input: { questions } })
  })
  .assistant(({ writer, toolCall }) => {
    writer.text(
      toolCall?.name === "askQuestions" && toolCall.output
        ? `Starting with ${toolCall.output.answers.direction}.`
        : "Starting now."
    )
  })
```

ユーザーの決定を待って一時停止するには、`needsApproval` を渡します。スクリプト化された出力
承認後にストリーミングされ、拒否は自動的にストリーミングされます。

```ts showLineNumbers
chat
  .assistant(({ writer }) => {
    writer.text("That will archive 3 drafts. I need your approval.")
    writer.tool("archiveDrafts", {
      input: { count: 3 },
      needsApproval: true,
      output: { archived: 3 },
    })
  })
  .assistant(({ writer, toolCall }) => {
    writer.text(
      toolCall?.approved ? "Archived 3 drafts." : "Okay, leaving them in place."
    )
  })
```
