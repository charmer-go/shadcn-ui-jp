アイテムをインストールできるオープン ソース レジストリのインデックスを作成しました。

`components.json` ファイルを構成しなくても、レジストリインデックスから項目を検索、表示、追加できます。

これらは、`components.json` ファイルに自動的に追加されます。

```bash
npx shadcn add @ai-elements/prompt-input
```

レジストリの完全なリストは [https://ui.shadcn.com/r/registries.json](https://ui.shadcn.com/r/registries.json]で入手できます。

レジストリをインデックスに追加するにはまず、PR を `shadcn/ui` リポジトリに送信します。詳細については、[レジストリ インデックスのドキュメント](/docs/registry/registry-index) を参照してください。
