コンポーネント ドキュメント全体に **構成** セクションを追加しました。これにより、何が何をラップしているか、どのサブコンポーネントが一緒に属しているか、無効なネストを回避する方法など、正しい構造が一目でわかるようになりました。

```text
Card
├── CardHeader
│   ├── CardTitle
│   ├── CardDescription
│   └── CardAction
├── CardContent
└── CardFooter
```

## これを追加した理由

**LLM とコーディング エージェントは、完全な構造を確認できる場合、より確実に要素を構成できる**ことがわかりました。つまり、欠落しているラッパーが少なく、間違った階層が少なく、例との一致が良くなります。

### エージェントにドキュメントを持ち込む

あなたまたはあなたの LLM は、構成、使用法、例を含む同じコンポーネントのドキュメントを CLI からコンテキストに取り込むことができます。

```bash
npx shadcn@latest docs card
```

[shadcn/skills](/docs/skills) を使用している場合、これは自動的に行われます。
