私たちは、小規模で集中的なための新しいパッケージである **@shadcn/helpers** をオープンソース化しています。
アプリの開発を容易にするヘルパー。

AI SDK と TanStack AI のヘルパーから始めます。それはあなたが書くことができます
コード内で会話を実行し、その後、何もせずに実際の `useChat` ライフサイクルを通して実行します。
モデル、API ルート、ネットワーク リクエスト、または API キー。

UI はネイティブを受け取ります
フレームワーク メッセージとストリーミング イベント、つまり推論、ツール呼び出し、読み込み
状態とメッセージ コンポーネントは実稼働環境と同じように動作します。

AI SDK ヘルパーを使用して書かれた会話は次のとおりです。

```ts showLineNumbers
import { createChat } from "@shadcn/helpers/ai-sdk"

const chat = createChat()
  .user("What changed in this release?")
  .assistant("The release adds keyboard shortcuts and faster search.")
  .user("Can you check the full release notes?")
  .sleep(500)
  .assistant(({ writer }) => {
    writer.stepStart()

    // Reasoning.
    writer.reasoning("I should read the release notes first.")

    // Tool call.
    writer
      .tool("getReleaseNotes", {
        title: "Reading release notes",
        input: { version: "latest" },
      })
      .sleep(500)
      .output({
        highlights: ["Keyboard shortcuts", "Faster search"],
      })

    // Source.
    writer.sourceUrl({
      title: "Release notes",
      url: "https://example.com/releases",
    })

    // Response.
    writer.text("The release adds keyboard shortcuts and faster search.")
  })
```

そのメッセージを渡して `useChat` に転送します。

```tsx showLineNumbers
import { useChat } from "@ai-sdk/react"

const initialMessages = chat.get(0)
const transport = chat.transport()

export function Chat() {
  const { messages } = useChat({
    messages: initialMessages,
    transport,
  })
}
```

パッケージには次の 2 つのアダプターが含まれています。

- [`@shadcn/helpers/ai-sdk`](/docs/helpers/ai-sdk) は AI SDK の `useChat` にプラグインします
交通手段として。
- [`@shadcn/helpers/tanstack-ai`](/docs/helpers/tanstack-ai) を TanStack にプラグインします
AI の `useChat` を接続とし​​て使用し、実際の AG-UI イベントをストリーミングします。

これを使用してコンポーネントを構築したり、プレビューやデモを作成したり、ドキュメントを作成したり、
決定的な出力とバックエンド依存性のないストリーミング インターフェイスをテストします。
