**パブリック GitHub リポジトリをレジストリに変えることができるようになりました。**

リポジトリのルートに `registry.json` ファイルを追加し、必要な項目を定義します。
配布したい場合、ユーザーは次のコマンドを使用して GitHub から直接インストールできます。
`shadcn` CLI。

```bash
npx shadcn@latest add <username>/<repo>/<item>
```

たとえば、`acme/toolkit` リポジトリから `project-conventions` アイテムをインストールするには、次のようにします。

```bash
npx shadcn@latest add acme/toolkit/project-conventions
```

GitHub レジストリはソース レジストリです。 `shadcn build` を実行する必要はありません。
生成されたアイテムの JSON ファイルを公開するか、レジストリ サーバーをセットアップします。 CLI は、
ルート `registry.json`、`include` エントリを解決し、要求されたアイテムを検索し、
その項目で宣言されたファイルをインストールします。

## 何でも配布

レジストリ項目はコンポーネントに限定されません。 GitHub レジストリは配布できます
コンポーネント、フック、ユーティリティ、デザイントークン、機能キット、プロジェクト規約、
エージェントの指示、テスト設定、CI ワークフロー、リリース ワークフロー、テンプレート、
codemod、移行キット、その他のプロジェクト ファイル。

たとえば、リポジトリは、以下をインストールする `project-conventions` 項目を公開できます。
共有ドキュメント、エディタ設定、エージェントの指示:

```json title="registry.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry.json",
  "name": "acme-toolkit",
  "homepage": "https://github.com/acme/toolkit",
  "items": [
    {
      "name": "project-conventions",
      "type": "registry:item",
      "files": [
        {
          "path": "AGENTS.md",
          "type": "registry:file",
          "target": "~/AGENTS.md"
        },
        {
          "path": ".editorconfig",
          "type": "registry:file",
          "target": "~/.editorconfig"
        },
        {
          "path": "docs/conventions.md",
          "type": "registry:file",
          "target": "~/docs/conventions.md"
        }
      ]
    }
  ]
}
```

## コマンド

GitHub レジストリ アドレスは、他のレジストリと同じコマンドで動作します
アドレス。

GitHub レジストリの項目をリストします。

```bash
npx shadcn@latest list acme/toolkit
```

検索項目:

```bash
npx shadcn@latest search acme/toolkit --query conventions
```

アイテムを表示します:

```bash
npx shadcn@latest view acme/toolkit/project-conventions
```

アイテムをインストールします。

```bash
npx shadcn@latest add acme/toolkit/project-conventions
```

完全なガイドについては、[GitHub Registries](/docs/registry/github) のドキュメントを参照してください。
