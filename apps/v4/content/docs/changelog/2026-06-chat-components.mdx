## メッセージスクローラー

`MessageScroller` は、会話のスクロール コンテナーです。それは、
間違いやすい部分: アンカーされたターン、ストリームされた返信、保存されたスレッド
復元、先頭に追加された履歴、メッセージへのジャンプ、スクロール コントロール、および可視性
トラッキング。

`MessageScroller` は、メッセージ、AI 状態、
トランスポート、永続性、またはモデルの状態。コンテンツ レンダラーを持ち込んでください。

`MessageScroller` は、`@shadcn/react` のスタイルなしのヘッドレス コンポーネントとしても使用できます。

一度に。

新しい抽象化、更新されたスタイル、または Radix と Base UI にわたるサポート。
