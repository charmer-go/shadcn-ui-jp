---
title: 2025 年 6 月 - radix-ui の移行
description: 新しい radix-ui パッケージに移行するための新しいコマンド。
date: 2025-06-11
---

新しい `radix-ui` パッケージに移行するための新しいコマンドを追加しました。このコマンドは、すべての `@radix-ui/react-*` インポートを `radix-ui` に置き換えます。

```bash
npx shadcn@latest migrate radix
```

`ui` コンポーネント内のすべてのインポートが自動的に更新され、`radix-ui` が依存関係としてインストールされます。

```diff showLineNumbers title="components/ui/alert-dialog.tsx"
- import * as AlertDialogPrimitive from "@radix-ui/react-alert-dialog"
+ import { AlertDialog as AlertDialogPrimitive } from "radix-ui"
```

コマンドを実行した後は、必ずコンポーネントとプロジェクトをテストしてください。

**注:** 新しく追加されたコンポーネントのインポートを更新するには、移行コマンドを再度実行します。
