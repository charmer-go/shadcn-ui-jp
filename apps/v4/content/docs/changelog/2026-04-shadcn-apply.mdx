`shadcn apply` を追加したので、最初からやり直すことなく既存のプロジェクトのプリセットを切り替えることができます。

既存のプロジェクトで `npx shadcn@latest apply` を実行すると、新しいプリセットが適用され、既存のコンポーネントが再インストールされ、テーマ、色、CSS 変数、フォント、アイコンが更新されます。

```bash
npx shadcn@latest apply --preset b2D0vQ7G4
```

CLI は、プリセット URL が異なる値で生成された場合でも、既存のプロジェクトの現在のベース設定と RTL 設定を保持します。
