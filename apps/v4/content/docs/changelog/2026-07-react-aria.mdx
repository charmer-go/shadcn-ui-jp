## 新着情報

- **一流の React Aria ベース** - どこでも React Aria を選択できます
CLI、プリセット、shadcn/create を含むベース UI または Radix。
- **完全なコンポーネント ドキュメント** - React Aria コンポーネントには専用のドキュメントがあります
インストール、使用法、構成、例、および API リファレンスのセクション。
- **全 8 つのスタイル** - React Aria を Vega、Nova、Maia、Lyra、Mira、Luma、
レアとかセラとか。
- **ベース固有の出力** - React Aria の状態セレクターと依存関係は次のとおりです。
Aria レジストリにスコープされます。既存の Base UI および Radix コンポーネントは、
変わらない。

## React Aria から始めましょう

プロジェクトを初期化するときは、`aria` ベースを使用します。

```bash
npx shadcn@latest init --base aria
```

または、[shadcn/create](/create?base=aria) で **React Aria** を選択します。プロジェクトが完了したら
が初期化されると、`shadcn add` はそれぞれの React Aria 実装をインストールします。
成分。

Base UI はデフォルトのままで、Radix は引き続き完全にサポートされます。既存
プロジェクトは現在のベースに留まります。
