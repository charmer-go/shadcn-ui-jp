Luma は、次のアプリの新しい基盤です。同じ shadcn/ui ワークフローを維持しながら、コンポーネントの表面をより柔らかくし、間隔をあけ、より穏やかな視覚的なリズムを与えます。

他の新しいスタイルと同様に、Luma はテーマを超えています。コンポーネントのジオメトリ、間隔、感触が変更されるため、アプリは異なる視覚的なベースラインから開始されます。

現在、[shadcn/create](/create) で Radix UI と Base UI の両方で利用可能です。
