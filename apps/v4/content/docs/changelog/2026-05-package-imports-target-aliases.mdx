`shadcn@4.7.0` の `files.target` でのパッケージのインポートとエイリアスのサポートを追加しました。

## パッケージのインポート

`shadcn` CLI は、コンポーネントのインストール用に `package.json#imports` をサポートするようになりました。
インポートの書き換え、およびサードパーティのレジストリの解決。プライベートでも使えます
`#...` のみに依存するのではなく、`package.json` からエイリアスをインポートします。
`tsconfig.json`の`compilerOptions.paths`。

```json title="package.json" showLineNumbers
{
  "imports": {
    "#components/*": "./src/components/*.tsx",
    "#lib/*": "./src/lib/*.ts",
    "#hooks/*": "./src/hooks/*.ts"
  }
}
```

次に、`components.json` で同じルートを使用します。

```json title="components.json" showLineNumbers
{
  "aliases": {
    "components": "#components",
    "ui": "#components/ui",
    "lib": "#lib",
    "hooks": "#hooks",
    "utils": "#lib/utils"
  }
}
```

これは、アプリのローカル ファイルがパッケージ インポートを使用するモノリポジトリでも機能します。
共有 UI ファイルは、ワークスペース パッケージのエクスポートからインポートされます。

セットアップの詳細については、[パッケージ インポート ガイド](/docs/package-imports) を参照してください。

## ターゲットのエイリアス

レジストリ項目は、`files[].target` のターゲット エイリアスを使用してファイルをインストールできるようになりました
ユーザーが構成した shadcn ディレクトリの下にあります。たとえば、次のレジストリ項目は、`ui/ai` ディレクトリに `prompt-input.tsx` ファイルをインストールします。

```json title="example.json" showLineNumbers
{
  "files": [
    {
      "path": "registry/default/ai/prompt-input.tsx",
      "type": "registry:ui",
      "target": "@ui/ai/prompt-input.tsx"
    }
  ]
}
```

[レジストリの例](/docs/registry/examples#target-placeholders) を参照してください。
さらに詳しく。
