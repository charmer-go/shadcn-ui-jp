shadcn/cli のバージョン 4 をリリースします。より高機能に、より使いやすく。あなたとあなたのコーディングエージェントのために構築されています。ここにはすべてが新しいものです。

## shadcn/スキル

shadcn/skills は、コンポーネントとレジストリを正しく操作するために必要なコンテキストをコーディング エージェントに提供します。 Radix と Base UI プリミティブの両方、更新された API、コンポーネント パターン、レジストリ ワークフローについて説明します。このスキルは、shadcn CLI の使用方法、いつ呼び出すか、どのフラグを渡すかについても認識しています。エージェントは間違いを減らし、実際に設計システムと一致するコードを生成します。

エージェントに次のような質問をすることができます。

- 「新しい vite モノレポを作成する」
- 「tailark からヒーローを見つけて、ホームページに追加し、react-bits のアニメーションを使用してテキストをアニメーション化します。」
- 「@clark からサインイン ページをインストールして構成します」

```bash
npx skills add shadcn/ui
```

## --preset の導入

プリセットは、デザイン システム構成全体を短いコードにパックします。色、テーマ、アイコン ライブラリ、フォント、半径。 1 つの文字列にすべてが含まれています。

[shadcn/create](/create) でプリセットをビルドし、ライブでプレビューし、準備ができたらコードを取得します。

```bash
npx shadcn@latest init --preset a1Dg5eFl
```

これを使用して、カスタム構成からプロジェクトをスキャフォールディングしたり、チームと共有したり、レジストリで公開したりできます。プロンプトにそれをドロップすると、エージェントがどこから始めればよいかわかるようになります。 Claude、Codex、v0、Replit 全体で使用します。プリセットを持ち歩きましょう。

## プリセットの切り替え

新しいアプリに取り組んでいるときは、気に入ったものを見つけるまでに数回試行する必要があるため、プリセットの切り替えが非常に簡単になりました。アプリで `init --preset` を実行すると、CLI がコンポーネントを含むすべての再構成を処理します。

```bash
npx shadcn@latest init --preset ad3qkJ7
```

## スキル + プリセット

エージェントはプリセットの使用方法を知っています。プロジェクトの足場を築き、設計システムを切り替え、何か新しいことに挑戦してください。

- 「--preset adtk27v を使用して新しい次のアプリを作成します」
- 「--preset adtk27v を試してみましょう」

## 新しい shadcn/作成

カスタム プリセットの構築を支援するために、[shadcn/create](/create) を再構築しました。プリセットのプレビューに使用できる UI コンポーネントのライブラリが含まれるようになりました。構築を開始する前に、色、フォント、半径が実際のコンポーネントにどのように適用されるかを確認してください。

## 新しい --dry-run、--diff、および --view フラグ

何かが書き込まれる前に、レジストリがプロジェクトに何を追加するかを調べてください。ペイロードを自分で確認するか、コーディング エージェントにパイプして再確認してください。

```bash
npx shadcn@latest add button --dry-run
npx shadcn@latest add button --diff
npx shadcn@latest add button --view
```

## プリミティブの更新

`--diff` フラグを使用して、レジストリの更新を確認できます。または、エージェントに「@shadcn からの更新を確認して、ローカルの変更とマージしてください」と依頼してください。

```bash
npx shadcn@latest add button --diff
```

## shadcn init --テンプレート

`shadcn init` は、Next.js、Vite、Laravel、React Router、Astro、TanStack Start の完全なプロジェクト テンプレートをスキャフォールディングするようになりました。 Next.js と Vite にはダーク モードが含まれています。

```bash
npx shadcn@latest init

Select a template › - Use arrow-keys. Return to submit.
❯ Next.js
  Vite
  TanStack Start
  React Router
  Astro
  Laravel
```

`--monorepo` を使用してモノリポジトリを設定します。

```bash
npx shadcn@latest init -t next --monorepo
```

## shadcn init --base

プリミティブを選択します。 Radix または Base UI でプロジェクトを開始するには、`--base` を使用します。

```bash
npx shadcn@latest init --base radix
```

## シャドン情報

`info` コマンドにより、フレームワーク、バージョン、CSS 変数、インストールされているコンポーネント、各コンポーネントのドキュメントと例の場所などの全体像が表示されるようになりました。コーディング エージェントにプロジェクトで作業するために必要なコンテキストを提供するのに最適です。

```bash
npx shadcn@latest info
```

## shadcn ドキュメント

CLI から直接、UI コンポーネントのドキュメント、コード、サンプルを入手できます。プリミティブを正しく使用するためのコンテキストをコーディング エージェントに提供します。

```bash
npx shadcn@latest docs combobox

combobox
  - docs      https://ui.shadcn.com/docs/components/radix/combobox
  - examples  https://ui.shadcn.com/code/apps/v4/registry/bases/radix/examples/combobox-example.tsx
  - api       https://base-ui.com/react/components/combobox
```

## レジストリ:ベースとレジストリ:フォント

レジストリは、`registry:base` を使用して、設計システム全体を単一のペイロードとして配布できるようになりました。コンポーネント、依存関係、CSS 変数、フォント、構成。 1 回のインストールですべてがセットアップされます。

フォントは現在、第一級のレジストリ タイプです。コンポーネントをインストールするのと同じ方法で、それらをインストールして構成します。

```json title="font-inter.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry-item.json",
  "name": "font-inter",
  "type": "registry:font",
  "font": {
    "family": "'Inter Variable', sans-serif",
    "provider": "google",
    "import": "Inter",
    "variable": "--font-sans",
    "subsets": ["latin"]
  }
}
```

```bash
npx shadcn@latest add font-inter
```
