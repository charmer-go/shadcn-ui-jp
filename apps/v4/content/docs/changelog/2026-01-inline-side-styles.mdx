`inline-start` および `inline-end` サイド値をサポートするために、ベース UI コンポーネントのスタイルを更新しました。次のコンポーネントがこれらの値をサポートするようになりました。

- ツールチップ
- ポップオーバー
- コンボボックス
- コンテキストメニュー
- ドロップダウンメニュー
- ホバーカード
- メニューバー
- 選択

### 何が変わったのか

論理側の値を処理するために新しい Tailwind クラスを追加しました。

```diff
<PopoverPrimitive.Popup
  className={cn(
    "... data-[side=bottom]:slide-in-from-top-2
    data-[side=left]:slide-in-from-right-2
    data-[side=right]:slide-in-from-left-2
    data-[side=top]:slide-in-from-bottom-2
+   data-[side=inline-start]:slide-in-from-right-2
+   data-[side=inline-end]:slide-in-from-left-2 ...",
    className
  )}
/>
```

### 使用法

```tsx
<Popover>
  <PopoverTrigger>Open</PopoverTrigger>
  <PopoverContent side="inline-start">
    {/* Opens on the left in LTR, right in RTL */}
  </PopoverContent>
</Popover>
```
