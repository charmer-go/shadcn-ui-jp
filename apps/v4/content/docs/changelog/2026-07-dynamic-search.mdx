**レジストリはサーバー側で検索を処理できるようになりました。**

`shadcn search` を実行すると、CLI は検索パラメータを
レジストリをクエリパラメータとして使用します。

```txt
GET /r/registry.json?q=button&limit=50&offset=0
```

`pagination` オブジェクトを使用して一致する項目を返します。CLI は
結果はそのまま。これにより、大規模なレジストリの検索が高速化され、ダウンロードが不要になります。
完全なカタログを検索してください。

```json title="registry.json?q=button&limit=1"
{
  "name": "acme",
  "homepage": "https://acme.com",
  "items": [
    {
      "name": "button",
      "type": "registry:ui",
      "description": "A button component."
    }
  ],
  "pagination": {
    "total": 12,
    "offset": 0,
    "limit": 1,
    "hasMore": true
  }
}
```

動的検索はオプトインです。静的レジストリはクエリ パラメータを無視し、保持します。
何も変更せずに動作します。

詳細については、[動的検索](/docs/registry/dynamic-search) ドキュメントを参照してください。
