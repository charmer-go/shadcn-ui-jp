`new-york` スタイルは、個別の `@radix-ui/react-*` パッケージではなく、統合された `radix-ui` パッケージを使用するようになりました。

### 何が変わったのか

`new-york` スタイルを使用してコンポーネントを追加すると、個別のパッケージではなく `radix-ui` からインポートされるようになります。

```diff title="components/ui/dialog.tsx"
- import * as DialogPrimitive from "@radix-ui/react-dialog"
+ import { Dialog as DialogPrimitive } from "radix-ui"
```

これにより、複数の `@radix-ui/react-*` パッケージではなく、単一の `radix-ui` 依存関係を持つ、よりクリーンな `package.json` が作成されます。

### 既存のプロジェクトの移行

`new-york` スタイルを使用する既存のプロジェクトがある場合は、移行コマンドを使用して新しい `radix-ui` パッケージに移行できます。

```bash
npx shadcn@latest migrate radix
```

これにより、UI コンポーネント内のすべてのインポートが更新され、`radix-ui` が依存関係に追加されます。

`ui` ディレクトリの外にコンポーネントを移行するには、`path` 引数を使用します。

```bash
npx shadcn@latest migrate radix src/components/custom
```

完了したら、未使用の `@radix-ui/react-*` パッケージを `package.json` から削除できます。

詳細については、[migrate radix ドキュメント](/docs/cli#merge-radix) を参照してください。
