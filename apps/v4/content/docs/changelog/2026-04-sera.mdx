Sera は、印刷デザインの原則に基づいて構築された、タイポグラフィー優先のスタイルです。セリフの見出しとサンセリフの本文を組み合わせ、四角い角、大文字のトラッキング、下線付きのコントロールを使用して、アプリに編集的な雰囲気を作り出します。

他の新しいスタイルと同様に、Sera はテーマを超えています。コンポーネントのジオメトリ、間隔、感触が変更されるため、アプリは異なる視覚的なベースラインから開始されます。

現在、[shadcn/create](/create) で Radix UI と Base UI の両方で利用可能です。
