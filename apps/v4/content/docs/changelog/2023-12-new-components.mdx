新しいコンポーネントを shadcn/ui に追加し、CLI に多くの改善を加えました。

新機能の概要を以下に示します。

- [**Carousel**](#carousel) - モーション、スワイプジェスチャ、キーボードサポートを備えたカルーセルコンポーネント。
- [**Drawer**](#drawer) - モバイルで見る栄えの良いドロワー コンポーネント。
- [**Pagination**](#pagination) - ページ ナビゲーション、前および次のボタンを備えたページネーション コンポーネント。
- [**Resizable**](#resizable) - サイズ変更可能なパネル グループとレイアウトを構築するためのサイズ変更可能なコンポーネント。
- [**Sonner**](#sonner) - 必要となる最後のトーストコンポーネント。
- [**CLI アップデート**](#cli-updates) - カスタム **Tailwind プレフィックス** および `tailwind.config.ts` のサポート。

### カルーセル

モーション、スワイプ ジェスチャ、キーボード サポートを備えたフル機能のカルーセル コンポーネントを追加しました。 [Embla Carousel](https://www.embla-carousel.com) の上に構築されています。

無限ループ、自動再生、垂直方向などをサポートしています。

この `<Resizable />` コンポーネントを使用して、サイズ変更可能なパネル グループとレイアウトを構築します。

### CLI の更新

これは最も要望の多かった機能の 1 つです。 カスタム Tailwind プレフィックスを構成できるようになり、コンポーネントを追加するときに cli がユーティリティ クラスに自動的にプレフィックスを付けます。

これは、Docusaurus、Nextra などのみんなのプロジェクトに shadcn/ui コンポーネントを簡単に追加できることを意味します。

```tsx /tw-/
<AlertDialog className="tw-grid tw-gap-4 tw-border tw-bg-background tw-shadow-lg" />
```

`cn`、`cva`、および CSS 変数で動作します。

cli は `tailwind.config.ts` を検出し、TypeScript バージョンの構成を追加できるようになりました。
