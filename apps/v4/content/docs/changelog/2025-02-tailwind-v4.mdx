Tailwind v4 と React 19 の最初のプレビューを出荷しました。すぐにお試しいただけます。今日から使い始めることができます。

新着情報：

- CLI は、Tailwind v4 を使用してプロジェクトを初期化できました。
- 新しい @theme ディレクティブと @theme インライン オプションを完全にサポートします。
- すべてのコンポーネントが Tailwind v4 および React 19 用に更新されました。
- forwardRefs を削除、型を調整しました。
- すべてのプリミティブにスタイル設定用のデータスロット属性が追加されました。
- コンポーネントのスタイルを修正し、クリーンアップしました。
- Sonnerを優先して、トーストコンポーネントを廃止します。
- ボタンはデフォルトのカーソルを使用するようになりました。
- もったいないのスタイルは廃止予定です。新しいプロジェクトではnew-yorkを使用します。
- HSL カラーが OKLCH に変換されるようになりました。

については、[ドキュメント](詳細/docs/tailwind-v4) を参照してください。
