このコンポーネントのラウンドでは、私たちが毎日構築しているもの、何度も再構築している退屈なものを検討し、実際に使用できる再利用可能な抽象化を作成しました。

**これらのコンポーネントは、Radix、Base UI、React Aria など、あらゆるコンポーネント ライブラリで動作します。コピーしてプロジェクトに貼り付けます。**

- [スピナー](#spinner): 読み込み状態を示すインジケーターです。
- [Kbd](#kbd): キーボードのキーまたはキーのグループを表示します。
- [ボタングループ](#button-group): アクションおよび分割ボタンのボタンのグループ。
- [入力グループ](#input-group): アイコン、ボタン、ラベルなどを使用して入力します。
- [フィールド](#field): 1 つのコンポーネント。すべてのフォーム。
- [アイテム](#item): アイテムやカードなどのリストを表示します。
- [Empty](#empty): 空の状態に使用します。

### スピナー

それでは、最も簡単なもの、**Spinner** と **Kbd** から始めましょう。かなり基本的なものです。私たちは皆、彼らが何をするのか知っています。


### KBD

Kbd はキーボードのキーをレンダリングするコンポーネントです。

```tsx
import { Kbd, KbdGroup } from "@/components/ui/kbd"
```

```tsx
<Kbd>Ctrl</Kbd>
```

`KbdGroup` を使用して、キーボードのキーをグループ化します。

```tsx showLineNumbers
<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>B</Kbd>
</KbdGroup>
```

<ComponentPreview styleName="new-york-v4"
  name="kbd-demo"

/>

これをボタン、ツールヒント、入力グループなどに追加できます。

### ボタングループ

これについては、ボタン グループについて多くのリクエストがありました。これは、関連するボタンを一貫したスタイルでグループ化するコンテナです。アクショングループ、分割ボタンなどに最適です。

<ComponentPreview styleName="new-york-v4"
  name="button-group-demo"

/>

コードは次のとおりです。

```tsx
import { ButtonGroup } from "@/components/ui/button-group"
```

```tsx showLineNumbers
<ButtonGroup>
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

ボタン グループをネストして、間隔をあけてより複雑なレイアウトを作成できます。

```tsx showLineNumbers
<ButtonGroup>
  <ButtonGroup>
    <Button>Button 1</Button>
    <Button>Button 2</Button>
  </ButtonGroup>
  <ButtonGroup>
    <Button>Button 3</Button>
    <Button>Button 4</Button>
  </ButtonGroup>
</ButtonGroup>
```

`ButtonGroupSeparator` を使用して分割ボタンを作成します。古典的なドロップダウン パターン。

<ComponentPreview styleName="new-york-v4"
  name="button-group-dropdown"

/>

これを使用して、接頭辞または接尾辞のボタンやテキストを入力に追加することもできます。

<ComponentPreview styleName="new-york-v4"
  name="button-group-select"

/>

```tsx showLineNumbers
<ButtonGroup>
  <ButtonGroupText>Prefix</ButtonGroupText>
  <Input placeholder="Type something here..." />
  <Button>Button</Button>
</ButtonGroup>
```

### 入力グループ

入力グループを使用すると、アイコンやボタンなどを入力に追加できます。ご存知のとおり、入力周りに常に必要となるこれらすべての小さな部分です。

```tsx
import {
  InputGroup,
  InputGroupAddon,
  InputGroupInput,
} from "@/components/ui/input-group"
```

```tsx showLineNumbers
<InputGroup>
  <InputGroupInput placeholder="Search..." />
```

### 空の

さて、最後のもの: **空**。これを使用して、アプリ内に空の状態を表示します。

```tsx
import {
  Empty,
  EmptyContent,
  EmptyDescription,
  EmptyMedia,
  EmptyTitle,
} from "@/components/ui/empty"
```

使い方は次のとおりです。

```tsx showLineNumbers

  <EmptyMedia variant="icon">

  <EmptyTitle>No messages</EmptyTitle>
  <EmptyDescription>You don't have any messages yet.</EmptyDescription>
  <EmptyContent>
```
