このプロジェクトとコンポーネントは TypeScript で書かれています。 **プロジェクトにも TypeScript を使用することをお勧めします**。

ただし、コンポーネントの JavaScript バージョンが提供されており、[cli](/docs/cli) から入手できます。

```txt
Would you like to use TypeScript (recommended)? no
```

TypeScript をオプトアウトするには、`components.json` ファイルで `tsx` フラグを使用します。

```json {10} title="components.json" showLineNumbers
{
  "style": "default",
  "tailwind": {
    "config": "tailwind.config.js",
    "css": "src/app/globals.css",
    "baseColor": "zinc",
    "cssVariables": true
  },
  "rsc": false,
  "tsx": false,
  "aliases": {
    "utils": "~/lib/utils",
    "components": "~/components"
  }
}
```

インポートエイリアスを構成するには、次の `jsconfig.json` を使用できます。

```json {4} title="jsconfig.json" showLineNumbers
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```
