このリリースでは、レジストリ作成者向けに 2 つの更新が追加されています。

- `include` 複数の `registry.json` から大規模なソース レジストリを構成する場合
ファイル。
- 公開前にソース レジストリをチェックするための `shadcn registry validate`。

これにより、ソース レジストリと動的レジストリを維持する必要がなく、簡単に保守できるようになります。
1 つの大きな `registry.json` ファイルを手動で作成します。

レジストリ作成者は、複数のソース レジストリにまたがる大規模なソース レジストリを整理できるようになりました。
`registry.json` ファイルを作成し、`shadcn build` で作成します。

```txt /registry.json/
registry.json
components
└── ui
    ├── button.tsx
    ├── input.tsx
    └── registry.json
hooks
├── registry.json
├── use-media-query.ts
└── use-toggle.ts
```

{/* よりきれいな無視 */}
```json title="registry.json" showLineNumbers {6-7}
{
  "$schema": "https://ui.shadcn.com/schema/registry.json",
  "name": "acme",
  "homepage": "https://acme.com",
  "include": [
    "components/ui/registry.json",
    "hooks/registry.json"
  ]
}
```

付属の `registry.json` ファイルは、合成に有効なレジストリ ファイルであり、
`name` および `homepage` は省略します。ルート `registry.json` のみが定義する必要があります。
レジストリのメタデータ。

```json title="components/ui/registry.json" showLineNumbers
{
  "$schema": "https://ui.shadcn.com/schema/registry.json",
  "items": [
    {
      "name": "button",
      "type": "registry:ui",
      "files": [
        {
          "path": "button.tsx",
          "type": "registry:ui"
        }
      ]
    }
  ]
}
```

## ビルド出力

`shadcn build` は、含まれているレジストリを解決し、フラット化されたレジストリを書き込みます
`include` なしの `registry.json`。アイテムファイルのパスはルートから保存されます
レジストリにあるため、`components/ui/registry.json` で宣言されたファイルは次のように書き込まれます。
構築されたレジストリ項目の `components/ui/button.tsx`。

## レジストリを検証する

ソース レジストリを公開または提供する前に検証できるようになりました。

```bash
npx shadcn registry validate
```

検証はソース レジストリ ファイルに対して直接実行されます。その必要はありません
最初に `shadcn build` を実行します。

このコマンドは、ルート `registry.json`、含まれるレジストリ ファイル、項目をチェックします。
スキーマ エラー、項目名の重複、インクルード ルール、およびローカル項目ファイル パス。
検証では、1 回の実行で検出できるすべての対処可能なエラーが報告されます。

## レジストリ ローダー

`shadcn/registry` パッケージは、`loadRegistry` と
動的レジストリ ルートの場合は `loadRegistryItem`。

```ts title="app/r/registry.json/route.ts" showLineNumbers
import { loadRegistry } from "shadcn/registry"

export async function GET() {
  const registry = await loadRegistry()

  return Response.json(registry)
}
```

```ts title="app/r/[name].json/route.ts" showLineNumbers
import { loadRegistryItem } from "shadcn/registry"

export async function GET(
  _: Request,
  { params }: { params: Promise<{ name: string }> }
) {
  const { name } = await params
  const item = await loadRegistryItem(name)

  return Response.json(item)
}
```
