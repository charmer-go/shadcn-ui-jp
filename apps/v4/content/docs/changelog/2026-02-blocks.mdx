すべての [ブロック](/ブロック) が基数 UI とベース UI の両方で使用できるようになりました。

- **両方のライブラリのすべてのブロック** - ログイン、サインアップ、サイドバー、ダッシュボードのブロックを含むすべてのブロックが、Radix と Base UI の両方のバリアントで使用できるようになりました。
- **同じ CLI ワークフロー** - `npx shadcn add` を実行すると、CLI はプロジェクト構成に基づいて正しいブロック バリアントをプルします。

すでに `npx shadcn create` を使用してプロジェクトを設定している場合、ブロックは選択したライブラリを自動的に使用します。追加の構成は必要ありません。

```bash
npx shadcn@latest add login-01
```

[blocks](/blocks) ページで完全なコレクションを参照してください。
