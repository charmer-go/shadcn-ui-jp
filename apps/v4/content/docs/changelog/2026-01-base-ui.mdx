12 月に `npx shadcn create` をリリースしたとき、コンポーネント ライブラリとして Radix と Base UI のどちらかを選択できる機能を導入しました。現在、すべての Base UI コンポーネントの完全なドキュメントをフォローアップしています。

### 新着情報

- **完全なベース UI ドキュメント** - すべてのコンポーネントに、使用法、小道具、例をカバーするベース UI 専用のドキュメントが含まれるようになりました。
- **再構築されたサンプル** - すべてのコンポーネントのサンプルは、Radix UI と Base UI の両方に対して再構築されています。それらを切り替えて実装の違いを確認してください。
- **並べて比較** - このドキュメントを使用すると、両方のライブラリ間でコンポーネントがどのように動作するかを簡単に比較できます。

### 同じ抽象化、異なるプリミティブ

目標は変わりません。どのプリミティブ ライブラリを選択しても、一貫した API を提供します。コンポーネントは同じように見え、同じように動作します。基礎となる実装のみが変更されます。

```tsx
// Works the same whether you're using Radix or Base UI.
import { Dialog, DialogContent, DialogTrigger } from "@/components/ui/dialog"
```

新しいプロジェクトを開始する場合は、`npx shadcn create` を実行して、好みのライブラリを選択します。残りは CLI が処理します。
