マルチステップの質問フロー用の新しいコンポーネント。エージェントの説明に使用します
プロンプト、オンボーディング、アンケート、受付フォーム、構成。

## 特徴

- ネイティブ無線とチェックボックスによる単一および複数の選択。
- 固定の選択肢と自由形式の回答。
- オプションの質問を明示的にスキップします。
- 前へ、次へ、送信、およびカスタム進行状況コントロール。
- 必須のカスタム検証。
- 制御されたナビゲーション、保存されたデフォルト、および条件付きの質問。
- オプションの文字または数字のショートカットを使用したキーボード ナビゲーション。
- ネイティブ フォームのシリアル化とサーバーでレンダリングされたコレクション状態。
- スタンドアロン、カード、ダイアログの構成。

## インストール

```bash
npx shadcn@latest add questionnaire
```
