より多くの機能をサポートするためにレジストリ スキーマを更新しています。

コードをフラットなJSONファイルとして定義し、CLI経由で配布します。

- カスタム スタイル: 独自のデザイン システム、コンポーネント、トークンを導入します。
- サードパーティのレジストリおよび LLM のコンポーネントを拡張、上書き、組み合わせて一致させる
- テーマ、CSS 変数、フック、アニメーション、Tailwind レイヤーとユーティリティをインストールします
