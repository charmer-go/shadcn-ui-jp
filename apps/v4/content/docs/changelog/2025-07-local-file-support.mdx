date: 2025-07-07
---

shadcn CLI はローカル ファイルをサポートするようになりました。プロジェクトを初期設定、ローカル JSON ファイルからコンポーネント、テーマ、フック、ユーティリティなどを追加します。

```bash
# Initialize a project from a local file
npx shadcn init ./template.json

# Add a component from a local file
npx shadcn add ./block.json
```

この機能により、強力な新しいワークフローが可能になります。

- **ゼロセットアップ** - リモート レジストリは不要
- **開発の高速化** - 公開前にレジストリ項目をローカルでテストします
- **エージェントと MCP のワークフローの強化** - レジストリ項目をローカルで生成して実行
- **プライベート コンポーネント** - 独自のコンポーネントをローカルかつプライベートに保ちます。
