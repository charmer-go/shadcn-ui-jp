**GitHub レジストリがプライベート リポジトリで動作するようになりました。**

6 月に、あらゆるパブリック GitHub リポジトリを
レジストリ。チームは内部コードにも同じこと、つまりデザインを求めました。
公開すべきではないシステム、機能キット、エージェントのルールおよび規約。

プライベート リポジトリからインストールできるようになりました。リポジトリを読み取れる場合は、
CLI はそこからインストールできます。

```bash
npx shadcn@latest add acme/internal-toolkit/auth-kit
```

## ゼロ構成

GitHub CLI にログインしている場合は、何も設定する必要はありません。

```bash
gh auth login
```

リポジトリが公開されていない場合、CLI は `gh` を使用してリポジトリを読み取ります。
保存されている認証情報。トークンは GitHub CLI 内に残ります。それは決して入りません
shadcn プロセス。

```txt
✔ Using gh credentials.
✔ Checking registry.
✔ Created 1 file:
  - lib/auth.ts
```

## CI サポート

GitHub CLI がインストールされていない場合は、`GH_TOKEN` または `GITHUB_TOKEN` を設定します。

```bash
GH_TOKEN=github_pat_xxx npx shadcn@latest add acme/internal-toolkit/auth-kit
```

リポジトリをスコープとするきめ細かい個人アクセス トークンを使用することをお勧めします。
**コンテンツ: 読み取り専用** アクセス。

## すべてのコマンドで動作します

プライベート リポジトリは、パブリック GitHub レジストリと同じコマンドで動作します。

```bash
npx shadcn@latest list acme/internal-toolkit
```

```bash
npx shadcn@latest search acme/internal-toolkit --query auth
```

```bash
npx shadcn@latest view acme/internal-toolkit/auth-kit
```

```bash
npx shadcn@latest registry validate acme/internal-toolkit
```

## 仕組み

- パブリック リポジトリは、以前とまったく同様に匿名で読み取られます。資格情報がありません
が使用され、GitHub CLI は決して呼び出されません。
- CLI は最初に匿名アクセスを試行し、認証情報が使用されない場合にのみ使用します。
リポジトリは公開されていません。
- プライベート ファイルは GitHub のコンテンツ API を通じて読み取られ、解決されたファイルに固定されます。
SHAをコミットします。
- `GH_TOKEN` からのトークンは、`api.github.com` にのみ送信されます。保存された GitHub
CLI 資格情報は、CLI ではなく、`gh` によって読み取られます。

を参照してください。
