## アプローチ

このフォームでは、スタイルを持たないスキーマファーストのフォーム処理に Formisch を利用します。**マークアップとスタイルを完全に柔軟に制御できる** `<Field />` コンポーネントでフォームを構築します。

- フォーム状態の管理に Formisch の `useForm` フックを使います。
- ネイティブの `<form>` 要素を送信処理付きでラップする `<Form />` コンポーネントを使います。
- 制御された入力に `<Field />` の render prop コンポーネントを使います。
- [Valibot](https://valibot.dev) でスキーマ検証を行います。
- スキーマから型安全なフィールド パスを推論します。

## フォーム メソッド

Formisch はフォーム オブジェクトのメソッドではなく、**トップレベル関数**としてフォーム操作を公開します。必要なものだけをインポートします。

```ts
import { getInput, insert, reset, submit } from "@formisch/react"
```

すべてのメソッドは同じシグネチャに従います。**最初のパラメーターは常にフォーム ストア**で、**2 番目のパラメーター（必要な場合）は常に設定オブジェクト**です。

```ts
// Read a field value
const email = getInput(form, { path: ["email"] })

// Reset the form with new initial values
reset(form, { initialInput: { email: "", password: "" } })

// Move an item in a field array
move(form, { path: ["items"], from: 0, to: 3 })
```

この設計により、すべてのメソッドで API の柔軟性と一貫性が保たれます。このガイド全体で、状態の読み取り（`getInput`、`getErrors`）、状態の書き込み（`setInput`、`setErrors`）、フォーム制御（`submit`、`validate`、`focus`）、配列操作（`insert`、`remove`、`move`、`swap`、`replace`）に同じ `(form, config)` 形式を使います。詳しくは[メソッドの完全なリファレンス](https://formisch.dev/react/guides/form-methods)を参照してください。

## 構成

Formisch の `<Field />` コンポーネントと shadcn の `<Field />` コンポーネントを使った、基本的なフォームの例です。

```tsx showLineNumbers {3-21}
<Form of={form} onSubmit={handleSubmit}>
  <FieldGroup>
    <FormischField of={form} path={["title"]}>
      {(field) => (
        <Field data-invalid={field.errors !== null}>
          <FieldLabel htmlFor="form-title">Bug Title</FieldLabel>
          <Input
            {...field.props}
            id="form-title"
            value={field.input}
            aria-invalid={field.errors !== null}
            placeholder="Login button not working on mobile"
            autoComplete="off"
          />
          <FieldDescription>
            Provide a concise title for your bug report.
          </FieldDescription>
          {field.errors && (
            <FieldError errors={field.errors.map((message) => ({ message }))} />
          )}
        </Field>
      )}
    </FormischField>
  </FieldGroup>
</Form>
```

<Callout icon={<InfoIcon />}>
  **注:** Formisch には独自の `Field` コンポーネントがあります。shadcn の `Field` との名前の衝突を避けるため、以下の例では Formisch 版を `FormischField` としてインポートし、shadcn の `Field` は元の名前を維持しています。自分のコードではどちら側にも別名を付けられますが、一貫して使用してください。

## フォーム

### フォーム スキーマを作成する

Valibot スキーマでフォームの形を定義することから始めます。Formisch はこのスキーマからすべての入力型と出力型を直接推論します。

```tsx showLineNumbers title="form.tsx"
import * as v from "valibot"

const FormSchema = v.object({
  title: v.pipe(
    v.string(),
    v.minLength(5, "Bug title must be at least 5 characters."),
    v.maxLength(32, "Bug title must be at most 32 characters.")
  ),
  description: v.pipe(
    v.string(),
    v.minLength(20, "Description must be at least 20 characters."),
    v.maxLength(100, "Description must be at most 100 characters.")
  ),
})
```

### フォームを設定する

次に、Formisch の `useForm` フックを使ってフォーム インスタンスを作成します。スキーマは `useForm` に直接渡すため、resolver の手順はありません。

```tsx showLineNumbers title="form.tsx" {1-2,21-25}
import { Form, Field as FormischField, useForm } from "@formisch/react"
import type { SubmitHandler } from "@formisch/react"
import * as v from "valibot"

const FormSchema = v.object({
  title: v.pipe(
    v.string(),
    v.minLength(5, "Bug title must be at least 5 characters."),
    v.maxLength(32, "Bug title must be at most 32 characters.")
  ),
  description: v.pipe(
    v.string(),
    v.minLength(20, "Description must be at least 20 characters."),
    v.maxLength(100, "Description must be at most 100 characters.")
  ),
})

export function BugReportForm() {
  const form = useForm({
    schema: FormSchema,
    initialInput: {
      title: "",
      description: "",
    },
  })

  const handleSubmit: SubmitHandler<typeof FormSchema> = (output) => {
    // Do something with the validated form values.
    console.log(output)
  }

  return (
    <Form of={form} onSubmit={handleSubmit}>
      {/* ... */}
      {/* Build the form here */}
      {/* ... */}
    </Form>
  )
}
```

`<Form />` コンポーネントはネイティブの `<form>` 要素をラップします。`event.preventDefault()` を呼び出して検証を実行し、データが有効な場合だけ `onSubmit` を呼び出します。受け取る `output` はスキーマから完全に型付けされます。

### フォームを構築する

これで、Formisch の `<Field />` コンポーネントと shadcn の `<Field />` コンポーネントを使ってフォームを構築できます。

## バリデーション

### クライアント側検証

Formisch は `useForm` に渡した Valibot スキーマを使ってフォーム データを検証します。resolver はありません。実行時検証と静的型の両方で、スキーマが唯一の信頼できる情報源になります。

```tsx showLineNumbers title="form.tsx" {1,3-6,11}
import { useForm } from "@formisch/react"

const FormSchema = v.object({
  title: v.string(),
  description: v.optional(v.string()),
})

export function ExampleForm() {
  const form = useForm({
    schema: FormSchema,
    initialInput: {
      title: "",
      description: "",
    },
  })
}
```

### 検証モード

Formisch は**最初の**検証と**その後の**検証を分けます。`useForm` の `validate` と `revalidate` オプションで設定します。

```tsx showLineNumbers title="form.tsx" {3-4}
const form = useForm({
  schema: FormSchema,
  validate: "blur",
  revalidate: "input",
})
```

| Option       | Value       | Description                                                     |
| ------------ | ----------- | --------------------------------------------------------------- |
| `validate`   | `"submit"`  | フォーム送信時に検証します（既定）。 |
| `validate`   | `"blur"`    | フィールドがフォーカスを失ったときに検証します。 |
| `validate`   | `"input"`   | 入力が変更されるたびに検証します。 |
| `validate`   | `"initial"` | フォーム作成時にすぐ検証します。 |
| `revalidate` | `"input"`   | 初回検証後、入力が変更されるたびに再検証します（既定）。 |
| `revalidate` | `"blur"`    | 初回検証後、フォーカスを失ったときに再検証します。 |
| `revalidate` | `"submit"`  | フォーム送信時だけ再検証します。 |

## エラーの表示

`<FieldError />` を使ってフィールドの隣にエラーを表示します。Formisch はエラーを文字列配列として返すため、`<FieldError />` が受け取る形にマッピングします。スタイルとアクセシビリティのために次を行います。

- `<Field />` コンポーネントに `data-invalid` prop を追加します。
- `<Input />`、`<SelectTrigger />`、`<Checkbox />` などのフォーム コントロールに `aria-invalid` prop を追加します。

```tsx showLineNumbers title="form.tsx" {3,10,12-14}
<FormischField of={form} path={["email"]}>
  {(field) => (
    <Field data-invalid={field.errors !== null}>
      <FieldLabel htmlFor="form-email">Email</FieldLabel>
      <Input
        {...field.props}
        id="form-email"
        value={field.input}
        type="email"
        aria-invalid={field.errors !== null}
      />
      {field.errors && (
        <FieldError errors={field.errors.map((message) => ({ message }))} />
      )}
    </Field>
  )}
</FormischField>
```

## 異なるフィールド型を扱う

Formisch では、フィールドを要素にバインドする方法が 2 つあります。

- **ネイティブ HTML 要素**（`<Input />` や `<Textarea />` など）— `field.props` を展開し、`value={field.input}` を渡します。Formisch が `name`、`ref`、`onChange`、`onBlur`、`onFocus` を設定します。
- **コンポーネント ライブラリの入力**（Radix ベースの `<Select />`、`<Checkbox />`、`<RadioGroup />`、`<Switch />` など）— `field.input` から値を読み取り、`field.onChange(value)` を呼び出して更新します。

### 入力

- 入力フィールドでは `field.props` を展開し、`value={field.input}` を渡します。
- エラーを表示するには、`<Input />` コンポーネントに `aria-invalid` prop、`<Field />` コンポーネントに `data-invalid` prop を追加します。

## フォームをリセットする

Formisch はトップレベルの `reset` 関数を公開します。フォーム ストアを渡すと初期入力へリセットできます。

```tsx showLineNumbers
<Button type="button" variant="outline" onClick={() => reset(form)}>
  Reset
</Button>
```

新しい初期値へリセットしたり、ユーザーの現在の入力を保持したままリセットしたりすることもできます。

```tsx showLineNumbers
// Reset to a fresh set of initial values
reset(form, { initialInput: { title: "", description: "" } })

// Sync the baseline to new server data, but keep the user's edits
reset(form, { initialInput: serverData, keepInput: true })
```

### 項目を追加する

`insert` 関数を使って配列に新しい項目を追加します。既定では末尾に追加されます。`at` インデックスを渡すと特定の位置に挿入できます。

```tsx showLineNumbers title="form.tsx"
<Button
  type="button"
  variant="outline"
  size="sm"
  onClick={() =>
    insert(form, { path: ["emails"], initialInput: { address: "" } })
  }
  disabled={fieldArray.items.length >= 5}
>
  Add Email Address
</Button>
```

### 項目を削除する

`at` インデックスを指定した `remove` 関数を使って配列から項目を削除します。

```tsx showLineNumbers title="form.tsx"

{
  fieldArray.items.length > 1 && (
    <InputGroupAddon align="inline-end">
      <InputGroupButton
        type="button"
        variant="ghost"
        size="icon-xs"
        onClick={() => remove(form, { path: ["emails"], at: index })}
        aria-label={`Remove email ${index + 1}`}
      >
        <XIcon />
      </InputGroupButton>
    </InputGroupAddon>
  )
}
```

Formisch は項目の並べ替えと置換のために `move`、`swap`、`replace` も公開します。これらも同じ `(form, config)` シグネチャに従います。

### 配列の検証

Valibot の `array` とパイプライン バリデーターを使って、配列フィールドを制約します。

```tsx showLineNumbers title="form.tsx"
const FormSchema = v.object({
  emails: v.pipe(
    v.array(
      v.object({
        address: v.pipe(
          v.string(),
          v.nonEmpty("Enter an email address."),
          v.email("Enter a valid email address.")
        ),
      })
    ),
    v.minLength(1, "Add at least one email address."),
    v.maxLength(5, "You can add up to 5 email addresses.")
  ),
})
```
