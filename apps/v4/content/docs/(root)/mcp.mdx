---

shadcn MCP サーバーを使用すると、AI アシスタントがレジストリのアイテムと対話できるようになります。自然言語を使用して、利用可能なコンポーネントを参照し、特定のコンポーネントを検索し、プロジェクトに直接インストールできます。

たとえば、AI アシスタントに「acme レジストリのコンポーネントを使用してランディング ページを構築してください」または「shadcn レジストリからログイン フォームを見つけてください」と依頼できます。

レジストリはプロジェクトの `components.json` ファイルで構成されます。

```json title="components.json" showLineNumbers
{
  "registries": {
    "@acme": "https://acme.com/r/{name}.json"
  }
}
```

## MCP とは何ですか?

[モデル コンテキスト プロトコル (MCP)](https://modelcontextprotocol.io) は、AI アシスタントが外部のデータ ソースやツールに安全に接続できるようにするオープン プロトコルです。 shadcn MCP サーバーを使用すると、AI アシスタントは以下に直接アクセスできるようになります。

- **コンポーネントの参照** - 構成されたレジストリから使用可能なすべてのコンポーネント、ブロック、テンプレートをリストします。
- **レジストリ全体を検索** - 複数のソースから名前または機能で特定のコンポーネントを検索します
- **自然言語を使用してインストール** - 「ログイン フォームを追加する」などの単純な会話プロンプトを使用してコンポーネントを追加します
- **複数のレジストリのサポート** - パブリック レジストリ、プライベート企業ライブラリ、サードパーティ ソースにアクセス

---

## 仕組み

MCP サーバーは、AI アシスタント、コンポーネント レジストリ、shadcn CLI の間のブリッジとして機能します。

1. **レジストリ接続** - MCP は、構成されたレジストリ (shadcn/ui、プライベート レジストリ、サードパーティ ソース) に接続します。
2. **自然言語** - 必要なことを平易な英語で説明します
3. **AI 処理** - アシスタントがリクエストをレジストリ コマンドに変換します。
4. **コンポーネントの配信** - リソースが取得され、プロジェクトにインストールされます

---

## サポートされているレジストリ

shadcn MCP サーバーは、追加設定なしで shadcn 互換のレジストリで動作します。

- **shadcn/ui レジストリ** - すべての shadcn/ui コンポーネントを含むデフォルトのレジストリ
- **サードパーティ レジストリ** - shadcn レジストリ仕様に従う任意のレジストリ
- **プライベート レジストリ** - 会社の内部コンポーネント ライブラリ
- **名前空間レジストリ** - `@namespace` 構文で構成された複数のレジストリ

## 構成

任意の MCP クライアントを使用して、shadcn MCP サーバーと対話できます。ここでは最も人気のあるものの説明を示します。

### クロードコード

クロード コードで shadcn MCP サーバーを使用するには、プロジェクトの `.mcp.json` ファイルに次の構成を追加します。

```json title=".mcp.json" showLineNumbers
{
  "mcpServers": {
    "shadcn": {
      "command": "npx",
      "args": ["shadcn@latest", "mcp"]
    }
  }
}
```

構成を追加した後、Claude Code を再起動し、`/mcp` を実行して、リストに shadcn MCP サーバーを表示します。 `Connected` が表示されていれば問題ありません。

詳細については、[Claude Code MCP ドキュメント](https://code.claude.com/docs/en/mcp) を参照してください。

### カーソル

Cursor で MCP を構成するには、shadcn サーバーをプロジェクトの `.cursor/mcp.json` 構成ファイルに追加します。

```json title=".cursor/mcp.json" showLineNumbers
{
  "mcpServers": {
    "shadcn": {
      "command": "npx",
      "args": ["shadcn@latest", "mcp"]
    }
  }
}
```

構成を追加した後、カーソル設定で shadcn MCP サーバーを有効にします。

有効にすると、MCP サーバー リストの shadcn サーバーの横に緑色の点と利用可能なツールのリストが表示されます。

詳細については、[Cursor MCP ドキュメント](https://docs.cursor.com/en/context/mcp#using-mcp-json) を参照してください。

### VS コード

GitHub Copilot を使用して VS Code で MCP を構成するには、shadcn サーバーをプロジェクトの `.vscode/mcp.json` 構成ファイルに追加します。

```json title=".vscode/mcp.json" showLineNumbers
{
  "servers": {
    "shadcn": {
      "command": "npx",
      "args": ["shadcn@latest", "mcp"]
    }
  }
}
```

構成を追加した後、`.vscode/mcp.json` を開き、shadcn サーバーの横にある [**開始**] をクリックします。

詳細については、[VS Code MCP ドキュメント](https://code.visualstudio.com/docs/copilot/chat/mcp-servers) を参照してください。

### コーデックス

<Callout>
**注:** `shadcn` CLI は、`~/.codex/config.toml` を自動的に更新できません。
構成を手動で追加する必要があります。
</Callout>

Codex で MCP を構成するには、shadcn サーバーを `~/.codex/config.toml` に追加します。

```toml title="~/.codex/config.toml" showLineNumbers
[mcp_servers.shadcn]
command = "npx"
args = ["shadcn@latest", "mcp"]
```

構成を追加した後、Codex を再起動して MCP サーバーをロードします。

## レジストリの構成

MCP サーバーは、プロジェクトの `components.json` 構成を通じて複数のレジストリをサポートします。これにより、プライベート レジストリやサードパーティ プロバイダーなどのさまざまなソースからコンポーネントにアクセスできるようになります。

`components.json` で追加のレジストリを構成します。

```json title="components.json" showLineNumbers
{
  "registries": {
    "@acme": "https://registry.acme.com/{name}.json",
    "@internal": {
      "url": "https://internal.company.com/{name}.json",
      "headers": {
        "Authorization": "Bearer ${REGISTRY_TOKEN}"
      }
    }
  }
}
```

<Callout>
**注:** 標準の shadcn/ui にアクセスするために構成は必要ありません
レジストリ。
</Callout>

## 認証

認証が必要なプライベート レジストリの場合は、`.env.local` で環境変数を設定します。

```bash title=".env.local"
REGISTRY_TOKEN=your_token_here
API_KEY=your_api_key_here
```

レジストリ認証の詳細については、[認証ドキュメント](/docs/registry/authentication) を参照してください。

## プロンプトの例

MCP サーバーが構成されたら、自然言語を使用してレジストリと対話できるようになります。次のプロンプトのいずれかを試してください。

### 参照と検索

- shadcn レジストリ内の利用可能なコンポーネントをすべて表示します
- shadcn レジストリからログイン フォームを見つけます

### アイテムをインストールする

- ボタンコンポーネントをプロジェクトに追加します
- shadcn コンポーネントを使用してログイン フォームを作成する
- acme レジストリから Cursor ルールをインストールします。

### 名前空間の操作

- acme レジストリのコンポーネントを表示
- @internal/auth-form をインストールする
- acme レジストリのヒーロー、機能、紹介セクションを使用してランディング ページを作成します

## トラブルシューティング

### MCP が応答しない

MCP サーバーがプロンプトに応答しない場合:

1. **構成の確認** - MCP サーバーが適切に構成され、MCP クライアントで有効になっていることを確認します。
2. **MCP クライアントの再起動** - 設定変更後に MCP クライアントを再起動します。
3. **インストールの確認** - `shadcn` がプロジェクトにインストールされていることを確認します
4. **ネットワークを確認** - 構成されたレジストリにアクセスできることを確認します

### レジストリ アクセスの問題

コンポーネントがレジストリから読み込まれていない場合:

1. **components.json を確認します** - レジストリ URL が正しいことを確認します
2. **テスト認証** - 環境変数がプライベート レジストリに設定されていることを確認します
3. **レジストリの確認** - レジストリがオンラインでアクセス可能であることを確認します。
4. **名前空間の確認** - 名前空間の構文が正しいことを確認します (`@namespace/component`)

### インストールの失敗

コンポーネントのインストールに失敗した場合:

1. **プロジェクト設定を確認** - 有効な `components.json` ファイルがあることを確認してください
2. **パスの確認** - ターゲット ディレクトリが存在することを確認します。
3. **権限の確認** - コンポーネント ディレクトリへの書き込み権限を確認します。
4. **依存関係の確認** - 必要な依存関係がインストールされていることを確認します

### ツールもプロンプトもありません

`No tools or prompts` メッセージが表示された場合は、次のことを試してください。

1. **npx キャッシュをクリアします** - `npx clear-npx-cache` を実行します
2. **MCP サーバーを再度有効にする** - MCP クライアントで MCP サーバーを再度有効にしてみてください
3. **ログの確認** - カーソルの [表示] -> [出力] でログを確認し、ドロップダウンで `MCP: project-*` を選択します。
