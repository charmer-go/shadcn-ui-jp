<Callout>

テーマを視覚的に構築したいですか? [shadcn/create](/create) を使用して色、半径、フォント、アイコンをプレビューし、プロジェクトのプリセットを生成します。

</Callout>

テーマには CSS 変数を使用し、推奨します。

これにより、コンポーネントがデフォルトで使用する `background`、`foreground`、`primary` などのセマンティック テーマ トークンが得られます。 CSS でこれらのトークンをオーバーライドすると、コンポーネント クラスを書き換えずにアプリの外観を変更できます。

```tsx /bg-background/ /text-foreground/
<div className="bg-background text-foreground" />
```

テーマに CSS 変数を使用するには、`components.json` ファイルで `tailwind.cssVariables` を `true` に設定します。これがデフォルトです。

```json {8} title="components.json" showLineNumbers
{
  "style": "base-nova",
  "rsc": true,
  "tailwind": {
    "config": "",
    "css": "app/globals.css",
    "baseColor": "neutral",
    "cssVariables": true
  }
}
```

Tailwind は、これらのトークンを `bg-background`、`text-foreground`、`border-border`、`ring-ring` などのユーティリティにマップします。

ダーク モードは、`.dark` セレクター内の同じトークンをオーバーライドすることで機能します。テーマプロバイダーの追加と `.dark` クラスの切り替えについては、[ダーク モード ドキュメント](/docs/dark-mode/next) を参照してください。

## トークン規約

セマンティックな背景と前景のペアを使用します。ベース トークンはサーフェスの色を制御し、`-foreground` トークンはそのサーフェス上にあるテキストとアイコンの色を制御します。

<Callout className="mt-4">

表面トークンでは背景のサフィックスが省略されます。たとえば、`primary` は `primary-foreground` とペアになります。

</Callout>

次の CSS 変数があるとします。

```css
--primary: oklch(0.205 0 0);
--primary-foreground: oklch(0.985 0 0);
```

次のコンポーネントの `background` の色は `var(--primary)` になり、`foreground` の色は `var(--primary-foreground)` になります。

```tsx
<div className="bg-primary text-primary-foreground">Hello</div>
```

## テーマトークン

これらのトークンは、CSS ファイルの `:root` および `.dark` の下に存在します。

|トークン |何を制御するのか |使用者 |
| ------------------------------------------------ | ------------------------------------------------------ | ---------------------------------------------------------------------------- |
| `background` / `foreground` |デフォルトのアプリの背景とテキストの色。             |ページシェル、ページセクション、およびデフォルトのテキスト。                             |
| `card` / `card-foreground` |隆起した表面とその内部のコンテンツ。         | `Card`、ダッシュボード パネル、設定パネル。                                   |
| `popover` / `popover-foreground` |浮遊サーフェスとその内部のコンテンツ。         | `Popover`、`DropdownMenu`、`ContextMenu`、およびその他のオーバーレイ。                |
| `primary` / `primary-foreground` |強調されたアクションとブランドの表面。              |デフォルトの `Button`、選択された状態、バッジ、およびアクティブなアクセント。               |
| `secondary` / `secondary-foreground` |低強調のアクションとサポート面を埋め込みます。 |二次ボタン、二次バッジ、およびサポート UI。                      |
| `muted` / `muted-foreground` |微妙な表面と低めの強調のコンテンツ。            |説明、プレースホルダー、空の状態、ヘルパー テキスト、および落ち着いた表面。 |
| `accent` / `accent-foreground` |インタラクティブなホバー、フォーカス、アクティブなサーフェス。         |ゴースト ボタン、メニューのハイライト状態、ホバーされた行、および選択された項目。      |
| `destructive` |破壊的なアクションとエラーの強調。                |破壊的なボタン、無効な状態、および破壊的なメニュー項目。             |
| `border` |デフォルトの境界線と区切り文字。                        |カード、メニュー、テーブル、セパレーター、レイアウトの仕切り。                       |
| `input` |フォームコントロールの境界線と入力表面処理。      | `Input`、`Textarea`、`Select`、およびアウトライン スタイルのコントロール。                   |
| `ring` |フォーカスリングと輪郭。                              |ボタン、入力、チェックボックス、メニュー、およびその他のフォーカス可能なコントロール。            |
| `chart-1` ... `chart-5` |デフォルトのグラフパレット。                             |チャートとチャート駆動のダッシュボード ブロック。                                    |
| `sidebar` / `sidebar-foreground` |ベースのサイドバーの表面とデフォルトのサイドバーのテキスト。     | `Sidebar` コンテナーとそのデフォルトのコンテンツ。                             |
| `sidebar-primary` / `sidebar-primary-foreground` |サイドバー内のアクションを強調します。              |アクティブなアイテム、アイコン タイル、バッジ、サイドバー CTA。                          |
| `sidebar-accent` / `sidebar-accent-foreground` |サイドバー内でホバーして選択した状態を表示します。          |サイドバー メニューのホバー状態、開いている項目、およびインタラクティブな行。                 |
| `sidebar-border` |サイドバー固有の境界線と区切り文字。               |サイドバーのヘッダー、グループ、および内部の仕切り。                              |
| `sidebar-ring` |サイドバー固有のフォーカス リング。                          |サイドバー内のフォーカスされたコントロール。                                         |
| `radius` |ベースコーナー半径のスケール。                          |カード、入力、ボタン、ポップオーバー、および派生した `radius-*` トークン。         |

<Callout className="mt-4">

チャート トークンについては、[チャート テーマに関するドキュメント](/docs/components/chart#theming) で詳しく説明されています。

</Callout>

## 半径スケール

`--radius` は、テーマの基本半径トークンです。

そこから小さな半径スケールを導き出すので、コンポーネントは単一の真実の情報源を共有しながら、一貫した角のサイズを使用できます。

```css title="app/globals.css" showLineNumbers
@theme inline {
  --radius-sm: calc(var(--radius) * 0.6);
  --radius-md: calc(var(--radius) * 0.8);
  --radius-lg: var(--radius);
  --radius-xl: calc(var(--radius) * 1.4);
  --radius-2xl: calc(var(--radius) * 1.8);
  --radius-3xl: calc(var(--radius) * 2.2);
  --radius-4xl: calc(var(--radius) * 2.6);
}
```

これはつまり：

- `radius-lg` は基本値です。
- `--radius` から半径が小さくスケールダウンします。
- `--radius` からより大きな半径スケールアップ。
- `--radius` を変更すると、半径スケール全体が更新されます。

## 新しいトークンの追加

新しいトークンを追加するには、`:root` および `.dark` で定義し、`@theme inline` を使用して Tailwind に公開します。

```css title="app/globals.css" showLineNumbers
:root {
  --warning: oklch(0.84 0.16 84);
  --warning-foreground: oklch(0.28 0.07 46);
}

.dark {
  --warning: oklch(0.41 0.11 46);
  --warning-foreground: oklch(0.99 0.02 95);
}

@theme inline {
  --color-warning: var(--warning);
  --color-warning-foreground: var(--warning-foreground);
}
```

コンポーネントで `bg-warning` および `text-warning-foreground` を使用できるようになりました。

```tsx /bg-warning/ /text-warning-foreground/
<div className="bg-warning text-warning-foreground" />
```

## ベースカラー

`tailwind.baseColor` は、`init` を実行するとき、またはプリセットを使用するときにプロジェクトに対して生成されるデフォルトのトークン値を制御します。

利用可能なベースカラーは次のとおりです: **ニュートラル**、**ストーン**、**亜鉛**、**モーブ**、**オリーブ**、**ミスト**、**トープ**。

## CSS 変数なし

CSS 変数を使用したくない場合は、代わりに CLI でインライン Tailwind カラー ユーティリティを使用してコンポーネントを生成できます。

```bash
npx shadcn@latest init --no-css-variables
```

これにより、`components.json` ファイル内の `tailwind.cssVariables` が `false` に設定されます。

```tsx /bg-zinc-950/ /text-zinc-50/ /dark:bg-white/ /dark:text-zinc-950/
<div className="bg-zinc-950 text-zinc-50 dark:bg-white dark:text-zinc-950" />
```

<Callout className="mt-4">

これはインストール時の選択です。既存のプロジェクトを切り替えるには、コンポーネントを削除して再インストールします。

</Callout>
