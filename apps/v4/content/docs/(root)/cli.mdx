## Tailwind CSS v3 プロジェクトでは、init

`init` コマンドを使用して、既存のプロジェクトの構成と依存関係を初期化するか、`--name` で新しいプロジェクトを作成します。

に追加します。 `init` コマンドは、依存関係をインストールし、`cn` ユーティリティを追加し、プロジェクトの CSS 変数を構成します。

```bash
npx shadcn@latest init
```

**オプション**

```bash
Usage: shadcn init [options] [components...]

initialize your project and install dependencies

Arguments:
  components                 names, url or local path to component

Options:
  -t, --template <template>  the template to use. (next, vite, start, react-router, laravel, astro)
  -b, --base <base>          the component library to use. (base, radix, aria)
  -p, --preset [name]        use a preset configuration
  -y, --yes                  skip confirmation prompt. (default: true)
  -d, --defaults             use default configuration: --template=next --preset=nova (default: false)
  -f, --force                force overwrite of existing configuration. (default: false)
  -c, --cwd <cwd>            the working directory. defaults to the current directory.
  -n, --name <name>          the name for the new project.
  -s, --silent               mute output. (default: false)
  --css-variables            use css variables for theming. (default: true)
  --no-css-variables         do not use css variables for theming.
  --monorepo                 scaffold a monorepo project.
  --no-monorepo              skip the monorepo prompt.
  --rtl                      enable RTL support.
  --no-rtl                   disable RTL support.
  --pointer                  enable pointer cursor for buttons.
  --no-pointer               disable pointer cursor for buttons.
  --reinstall                re-install existing UI components.
  --no-reinstall             do not re-install existing UI components.
  -h, --help                 display help for command
```

`create` コマンドは `init` のエイリアスです。

```bash
npx shadcn@latest create
```

## 移行

`migrate` コマンドを使用して、プロジェクトで移行を実行します。

```bash
npx shadcn@latest migrate [migration]
```

**利用可能な移行**

|移行 |説明 |
| ------------ | ------------------------------------------------------- |
| `cn` | `clsx` と `tailwind-merge` を `cn` に移行します。            |
| `icons`      | UI コンポーネントを別のアイコン ライブラリに移行します。 |
| `base-color` | テーマを別の基本色に移行します。           |
| `radix` | radix-ui に移行します。                                    |
| `rtl`        | RTL（右から左）の言語に対応するようコンポーネントを移行します。 |

**オプション**

```bash
Usage: shadcn migrate [options] [migration] [path]

run a migration.

Arguments:
  migration          the migration to run.
  path               optional path or glob pattern to migrate.

Options:
  -c, --cwd <cwd>    the working directory. defaults to the current directory.
  -l, --list         list all migrations. (default: false)
  -y, --yes          skip confirmation prompt. (default: false)
  -f, --from <name>  the base color or icon library to migrate from.
  -t, --to <name>    the base color or icon library to migrate to.
  -h, --help         display help for command
```

### 移行 cn

`cn` 移行は `clsx`、`tailwind-merge`、`cnfast` を [`cn`](https://github.com/shadcn-ui/cn) に置き換えます。

```bash
npx shadcn@latest migrate cn
```

他の移行とは異なり、`migrate cn` には `components.json` ファイルは必要ありません。 Tailwind CSS v4 を使用して、任意の JavaScript または TypeScript パッケージ プロジェクトで実行できます。

これは次のことを行います:

1. `clsx`、`clsx/lite`、`tailwind-merge`、`cnfast` からのインポートを書き換えます。
2. `twMerge(clsx(...))` 構成を直接 `cn(...)` 呼び出しに置き換えます。
3. 標準の shadcn ユーティリティを直接再エクスポートに置き換えます。
4. `cn` をインストールし、参照が残っていなければ古いパッケージを削除します。

**変更前**

```tsx
import { clsx, type ClassValue } from "clsx"
import { twMerge } from "tailwind-merge"

export function cn(...inputs: ClassValue[]) {
  return twMerge(clsx(inputs))
}
```

**後**

```tsx
export { cn } from "cn"
```

に対してオープンなままです。 移行では、個別に使用される場合も個別の API が保持されます。

```diff
- import { clsx } from "clsx"
- import { twMerge } from "tailwind-merge"
+ import { clsx, twMerge } from "cn"
```

`cnfast` は同じルート API を持っているため、そのモジュール指定子は直接置き換えられます。

```diff
- import { cn } from "cnfast"
+ import { cn } from "cn"
```

カスタム構成 API は `cn/config` に移動されました。エクスポートの名前が変更された場合、既存のローカル名は保持されます。

```diff
- import { createTailwindMerge, getDefaultConfig } from "tailwind-merge"
+ import {
+   createTwMerge as createTailwindMerge,
+   defaultConfig as getDefaultConfig,
+ } from "cn/config"
```

<Callout icon={<TriangleAlertIcon />}>
`cn` のマージ エンジンは `tailwind-merge` v3 と同様に Tailwind CSS v4 に対応しています。
  Tailwind CSS v3 を使用するプロジェクトは、引き続き `tailwind-merge` v2 を使用する必要があります。 A
  `clsx` のみの移行が安全です。
</Callout>

を移行します **特定のファイルを移行します**

ではありません。 ファイル、ディレクトリ、またはグロブ パターンを移行できます。

```bash
# Migrate a specific file.
npx shadcn@latest migrate cn src/lib/utils.ts

# Migrate files matching a glob pattern.
npx shadcn@latest migrate cn "src/**/*.{ts,tsx}"
```

対象を限定した移行では `cn` をインストールしますが、選択したパスの外にあるファイルが使用している可能性があるため、`package.json` の `clsx`、`tailwind-merge`、`cnfast` は残します。

このコマンドは、サポートされていないインポートを変更せずに残し、手動レビューのためにレポートします。これには、`experimentalParseClassName`、名前空間インポート、動的インポート形状、`validators` への直接呼び出し、および安全に移行できない可変引数 `createTailwindMerge` 呼び出しが含まれます。古い依存関係は、その参照の 1 つが残っている場合は常に保持されます。

### アイコン

`icons` 移行はコンポーネントをあるアイコン ライブラリから別のライブラリへ移行します。

```bash
npx shadcn@latest migrate icons
```

移行元と移行先のライブラリを尋ね、`ui` ディレクトリのアイコン インポートと JSX の使用箇所を書き換え、移行先ライブラリをインストールします。また、今後の `npx shadcn add` で新しいライブラリが使われるよう `components.json` の `iconLibrary` を更新します。

次のライブラリに対応しています: `lucide`、`tabler`、`hugeicons`、`phosphor`、`remixicon`、`radix`（レガシー）。

**非対話モード**

`--from` および `--to` を使用して、プロンプトをスキップします。

```bash
npx shadcn@latest migrate icons --from lucide --to phosphor --yes
```

を移行します **特定のファイルを移行します**

特定のファイルを移行したり、glob パターンを使用したりできます。対象を限定した実行では `components.json` は更新されません。

```bash
# Migrate a specific file.
npx shadcn@latest migrate icons src/components/ui/button.tsx --from lucide --to tabler

# Migrate files matching a glob pattern.
npx shadcn@latest migrate icons "src/components/**" --from lucide --to tabler
```

ターゲット ライブラリに同等のアイコンがないアイコンはそのまま残され、移行の終了時に報告されます。

### ベースカラー

`base-color` の移行により、テーマがある基本色から別の基本色に切り替わります。

```bash
npx shadcn@latest migrate base-color
```

これにより、ソースとターゲットの基本色の入力を求められ、テーマの CSS 変数 (`components.json` 内の `tailwind.css` によって構成された CSS ファイル) を書き換えて、将来の `npx shadcn add` のインストールで新しい基本色が使用されるように `baseColor` を更新します。

次の基本色に対応しています: `neutral`、`zinc`、`stone`、`mauve`、`olive`、`mist`、`taupe`。

**非対話モード**

`components.json` の現在の `baseColor` から移行するには `--to` を使うか、`--from` と `--to` の両方を明示的に渡します。

```bash
npx shadcn@latest migrate base-color --to zinc --yes
```

ソースのベース カラーと一致しなくなったテーマ トークンはそのまま残され、移行の最後にレポートされます。

### 移行 rtl

`rtl` 移行は RTL（右から左）の言語に対応するようコンポーネントを変換します。

```bash
npx shadcn@latest migrate rtl
```

これは次のことを行います:

1. `components.json` を更新して `rtl: true` を設定します。
2. 物理的な CSS プロパティを論理的な同等のプロパティに変換します (例: `ml-4` → `ms-4`、`text-left` → `text-start`)
3. 必要に応じて `rtl:` バリアントを追加します (例: `space-x-4` → `space-x-4 rtl:space-x-reverse`)

を移行します **特定のファイルを移行します**

特定のファイルを移行したり、glob パターンを使用したりできます。

```bash
# Migrate a specific file
npx shadcn@latest migrate rtl src/components/ui/button.tsx

# Migrate files matching a glob pattern
npx shadcn@latest migrate rtl "src/components/ui/**"
```

パスを指定しない場合、`components.json` の `ui` ディレクトリにあるすべてのファイルを変換します。

### 基数

`radix` の移行により、個別のインポートが更新されます。 `@radix-ui/react-*` パッケージを統合 `radix-ui` パッケージに変更します。

```bash
npx shadcn@latest migrate radix
```

これは次のことを行います:

1. `@radix-ui/react-*` から `radix-ui` へインポートを変換します。
2. `radix-ui` パッケージを `package.json`

**変更前**

```tsx
import * as DialogPrimitive from "@radix-ui/react-dialog"
import * as SelectPrimitive from "@radix-ui/react-select"
```

**後**

```tsx
import { Dialog as DialogPrimitive, Select as SelectPrimitive } from "radix-ui"
```

を移行します **特定のファイルを移行します**

You can migrate specific files or use glob patterns:

```bash
# Migrate a specific file.
npx shadcn@latest migrate radix src/components/ui/dialog.tsx

# Migrate files matching a glob pattern.
npx shadcn@latest migrate radix "src/components/ui/**"
```

パスを指定しない場合、`components.json` の `ui` ディレクトリにあるすべてのファイルを変換します。

完了したら、未使用の `@radix-ui/react-*` パッケージを `package.json` から削除できます。

## eject

`init` を実行すると、shadcn は `@import "shadcn/tailwind.css"` をグローバル CSS ファイルに追加します。このインポートは、カスタム バリアント (`data-open:`、`data-closed:` など) やアコーディオン アニメーションなどの共有 Tailwind v4 ユーティリティを提供します。

`eject` コマンドを使用して、`shadcn/tailwind.css` をグローバル CSS ファイルにインライン化し、プロジェクトから `shadcn` 依存関係を削除します。

<Callout icon={<TriangleAlertIcon />}>
  を移行します。 **注: この操作は元に戻すことができません。** 取り出した後、将来の shadcn CLI
  `shadcn/tailwind.css` への更新は自動的には適用されません。
</Callout>

```bash
npx shadcn@latest eject
```

**変更前**

```css
@import "tailwindcss";
@import "tw-animate-css";
@import "shadcn/tailwind.css";
```

**後**

```css
@import "tailwindcss";
@import "tw-animate-css";
/* ejected from shadcn@4.8.3 */
@theme inline {
  @keyframes accordion-down {
    from {
      height: 0;
    }
    to {
      height: var(
        --radix-accordion-content-height,
        var(--accordion-panel-height, auto)
      );
    }
  }
}

@custom-variant data-open {
  &:where([data-state="open"]),
  &:where([data-open]:not([data-open="false"])) {
    @slot;
  }
}

@utility no-scrollbar {
  -ms-overflow-style: none;
  scrollbar-width: none;

  &::-webkit-scrollbar {
    display: none;
  }
}
```

**Monorepo**

モノリポジトリでは、`components.json` およびグローバル CSS ファイルを含むワークスペースからコマンドを実行します。

```bash
npx shadcn@latest eject -c packages/ui
```

**オプション**

```bash
Usage: shadcn eject [options]

inline shadcn/tailwind.css and remove the shadcn dependency

Options:
  -c, --cwd <cwd>  the working directory. defaults to the current directory.
  -y, --yes        skip confirmation prompt. (default: false)
  -s, --silent     mute output. (default: false)
  -h, --help       display help for command
```
