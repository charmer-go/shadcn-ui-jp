---

スキルは、Claude Code のような AI アシスタントに shadcn/ui に関するプロジェクト認識コンテキストを提供します。インストールすると、AI アシスタントは、プロジェクトに適切な API とパターンを使用してコンポーネントを検索、インストール、構成、カスタマイズする方法を認識します。

たとえば、AI アシスタントに次のことを依頼できます。

- _「電子メールとパスワードのフィールドを含むログイン フォームを追加します。」_
- _「プロフィール情報を更新するためのフォームを含む設定ページを作成します。」_
- _「サイドバー、統計カード、データ テーブルを備えたダッシュボードを構築します。」_
- _「--preset [コード]に切り替える」_
- _「@tailark からヒーローを追加できますか?」_

スキルはプロジェクトの `components.json` を読み取り、フレームワーク、エイリアス、インストールされているコンポーネント、アイコン ライブラリ、およびベース ライブラリをアシスタントに提供するため、最初の試行で正しいコードを生成できます。

---

## インストール

```bash
npx skills add shadcn/ui
```

これにより、shadcn スキルがプロジェクトにインストールされます。インストールされると、AI アシスタントは shadcn/ui コンポーネントを操作するときに自動的にロードされます。

スキルの詳細については、[skills.sh](https://skills.sh) をご覧ください。

---

## 含まれるもの

このスキルは、AI アシスタントに次の知識を提供します。

### プロジェクトのコンテキスト

インタラクションごとに、スキルは `shadcn info --json` を実行して、プロジェクトの構成 (フレームワーク、Tailwind バージョン、エイリアス、ベース ライブラリ (`base`、`radix`、または `aria`)、アイコン ライブラリ、インストールされているコンポーネント、解決されたファイル パス) を取得します。

### CLI コマンド

すべての CLI コマンドの完全なリファレンス: `init`、`add`、`search`、`view`、`docs`、`diff`、`info`、および `build`。フラグ、ドライラン モード、スマート マージ ワークフロー、プリセット、テンプレートが含まれます。

### テーマとカスタマイズ

CSS 変数、OKLCH カラー、ダーク モード、カスタム カラー、境界線の半径、およびコンポーネントのバリアントがどのように機能するか。 Tailwind v3 と v4 の両方のガイダンスが含まれています。

### レジストリのオーサリング

カスタム コンポーネント レジストリを構築および公開する方法: `registry.json` 形式、項目タイプ、ファイル オブジェクト、依存関係、CSS 変数、構築、ホスティング、およびユーザー構成。

### MCP サーバー

AI アシスタントがレジストリからコンポーネントを検索、参照、インストールできるようにする shadcn MCP サーバーのセットアップとツール。

## 仕組み

1. **プロジェクト検出** — プロジェクト内で `components.json` ファイルが見つかると、スキルがアクティブになります。
2. **コンテキスト挿入** — `shadcn info --json` を実行してプロジェクト構成を読み取り、結果をアシスタントのコンテキストに挿入します。
3. **パターンの強制** — アシスタントは shadcn/ui 構成ルールに従います。フォームには `FieldGroup`、オプション セットには `ToggleGroup`、セマンティック カラー、および正しいベース固有 API を使用します。
4. **コンポーネントの検出** — アシスタントは、`shadcn docs`、`shadcn search`、または MCP ツールを使用して、コードを生成する前にコンポーネントとそのドキュメントを検索します。
