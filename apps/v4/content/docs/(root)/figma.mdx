## 無料

- [Sitsiilia Bergmann](https://x.com/sitsiilia) による [shadcn/ui コンポーネント](https://www.figma.com/community/file/1342715840824755935) - 定期的に保守される、shadcn コンポーネント システムと連携した適切に構造化されたコンポーネント ライブラリ。
- [Pietro Schirano](https://twitter.com/skirano) による [shadcn/ui デザイン システム](https://www.figma.com/community/file/1203061493325953101) - shadcn/ui のデザイン コンパニオン。各コンポーネントは、コードの実装に完全に一致するように丹念に作成されました。
- [Obra Studio](https://obra.studio/) による [Obra shadcn/ui Community Edition](https://www.figma.com/community/file/1514746685758799870/) - すべてのコンポーネントと簡単なテーマ システムを備えた、Figma 用の最も完全な無料 shadcn/ui キット。デザイナーのチームによって保守されています。
- [shadcncraft](https://shadcncraft.com) による [shadcncraft 無料スターター キット](https://www.figma.com/community/file/1534076420225325960) - 8 つすべての shadcn/ui スタイルのネイティブ Figma 変数、tweakcn および shadcn/ui Create からのテーマのインポート、アイコンの切り替え、および React コンポーネントのマッチング。積極的にメンテナンスされています。

## 有料

- [Matt Wierzbicki](https://x.com/matsugfx) による [shadcn/ui キット](https://shadcndesign.com) - Figma 用の常に最新のプレミアム UI キット - shadcn/ui と互換性があり、設計から開発へのスムーズな引き継ぎのために最適化されています。
- [shadcncraft – shadcn/ui Figma kit](https://shadcncraft.com/figma) - 8 つの shadcn スタイルすべてと、一致する React コードを備えた何百もの Pro コンポーネントとブロック。プラグインは新しいスタイルを構築し、カスタム shadcn プリセットと tweakcn テーマをロードし、フレームを React にエクスポートします。エージェントのスキルは、Figma MCP を通じて設計をコードに変換します。
- [shadcn/studio UI キット](https://shadcnstudio.com/figma) - 更新されたコンポーネント、550 以上のブロック、10 以上のテンプレート、20 以上のテーマ、デザインを shadcn/ui コードに変換する AI ツールを備えた shadcn/ui 互換の Figma キットでデザインと開発を加速します。
- [Shadcnblocks.com](https://www.shadcnblocks.com) - コンポーネント、500 以上のプロ ブロック、shadcn テーマ変数、ライト/ダーク モード、Figma MCP 対応のプレミアム Shadcn Figma UI キット。
- [Obra Studio](https://obra.studio/) による [Obra shadcn/ui Pro](https://shadcn.obra.studio/products/obra-shadcn-ui-pro) - Figma 内での shadcn/ui の最高のデザイナー エクスペリエンス。 8 つのスタイルすべて、shadcn との一貫性、Pro ブロック、デザインからコードまでのプラグイン。
- [Shadcn Space](https://shadcnspace.com/figma) - 最新の React および Next.js ワークフロー向けに構築された shadcn/ui 互換の Figma キットを備えた、美しくデザインされた 320 以上のブロック、9 以上のテンプレート、250 以上のコンポーネントのコレクション。実際のコード アーキテクチャと本番環境に対応した実装パターンを反映する Figma コンポーネントを使用して、設計、プロトタイプ、出荷を迅速化します。
- [ShadcnStore](https://x.com/shadcnstore) による [Shadcn Design System](https://shadcnstore.com/) - コンポーネント、バリアント、デザイン トークン、プロダクション対応ブロック、テンプレートを備えた shadcn/ui 用の完全な Figma UI キット。高速なワークフローとピクセル完璧なデザイナーから開発者への引き継ぎを目的に構築されています。
