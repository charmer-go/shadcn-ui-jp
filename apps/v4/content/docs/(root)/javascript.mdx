---
title: JavaScript
description: JavaScript で shadcn/ui を使用する方法
---

このプロジェクトとコンポーネントは TypeScript で書かれています。プロジェクトにも TypeScript を使用することをお勧めします。

ただし、JavaScript バージョンのコンポーネントも提供しています。 JavaScript バージョンは、[cli](/docs/cli) から入手できます。

TypeScript をオプトアウトするには、`components.json` ファイルで `tsx` フラグを使用します。

```json {4} title="components.json" showLineNumbers
{
  "style": "new-york",
  "rsc": false,
  "tsx": false,
  "tailwind": {
    "config": "",
    "css": "src/app/globals.css",
    "baseColor": "zinc",
    "cssVariables": true
  },
  "iconLibrary": "lucide",
  "aliases": {
    "components": "@/components",
    "utils": "@/lib/utils",
    "ui": "@/components/ui",
    "lib": "@/lib",
    "hooks": "@/hooks"
  }
}
```

インポート エイリアスを構成するには、次の `jsconfig.json` を使用できます。

```json {4} title="jsconfig.json" showLineNumbers
{
  "compilerOptions": {
    "paths": {
      "@/*": ["./*"]
    }
  }
}
```
