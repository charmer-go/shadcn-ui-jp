## 使用法

```tsx
import {
  Attachment,
  AttachmentAction,
  AttachmentActions,
  AttachmentContent,
  AttachmentDescription,
  AttachmentMedia,
  AttachmentTitle,
} from "@/components/ui/attachment"
```

```tsx
<Attachment>
  <AttachmentMedia>
    <FileTextIcon />
  </AttachmentMedia>
  <AttachmentContent>
    <AttachmentTitle>sales-dashboard.pdf</AttachmentTitle>
    <AttachmentDescription>PDF · 2.4 MB</AttachmentDescription>
  </AttachmentContent>
  <AttachmentActions>
    <AttachmentAction aria-label="Remove sales-dashboard.pdf">
      <XIcon />
    </AttachmentAction>
  </AttachmentActions>
</Attachment>
```

## 構成

添付ファイルを作成するには、次の構成を使用します。

```text
Attachment
├── AttachmentMedia
├── AttachmentContent
│   ├── AttachmentTitle
│   └── AttachmentDescription
├── AttachmentActions
│   └── AttachmentAction
└── AttachmentTrigger
```

`AttachmentGroup` を使用して、複数の添付ファイルをスクロール可能な行にレイアウトします。

```text
AttachmentGroup
├── Attachment
└── Attachment
```

## 特徴

- `AttachmentMedia` を介したアイコンと画像メディア
- アップロード状態: `idle`、`uploading`、`processing`、`error`、`done` (組み込みのスタイルと進行中のシマー付き)
- 3 つのサイズと水平方向または垂直方向
- アクションは独立してクリック可能なままで、リンクまたはダイアログを開くフルカード `AttachmentTrigger`
- スクロール可能、エッジフェード付きスナップ `AttachmentGroup`
- 各パーツの `className` プロップによるカスタマイズ可能なスタイル

## トリガー

`AttachmentTrigger` を追加して、カード全体にリンクまたはダイアログを開きます。アクションの後ろのカードを埋めるので、アクションはクリック可能なままになります。

## アクセシビリティ

`AttachmentAction` は `Button` をレンダリングし、`AttachmentTrigger` は実際の `<button>` (または `render` 経由の要素) をレンダリングします。両方が操作可能でアナウンスされるように、以下のガイダンスに従ってください。

### ラベルアイコンのみのアクション

`AttachmentAction` は通常アイコンのみなので、それぞれにアクションとそのターゲットを説明する `aria-label` を与えます。

```tsx showLineNumbers
<AttachmentAction aria-label="Remove sales-dashboard.pdf">
  <XIcon />
</AttachmentAction>
```

### トリガーにラベルを付ける

`AttachmentTrigger` は、独自のテキストを持たないカードをカバーするため、アクティブ化すると何が行われるかについて `aria-label` を与えます。

```tsx showLineNumbers
<AttachmentTrigger
  render={(props) => (
    <a
      {...props}
      href={url}
      target="_blank"
      rel="noreferrer"
      aria-label="Open workspace.png"
    />
  )}
/>
```

トリガーはスタック順でアクションの後ろにあるため、`AttachmentAction` と `AttachmentTrigger` が互いにトラップされることはありません。両方とも個別にフォーカス可能でクリック可能なままです。

### キーボードのスクロール

`AttachmentGroup` は水平にスクロールします。添付ファイルがインタラクティブである場合 (トリガーまたはアクション)、キーボード ユーザーはタブで画面外の項目にアクセスします。プレゼンテーション用添付ファイルの行の場合、`tabIndex={0}`、`role="group"`、および `aria-label` を追加して、グループ自体をフォーカス可能およびスクロール可能にします。

### 色を超えた意味

`error` 状態では、破壊的な色が使用されています。状態が色だけで伝わらないように、失敗の理由を `AttachmentDescription` に保持します。

## API リファレンス

### 添付ファイル

ルート添付コンテナ。

|小道具 |タイプ |デフォルト |説明 |
| ------------- | ------------------------------------------------------------ | -------------- | ------------------------------------------------- |
| `state` | `"idle" \| "uploading" \| "processing" \| "error" \| "done"` | `"done"` |アップロードの状態。スタイリングと輝きを促進します。 |
| `size` | `"default" \| "sm" \| "xs"` | `"default"` |添付ファイルのサイズ。                              |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |メディアをコンテンツの横または上に置きます。        |
| `className` | `string` | - |ルート要素に適用する追加のクラス。  |

### 添付メディア

アイコンまたは画像プレビュー用のメディア スロット。

|小道具 |タイプ |デフォルト |説明 |
| ----------- | ------------------- | -------- | ---------------------------------------------- |
| `variant` | `"icon" \| "image"` | `"icon"` |メディアにアイコンまたは `<img>` が含まれるかどうか。 |
| `className` | `string` | - |メディア スロットに適用する追加のクラス。 |

### 添付ファイルの内容

タイトルと説明を折り返します。

|小道具 |タイプ |デフォルト |説明 |
| ----------- | -------- | ------- | ------------------------------------------------ |
| `className` | `string` | - |コンテンツ スロットに適用する追加のクラス。 |

### 添付ファイルのタイトル

添付ファイルの名前。アタッチメントが `uploading` または `processing` のときに輝きます。

|小道具 |タイプ |デフォルト |説明 |
| ----------- | -------- | ------- | ----------------------------------------- |
| `className` | `string` | - |タイトルに適用する追加のクラス。 |

### 添付ファイルの説明

ファイルの種類、サイズ、アップロード ステータスなどの二次メタデータ。

|小道具 |タイプ |デフォルト |説明 |
| ----------- | -------- | ------- | ----------------------------------------------- |
| `className` | `string` | - |説明に適用する追加のクラス。 |

### 添付アクション

添付ファイルの最後に揃えられた 1 つ以上のアクションのコンテナー。

|小道具 |タイプ |デフォルト |説明 |
| ----------- | -------- | ------- | ------------------------------------------- |
| `className` | `string` | - |アクションに適用する追加のクラス。 |

### 添付ファイルアクション

アクションボタン。 [`Button`](/docs/components/aria/button) をレンダリングし、そのプロパティをすべて受け入れます。

|小道具 |タイプ |デフォルト |説明 |
| ---------- | ------------------------------------- | ----------- | ---------------------------------------- |
| `size` | `Button["size"]` | `"icon-xs"` |ボタンのサイズ。                         |
| `...props` | `React.ComponentProps<typeof Button>` | - |小道具は基礎となる `Button` に広がります。 |

### アタッチメントトリガー

アタッチメントをアクティブにするフルカード オーバーレイ。デフォルトで `<button>` をレンダリングします。

|小道具 |タイプ |デフォルト |説明 |
| ---------- | -------------------------------- | ------- | ---------------------------------------------- |
| `render` | `ReactElement \| function` | - |リンクなどの別の要素としてレンダリングします。 |
| `...props` | `React.ComponentProps<"button">` | - |小道具はトリガー要素に広がります。           |

### 添付ファイルグループ

水平方向にスクロール可能なスナップ行に添付ファイルをレイアウトします。

|小道具 |タイプ |デフォルト |説明 |
| ----------- | -------- | ------- | ----------------------------------------- |
| `className` | `string` | - |グループに適用する追加のクラス。 |
