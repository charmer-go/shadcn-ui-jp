## 使用法

```tsx showLineNumbers
import {
  Breadcrumb,
  BreadcrumbItem,
  BreadcrumbLink,
  BreadcrumbList,
  BreadcrumbPage,
} from "@/components/ui/breadcrumb"
```

```tsx showLineNumbers
<Breadcrumb>
  <BreadcrumbList>
    <BreadcrumbItem>
      <BreadcrumbLink href="/">Home</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbItem>
      <BreadcrumbLink href="/components">Components</BreadcrumbLink>
    </BreadcrumbItem>
    <BreadcrumbItem>
      <BreadcrumbPage>Breadcrumb</BreadcrumbPage>
    </BreadcrumbItem>
  </BreadcrumbList>
</Breadcrumb>
```

## 構成

次の構成を使用して、`Breadcrumb` を構築します。

```text
Breadcrumb
└── BreadcrumbList
    ├── BreadcrumbItem
    │   └── BreadcrumbLink
    ├── BreadcrumbItem
    │   └── BreadcrumbLink
    └── BreadcrumbItem
        └── BreadcrumbPage
```

## API リファレンス

### ブレッドクラム

`Breadcrumb` コンポーネントは、すべてのブレッドクラム コンポーネントをラップするルート ナビゲーション要素です。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |

### ブレッドクラムリスト

`BreadcrumbList` コンポーネントは、ブレッドクラム項目の順序付きリストを表示します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |

### ブレッドクラム項目

`BreadcrumbItem` コンポーネントは、個々のブレッドクラム項目をラップします。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |

### ブレッドクラムリンク

`BreadcrumbLink` コンポーネントは、パンくずリストにクリック可能なリンクを表示します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |

### ブレッドクラムページ

`BreadcrumbPage` コンポーネントは、ブレッドクラムに現在のページを表示します (クリック不可)。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |

### ブレッドクラム省略記号

`BreadcrumbEllipsis` コンポーネントは、折りたたまれたブレッドクラム項目の省略記号インジケーターを表示します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |

詳細については、[React Aria ドキュメント](https://react-aria.adobe.com/Breadcrumbs#api) を参照してください。
