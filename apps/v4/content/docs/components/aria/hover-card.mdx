## 使用法

```tsx showLineNumbers
import { HoverCard, HoverCardTrigger } from "@/components/ui/hover-card"
```

```tsx showLineNumbers
<HoverCardTrigger>
  <Button variant="link">Hover</Button>
  <HoverCard>
    The React Framework – created and maintained by @vercel.
  </HoverCard>
</HoverCardTrigger>
```

## 構成

次の構成を使用して `HoverCard` を構築します。

```text
HoverCardTrigger
├── Button
└── HoverCard
```

## トリガー遅延

`HoverCardTrigger` で `delay` および `closeDelay` を使用して、カード
が開閉します。

```tsx showLineNumbers
<HoverCardTrigger delay={100} closeDelay={200}>
  <Button variant="link">Hover</Button>
  <HoverCard>Content</HoverCard>
</HoverCardTrigger>
```

## 位置

`HoverCard` の `placement` プロップを使用して配置を制御します。

```tsx showLineNumbers
<HoverCardTrigger>
  <Button variant="link">Hover</Button>
  <HoverCard placement="top">Content</HoverCard>
</HoverCardTrigger>
```
