## 使用法

```tsx showLineNumbers
import { Avatar, AvatarFallback, AvatarImage } from "@/components/ui/avatar"
```

```tsx showLineNumbers
<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" />
  <AvatarFallback>CN</AvatarFallback>
</Avatar>
```

## 構成

次の構成を使用して、`Avatar` を構築します。

```text
Avatar
├── AvatarImage
├── AvatarFallback
└── AvatarBadge
```

次の構成を使用して、`AvatarGroup` を構築します。

```text
AvatarGroup
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
├── Avatar
│   ├── AvatarImage
│   ├── AvatarFallback
│   └── AvatarBadge
└── AvatarGroupCount
```

## バッジ

`AvatarBadge` コンポーネントを使用して、アバターにバッジを追加します。バッジはアバターの右下に配置されます。

<ComponentPreview styleName="aria-nova" name="avatar-badge" />

`className` プロップを使用して、カスタム色、サイズなどのカスタム スタイルをバッジに追加します。

```tsx showLineNumbers
<Avatar>
  <AvatarImage src="https://github.com/shadcn.png" alt="@shadcn" />
  <AvatarFallback>CN</AvatarFallback>
  <AvatarBadge className="bg-green-600 dark:bg-green-800" />
</Avatar>
```

## API リファレンス

### アバター

`Avatar` コンポーネントは、アバター イメージとフォールバックをラップするルート コンポーネントです。

|小道具 |タイプ |デフォルト |
| ----------- | --------------------------- | ----------- |
| `size` | `"default" \| "sm" \| "lg"` | `"default"` |
| `className` | `string` | - |

### アバター画像

`AvatarImage` コンポーネントはアバター画像を表示します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `src` | `string` | - |
| `alt` | `string` | - |
| `className` | `string` | - |

### アバターフォールバック

`AvatarFallback` コンポーネントは、イメージのロードに失敗した場合にフォールバックを表示します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |

### アバターバッジ

`AvatarBadge` コンポーネントは、アバター上にバッジ インジケーターを表示します。通常は右下に配置されます。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |

### アバターグループ

`AvatarGroup` コンポーネントは、スタイルが重なったアバターのグループを表示します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |

### アバターグループ数

`AvatarGroupCount` コンポーネントは、アバター グループ内のカウント インジケーターを表示し、通常は追加のアバターの数を示します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | - |
