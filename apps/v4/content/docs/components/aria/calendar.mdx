## 使用法

```tsx showLineNumbers
import {
  getLocalTimeZone,
  today,
  type CalendarDate,
} from "@internationalized/date"

import { Calendar } from "@/components/ui/calendar"
```

```tsx showLineNumbers
const [date, setDate] = React.useState<CalendarDate | null>(
  today(getLocalTimeZone())
)

return (
  <Calendar value={date} onChange={setDate} className="rounded-lg border" />
)
```

詳細については、[React Aria](https://react-aria.adobe.com/Calendar) ドキュメントを参照してください。

## カスタムセルサイズ

<ComponentPreview
  styleName="aria-nova"
  name="calendar-custom-days"
  title="カスタムセルサイズ"
  description="レスポンシブなカスタムセルサイズのカレンダー。"
  className="**:[.preview]:h-[560px]"
/>

`--cell-size` CSS 変数を使用して、カレンダーのセルのサイズをカスタマイズできます。ブレークポイント固有の値を使用して応答性を高めることもできます。

```tsx showLineNumbers
<Calendar
  value={date}
  onChange={setDate}
  className="rounded-lg border [--cell-size:--spacing(11)] md:[--cell-size:--spacing(12)]"
/>
```

または、固定値を使用します。

```tsx showLineNumbers
<Calendar
  value={date}
  onChange={setDate}
  className="rounded-lg border [--cell-size:2.75rem] md:[--cell-size:3rem]"
/>
```
