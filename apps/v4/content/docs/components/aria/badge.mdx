## 使用法

```tsx
import { Badge } from "@/components/ui/badge"
```

```tsx
<Badge variant="default | outline | secondary | destructive">Badge</Badge>
```

## バリアント

`variant` プロップを使用して、バッジのバリアントを変更します。

<ComponentPreview styleName="aria-nova" name="badge-variants" />

## アイコン付き

バッジ内にアイコンをレンダリングできます。左側のアイコンをレンダリングするには `data-icon="inline-start"` を使用し、右側のアイコンをレンダリングするには `data-icon="inline-end"` を使用します。

<ComponentPreview styleName="aria-nova" name="badge-icon" />

## スピナー付き

バッジ内にスピナーをレンダリングできます。 `data-icon="inline-start"` または `data-icon="inline-end"` プロップをスピナーに忘れずに追加してください。

<ComponentPreview styleName="aria-nova" name="badge-spinner" />

## リンク

リンクをバッジとしてレンダリングするには、`render` プロップを使用します。

<ComponentPreview styleName="aria-nova" name="badge-link" />

## カスタムカラー

`bg-green-50 dark:bg-green-800` などのカスタム クラスを `Badge` コンポーネントに追加することで、バッジの色をカスタマイズできます。

<ComponentPreview styleName="aria-nova" name="badge-colors" />

## API リファレンス

### バッジ

`Badge` コンポーネントは、バッジまたはバッジのように見えるコンポーネントを表示します。

|小道具 |タイプ |デフォルト |
| ----------- | ----------------------------------------------------------------------------- | ----------- |
| `variant` | `"default" \| "secondary" \| "destructive" \| "outline" \| "ghost" \| "link"` | `"default"` |
| `className` | `string` | - |
