## 使い方

```tsx showLineNumbers
import { Tooltip, TooltipTrigger } from "@/components/ui/tooltip"
```

```tsx showLineNumbers
<TooltipTrigger>
  <Button>Hover</Button>
  <Tooltip>
    <p>Add to library</p>
  </Tooltip>
</TooltipTrigger>
```

## 構成

Use the following composition to build a `Tooltip`:

```text
TooltipTrigger
├── Button
└── Tooltip
```
