## 使用法

```tsx
import {
  ButtonGroup,
  ButtonGroupSeparator,
  ButtonGroupText,
} from "@/components/ui/button-group"
```

```tsx
<ButtonGroup>
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

## 構成

`ButtonGroup` を構築するには、次の構成を使用します。

```text
ButtonGroup
├── Button or Input
├── ButtonGroupSeparator
└── ButtonGroupText
```

## アクセシビリティ

- `ButtonGroup` コンポーネントには、`role` 属性が `group` に設定されています。
- <Kbd>Tab</Kbd> を使用して、グループ内のボタン間を移動します。
- `aria-label` または `aria-labelledby` を使用してラベルを付けるボタングループ。

```tsx showLineNumbers
<ButtonGroup aria-label="Button group">
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

## ButtonGroup と ToggleGroup の比較

- アクションを実行するボタンをグループ化する場合は、`ButtonGroup` コンポーネントを使用します。
- 状態を切り替えるボタンをグループ化する場合は、`ToggleGroup` コンポーネントを使用します。

## API リファレンス

### ボタングループ

`ButtonGroup` コンポーネントは、関連するボタンを一貫したスタイルでグループ化するコンテナーです。

|小道具 |タイプ |デフォルト |
| ------------- | ---------------------------- | -------------- |
| `orientation` | `"horizontal" \| "vertical"` | `"horizontal"` |

```tsx
<ButtonGroup>
  <Button>Button 1</Button>
  <Button>Button 2</Button>
</ButtonGroup>
```

複数のボタン グループをネストして、間隔のある複雑なレイアウトを作成します。詳細については、[nested](#nested) の例を参照してください。

```tsx
<ButtonGroup>
  <ButtonGroup />
  <ButtonGroup />
</ButtonGroup>
```

### ButtonGroupSeparator

`ButtonGroupSeparator` コンポーネントは、グループ内のボタンを視覚的に分割します。

|小道具 |タイプ |デフォルト |
| ------------- | ---------------------------- | ------------ |
| `orientation` | `"horizontal" \| "vertical"` | `"vertical"` |

```tsx
<ButtonGroup>
  <Button>Button 1</Button>
  <ButtonGroupSeparator />
  <Button>Button 2</Button>
</ButtonGroup>
```

### ボタングループテキスト

このコンポーネントを使用して、ボタン グループ内のテキストを表示します。

|小道具 |タイプ |デフォルト |
| -------- | --------- | ------- |
| `render` | `boolean` | `false` |

```tsx
<ButtonGroup>
  <ButtonGroupText>Text</ButtonGroupText>
  <Button>Button</Button>
</ButtonGroup>
```

`render` プロップを使用して、カスタム コンポーネントをテキスト (ラベルなど) としてレンダリングします。

```tsx showLineNumbers
import { ButtonGroupText } from "@/components/ui/button-group"
import { Label } from "@/components/ui/label"

export function ButtonGroupTextDemo() {
  return (
    <ButtonGroup>
      <ButtonGroupText
        render={(props) => (
          <Label {...props} htmlFor="name">
            Text
          </Label>
        )}
      />
      <Input placeholder="Type something here..." id="name" />
    </ButtonGroup>
  )
}
```
