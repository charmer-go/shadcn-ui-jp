## カスタマイズ

について `Spinner` コンポーネントを編集すると、デフォルトのスピナー アイコンを他のアイコンに置き換えることができます。

<ComponentPreview styleName="aria-nova" name="spinner-custom" />

```tsx showLineNumbers title="components/ui/spinner.tsx"
import { cn } from "cn"
import { LoaderIcon } from "lucide-react"

function Spinner({ className, ...props }: React.ComponentProps<"svg">) {
  return (
    <LoaderIcon
      role="status"
      aria-label="Loading"
      className={cn("size-4 animate-spin", className)}
      {...props}
    />
  )
}

export { Spinner }
```

## ボタン

読み込み状態を示すスピナーをボタンに追加します。 `<Spinner />` を開始位置として `data-icon="inline-start"` を指定してラベルの前に配置するか、終了位置として `data-icon="inline-end"` を指定してラベルの後に配置します。

<ComponentPreview styleName="aria-nova" name="spinner-button" />

## バッジ

バッジにスピナーを追加して、読み込み状態を示します。 `<Spinner />` を開始位置として `data-icon="inline-start"` を指定してラベルの前に配置するか、終了位置として `data-icon="inline-end"` を指定してラベルの後に配置します。
