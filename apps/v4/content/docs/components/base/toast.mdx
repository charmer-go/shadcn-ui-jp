## 使用法

```tsx
import { toast } from "@/components/ui/toast"
```

```tsx
toast.add({
  title: "Event created",
  description: "Sunday, December 3 at 9:00 AM",
})
```

## 非同期タスクの状態

ステータス アイコンを表示するには、`type` オプションを設定します。組み込みレンダラーは `success`、`info`、`warning`、`error`、`loading` を認識します。

<ComponentPreview styleName="base-nova" name="toast-types" />

## アクション

`actionProps` を持つボタンの小道具を渡して、アクションをレンダリングします。

```tsx
const id = toast.add({
  title: "Event created",
  actionProps: {
    children: "Undo",
    onClick() {
      toast.close(id)
    },
  },
})
```
