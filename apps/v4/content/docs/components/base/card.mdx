## 使用法

```tsx showLineNumbers
import {
  Card,
  CardAction,
  CardContent,
  CardDescription,
  CardFooter,
  CardHeader,
  CardTitle,
} from "@/components/ui/card"
```

```tsx showLineNumbers
<Card>
  <CardHeader>
    <CardTitle>Card Title</CardTitle>
    <CardDescription>Card Description</CardDescription>
    <CardAction>Card Action</CardAction>
  </CardHeader>
  <CardContent>
    <p>Card Content</p>
  </CardContent>
  <CardFooter>
    <p>Card Footer</p>
  </CardFooter>
</Card>
```

## 構成

Use the following composition to build a `Card`:

```text
Card
├── CardHeader
│   ├── CardTitle
│   ├── CardDescription
│   └── CardAction
├── CardContent
└── CardFooter
```

## 間隔

`size` プロップに加えて、`--card-spacing` CSS 変数を使用して、セクション間の間隔とカード パーツの差し込みを制御できます。

<ComponentPreview
  styleName="base-nova"
  name="card-spacing"
  previewClassName="h-[34rem]"
/>

`-mx-(--card-spacing)` で負のマージンを使用すると、コンテンツをカードの差し込み口と揃えたまま端から端まで移動させることができます。端から端までのコンテンツがフッターの上にある場合は、`CardContent` で `-mb-(--card-spacing)` を使用してセクションのギャップを削除します。

## API リファレンス

### カード

`Card` コンポーネントは、カード コンテンツのルート コンテナーです。

| Prop        | Type                | Default     |
| ----------- | ------------------- | ----------- |
| `size`      | `"default" \| "sm"` | `"default"` |
| `className` | `string` | - |

### CardHeader

`CardHeader` コンポーネントは、タイトル、説明、およびオプションのアクションに使用されます。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardTitle

The `CardTitle` component is used for the card title.

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardDescription

`CardDescription` コンポーネントは、タイトルの下のヘルパー テキストに使用されます。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardAction

The `CardAction` component places content in the top-right of the header (for example, a button or a badge).

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### CardContent

The `CardContent` component is used for the main card body.

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### カードフッター

`CardFooter` コンポーネントは、カード下部のアクションと二次コンテンツに使用されます。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

## 変更履歴

### 間隔変数

If you're upgrading from a previous version of the `Card` component, you'll need to apply the following updates to use the `--card-spacing` variable:

<Steps>

<Step>Update the Card root spacing classes.</Step>

ハードコーディングされたギャップと垂直パディングを `--card-spacing` に置き換え、ルートにデフォルトと小さいサイズの値を設定します。

```diff
  className={cn(
-   "group/card flex flex-col gap-4 overflow-hidden rounded-xl bg-card py-4 text-sm text-card-foreground ring-1 ring-foreground/10 has-data-[slot=card-footer]:pb-0 has-[>img:first-child]:pt-0 data-[size=sm]:gap-3 data-[size=sm]:py-3 data-[size=sm]:has-data-[slot=card-footer]:pb-0 *:[img:first-child]:rounded-t-xl *:[img:last-child]:rounded-b-xl",
+   "group/card flex flex-col gap-(--card-spacing) overflow-hidden rounded-xl bg-card py-(--card-spacing) text-sm text-card-foreground ring-1 ring-foreground/10 [--card-spacing:--spacing(4)] has-data-[slot=card-footer]:pb-0 has-[>img:first-child]:pt-0 data-[size=sm]:[--card-spacing:--spacing(3)] data-[size=sm]:has-data-[slot=card-footer]:pb-0 *:[img:first-child]:rounded-t-xl *:[img:last-child]:rounded-b-xl",
    className
  )}
```

<Step>CardHeader 間隔クラスを更新します。</Step>

Replace the horizontal padding and border spacing with the shared variable:

```diff
  className={cn(
-   "group/card-header @container/card-header grid auto-rows-min items-start gap-1 rounded-t-xl px-4 group-data-[size=sm]/card:px-3 has-data-[slot=card-action]:grid-cols-[1fr_auto] has-data-[slot=card-description]:grid-rows-[auto_auto] [.border-b]:pb-4 group-data-[size=sm]/card:[.border-b]:pb-3",
+   "group/card-header @container/card-header grid auto-rows-min items-start gap-1 rounded-t-xl px-(--card-spacing) has-data-[slot=card-action]:grid-cols-[1fr_auto] has-data-[slot=card-description]:grid-rows-[auto_auto] [.border-b]:pb-(--card-spacing)",
    className
  )}
```

<Step>CardContent および CardFooter 間隔クラスを更新します。</Step>

Use `--card-spacing` for the content inset and footer padding:

```diff
  function CardContent({ className, ...props }: React.ComponentProps<"div">) {
    return (
      <div
        data-slot="card-content"
-       className={cn("px-4 group-data-[size=sm]/card:px-3", className)}
+       className={cn("px-(--card-spacing)", className)}
        {...props}
      />
    )
  }
```

```diff
  className={cn(
-   "flex items-center rounded-b-xl border-t bg-muted/50 p-4 group-data-[size=sm]/card:p-3",
+   "flex items-center rounded-b-xl border-t bg-muted/50 p-(--card-spacing)",
    className
  )}
```

</Steps>

After applying these changes, you can customize card spacing by setting `--card-spacing` on the `Card` with an arbitrary property class:

```tsx
function Example() {
  return <Card className="[--card-spacing:--spacing(6)]">...</Card>
}
```
