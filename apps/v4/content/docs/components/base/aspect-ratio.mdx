## 使用法

```tsx showLineNumbers
import { AspectRatio } from "@/components/ui/aspect-ratio"
```

```tsx showLineNumbers
<AspectRatio ratio={16 / 9}>
  <Image src="..." alt="Image" className="rounded-md object-cover" />
</AspectRatio>
```

## スクエア

`ratio={1 / 1}` プロップを使用する正方形のアスペクト比コンポーネント。画像を正方形で表示する場合に便利です。

## API リファレンス

### AspectRatio

The `AspectRatio` component displays content within a desired ratio.

|小道具 |タイプ |デフォルト |必須 |
| ----------- | -------- | ------- | -------- |
| `ratio` | `number` | - | Yes |
| `className` | `string` | -       | No       |

For more information, see the [Base UI documentation](https://base-ui.com/react/components/aspect-ratio#api-reference).
