## 無効

`disabled` プロパティを使用して入力を無効にします。無効な状態のスタイルを設定するには、`data-disabled` 属性を `Field` コンポーネントに追加します。

<ComponentPreview
  styleName="base-nova"
  name="input-disabled"
  previewClassName="*:max-w-xs"
/>

## 無効

`aria-invalid` プロパティを使用して、入力を無効としてマークします。無効な状態のスタイルを設定するには、`data-invalid` 属性を `Field` コンポーネントに追加します。

<ComponentPreview
  styleName="base-nova"
  name="input-invalid"
  previewClassName="*:max-w-xs"
