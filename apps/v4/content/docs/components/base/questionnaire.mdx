## 使用法

```tsx
import {
  Questionnaire,
  QuestionnaireActions,
  QuestionnaireChoice,
  QuestionnaireChoices,
  QuestionnaireDescription,
  QuestionnaireError,
  QuestionnaireInput,
  QuestionnaireItem,
  QuestionnaireNext,
  QuestionnairePrevious,
  QuestionnaireProgress,
  QuestionnaireSkip,
  QuestionnaireSubmit,
  QuestionnaireTitle,
} from "@/components/ui/questionnaire"
```

```tsx
const items = [
  {
    name: "direction",
    required: true,
    prompt: "What should we prototype next?",
    description: "Choose a direction or write your own.",
    choices: [
      {
        value: "delegation",
        label: "Delegation",
        description: "Show how work moves to a specialist.",
      },
      {
        value: "questions",
        label: "Question prompts",
        description: "Show choices while the interface waits.",
      },
      { value: "both", label: "Both together" },
    ],
    input: { label: "Another answer", placeholder: "Type another answer…" },
  },
  {
    name: "detail",
    required: false,
    prompt: "How much detail should it include?",
    description: "Skip this if you are not sure yet.",
    choices: [
      { value: "focused", label: "Focused" },
      { value: "complete", label: "Complete flow" },
    ],
  },
] as const
```

コレクションを一度定義します。サーバーでレンダリングされる
進行状況、アクション、ショートカットをパーツにマッピングします。

```tsx
<Questionnaire items={items} onSubmit={handleSubmit}>
  <QuestionnaireProgress />
  {items.map((question) => (
    <QuestionnaireItem
      key={question.name}
      name={question.name}
      required={question.required}
    >
      <QuestionnaireTitle>{question.prompt}</QuestionnaireTitle>
      <QuestionnaireDescription>
        {question.description}
      </QuestionnaireDescription>
      <QuestionnaireChoices>
        {question.choices.map((choice) => (
          <QuestionnaireChoice key={choice.value} value={choice.value}>
            <span className="font-medium">{choice.label}</span>
            {"description" in choice ? (
              <span className="text-muted-foreground">
                {choice.description}
              </span>
            ) : null}
          </QuestionnaireChoice>
        ))}
        {"input" in question ? (
          <QuestionnaireInput
            aria-label={question.input.label}
            placeholder={question.input.placeholder}
          />
        ) : null}
      </QuestionnaireChoices>
      <QuestionnaireError />
    </QuestionnaireItem>
  ))}
  <QuestionnaireActions>
    <QuestionnairePrevious />
    <QuestionnaireSkip />
    <QuestionnaireNext />
    <QuestionnaireSubmit />
  </QuestionnaireActions>
</Questionnaire>
```

```tsx
function handleSubmit(event: React.FormEvent<HTMLFormElement>) {
  event.preventDefault()
  const answers = new FormData(event.currentTarget)
  // answers.get("direction"), answers.getAll(...) for multiple items.
}
```

## を使用するには 構成

```text
Questionnaire
├── QuestionnaireProgress
├── QuestionnaireItem
│   ├── QuestionnaireTitle
│   ├── QuestionnaireDescription
│   ├── QuestionnaireChoices
│   │   ├── QuestionnaireChoice
│   │   └── QuestionnaireInput
│   └── QuestionnaireError
└── QuestionnaireActions
    ├── QuestionnairePrevious
    ├── QuestionnaireSkip
    ├── QuestionnaireNext
    └── QuestionnaireSubmit
```

アンケートは、注文されたアイテム、アクティブなアイテム、回答状態、検証、
の進行状況とナビゲーションに焦点が当てられます。含まれているページ、カード、ダイアログ、またはドロワーは
クローズおよびキャンセル動作、永続性、トランスポート、および分岐。

## アクセシビリティ

`QuestionnaireItem` は `fieldset` をレンダリングし、`QuestionnaireTitle` はその
`legend`。説明とアクティブなエラーは、現在の項目
および無効な項目と回答コントロールは `aria-invalid` を公開します。

修正された選択肢は、ネイティブのラジオとチェックボックスの動作を保持します。進行状況が公開されます
、ナビゲーションは実際のボタンを使用し、非アクティブなアイテムと
アクションは非表示であり、不活性です。ナビゲーションが成功すると、新しくアクティブになった
アイテム;検証に失敗すると、利用可能な回答コントロールに焦点が当てられます。

`QuestionnaireInput` には常に、表示ラベルが付いたアクセシビリティ対応の名前を付けます。
`aria-label`、または `aria-labelledby`。プレースホルダーはラベルではありません。
[アンケート アクセシビリティ ガイド](/docs/react/questionnaire#accessibility)
for labeling custom compositions and the complete keyboard behavior.

は独自のマークアップとスタイルを使用して直接指定します。

## API リファレンス

を参照してください。各パーツの小道具、データ属性、レンダリング状態は
[@shadcn/react Questionnaire](/docs/react/questionnaire#api-reference) ページを参照してください。
スタイル付きコンポーネントは、対応するスタイルなしプロパティを継承します。ナビゲーション
コンポーネントは、Button `size` および `variant` プロパティ、およびユーザーの以前の回答に当てはまらない
`QuestionnaireActions` は、スタイル付きのみのレイアウト ヘルパーです。
