## 使用法

```tsx showLineNumbers

  Alert,
  AlertAction,
  AlertDescription,
  AlertTitle,
} from "@/components/ui/alert"
```

```tsx showLineNumbers
<Alert>
  <InfoIcon />
  <AlertTitle>Heads up!</AlertTitle>
  <AlertDescription>
    You can add components and dependencies to your app using the cli.
  </AlertDescription>
  <AlertAction>
    <Button variant="outline">Enable</Button>
  </AlertAction>

```

## 構成

Use the following composition to build an `Alert`:

```text
Alert
├── Icon
├── AlertTitle
├── AlertDescription
└── AlertAction
```

## API リファレンス

### Alert

The `Alert` component displays a callout for user attention.

|小道具 |タイプ |デフォルト |
| --------- | ---------------------------- | ----------- |
| `variant` | `"default" \| "destructive"` | `"default"` |

### AlertTitle

`AlertTitle` コンポーネントは、アラートのタイトルを表示します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AlertDescription

The `AlertDescription` component displays the description or content of the alert.

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | -       |

### AlertAction

`AlertAction` コンポーネントは、アラートの右上隅に絶対配置されたアクション要素 (ボタンなど) を表示します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | -       |
