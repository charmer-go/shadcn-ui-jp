## 使用法

```tsx showLineNumbers
import {
  Item,
  ItemActions,
  ItemContent,
  ItemDescription,
  ItemMedia,
  ItemTitle,
} from "@/components/ui/item"
```

```tsx showLineNumbers
<Item>
  <ItemMedia variant="icon">
    <Icon />
  </ItemMedia>
  <ItemContent>
    <ItemTitle>Title</ItemTitle>
    <ItemDescription>Description</ItemDescription>
  </ItemContent>
  <ItemActions>
    <Button>Action</Button>
  </ItemActions>
</Item>
```

## 構成

次の構成を使用して `Item` を構築します:

```text
ItemGroup
└── Item
    ├── ItemHeader
    ├── ItemMedia
    ├── ItemContent
    │   ├── ItemTitle
    │   └── ItemDescription
    ├── ItemActions
    └── ItemFooter
```

## 項目とフィールド

チェックボックス、入力、ラジオ、または選択などのフォーム入力を表示する必要がある場合は、`Field` を使用します。

If you only need to display content such as a title, description, and actions, use `Item`.

## API リファレンス

### 項目

メディア、タイトル、説明、およびアクションを含むコンテンツを表示するための主要コンポーネント。

|小道具 |タイプ |デフォルト |
| --------- | ----------------------------------- | ----------- |
| `variant` | `"default" \| "outline" \| "muted"` | `"default"` |
| `size` | `"default" \| "sm" \| "xs"` | `"default"` |
| `render` | `React.ReactElement` |             |

### ItemGroup

関連項目を一貫したスタイルでグループ化するコンテナー。

```tsx
<ItemGroup>
  <Item />
  <Item />
</ItemGroup>
```

### ItemSeparator

グループ内の項目間の区切り文字。

```tsx
<ItemGroup>
  <Item />
  <ItemSeparator />
  <Item />
</ItemGroup>
```

### アイテムメディア

`ItemMedia` を使用して、アイコン、画像、アバターなどのメディア コンテンツを表示します。

|小道具 |タイプ |デフォルト |
| --------- | -------------------------------- | ----------- |
| `variant` | `"default" \| "icon" \| "image"` | `"default"` |

```tsx
<ItemMedia variant="icon">
  <Icon />
</ItemMedia>
```

```tsx
<ItemMedia variant="image">
  <img src="..." alt="..." />
</ItemMedia>
```

### ItemContent

アイテムのタイトルと説明をラップします。

```tsx
<ItemContent>
  <ItemTitle>Title</ItemTitle>
  <ItemDescription>Description</ItemDescription>
</ItemContent>
```

### ItemTitle

項目のタイトルを表示します。

```tsx
<ItemTitle>Item Title</ItemTitle>
```

### 項目説明

項目の説明が表示されます。

```tsx
<ItemDescription>Item description</ItemDescription>
```

### ItemsActions

アクション ボタンまたはその他のインタラクティブ要素のコンテナー。

```tsx
<ItemActions>
  <Button>Action</Button>
</ItemActions>
```

### ItemsHeader

項目コンテンツの上にヘッダーを表示します。 DOM 内の

```tsx
<Item>
  <ItemHeader>Header</ItemHeader>
  <ItemContent>...</ItemContent>
</Item>
```

### アイテムフッター

項目コンテンツの下にフッターを表示します。

```tsx
<Item>
  <ItemContent>...</ItemContent>
  <ItemFooter>Footer</ItemFooter>
</Item>
```
