


## API リファレンス

### Kbd

`Kbd` コンポーネントを使用して、キーボードのキーを表示します。

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | `` |

```tsx
<Kbd>Ctrl</Kbd>
```

### KbdGroup

Use the `KbdGroup` component to group `Kbd` components together.

| Prop        | Type     | Default |
| ----------- | -------- | ------- |
| `className` | `string` | `` |

```tsx
<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>B</Kbd>
</KbdGroup>
```
