## 使用法

```tsx showLineNumbers
import {
  Drawer,
  DrawerClose,
  DrawerContent,
  DrawerDescription,
  DrawerFooter,
  DrawerHeader,
  DrawerTitle,
  DrawerTrigger,
} from "@/components/ui/drawer"
```

```tsx showLineNumbers
<Drawer>
  <DrawerTrigger render={<Button variant="outline" />}>Open</DrawerTrigger>
  <DrawerContent>
    <DrawerHeader>
      <DrawerTitle>Are you absolutely sure?</DrawerTitle>
      <DrawerDescription>This action cannot be undone.</DrawerDescription>
    </DrawerHeader>
    <div className="p-4">{/* Content here */}</div>
    <DrawerFooter>
      <Button>Submit</Button>
      <DrawerClose render={<Button variant="outline" />}>Cancel</DrawerClose>
    </DrawerFooter>
  </DrawerContent>
</Drawer>
```

## 構成

次の構成を使用して `Drawer` を構築します。

```text
Drawer
├── DrawerTrigger
└── DrawerContent
    ├── DrawerHeader
    │   ├── DrawerTitle
    │   └── DrawerDescription
    └── DrawerFooter
```

`DrawerContent` composes the portal, overlay, viewport, and popup from Base UI. For lower-level control, `DrawerPortal`, `DrawerOverlay`, and `DrawerSwipeHandle` are also exported.

## Custom Sizes

A vertical drawer sizes itself to its content and is capped at `calc(100dvh - 6rem)` by default. A side drawer spans `75%` of the viewport width, or `24rem` on larger screens.

などの Vul プロパティ 垂直ドロワーの高さをカスタマイズするには、`DrawerContent` の `h-*` および `max-h-*` ユーティリティを使用します。

```tsx
<DrawerContent className="h-[50vh]">
```

To customize the width of a side drawer, use the `w-*` and `max-w-*` utilities on `DrawerContent`.

```tsx
<DrawerContent className="w-96">
```

同じコンポーネントが複数の方向でレンダリングされる場合、`data-[swipe-axis=*]` バリアントを使用してオーバーライドの範囲を 1 つの軸に設定します。

```tsx
<DrawerContent className="data-[swipe-axis=y]:max-h-[50vh] data-[swipe-axis=x]:w-96">
```

ドロワーの領域をスクロール可能にするには、スクロール コンテナーをフレックス アイテムにします。コンテンツサイズのドロワー内では解決されない `h-full` は避けてください。

```tsx
<DrawerContent>
  <DrawerHeader>...</DrawerHeader>
  <div className="flex-1 overflow-y-auto p-4">{/* Scrollable content */}</div>
  <DrawerFooter>...</DrawerFooter>
</DrawerContent>
```

## スタイリング

ドロワーは、スタイル レベルのカスタマイズ用の CSS 変数を公開します。 `DrawerContent` にサイズ変数を設定します。 CSS の `[data-slot=drawer-overlay]` にオーバーレイ変数を設定します。

| Variable                       | Default                | Description                                                             |
| ------------------------------ | ---------------------- | ----------------------------------------------------------------------- |
| を使用するようになりました。 `--drawer-inset` | `0px` |引き出しをビューポートの端から浮かせます。                              |
| `--drawer-bleed-background`    | `var(--color-popover)` | Fills the gap behind the drawer on swipe overshoot.                     |
| `--drawer-overlay-min-opacity` | `0` |最小オーバーレイ不透明度。スナップポイントがアクティブな場合のデフォルトは `0.5` です。 |

ドロワーは、`DrawerContent` の `data-[swipe-direction=down]:` やその子孫の `group-data-[swipe-axis=y]/drawer-popup:` などのバリアントでターゲットにできるデータ属性も設定します。

| Attribute                 | Values                        | Set when                              |
| ------------------------- | ----------------------------- | ------------------------------------- |
| `data-swipe-direction` | `up`、`right`、`down`、`left` |いつも。                               |
| `data-swipe-axis` | `x`、`y` |いつも。                               | Vaul の代わりに
| `data-snap-points`        | Present                       | The drawer has snap points.           |
| `data-expanded` |現在 |引き出しは完全なスナップポイントにあります。 |
| `data-swiping`            | Present                       | A swipe is in progress.               |
| `data-nested-drawer-open` |現在 |入れ子の引き出しが上部に開きます。       |

## 非モーダル

`modal={false}` を設定すると、ドロワーが開いているときにページの残りの部分と対話できるようになります。 `disablePointerDismissal`と組み合わせると、外付けプレスのドロワー閉まりを防止します。 `modal="trap-focus"` を使用すると、スクロールとポインターの操作を制限せずにドロワー内にフォーカスを維持できます。

## スナップポイント

Use `snapPoints` to snap a drawer to preset heights. Numbers between `0` and `1` represent fractions of the viewport. Numbers greater than `1` are treated as pixel values. String values support `px` and `rem` units. Snap points apply to vertical drawers.

制御された `snapPoint` および `onSnapPointChange` プロパティを使用して、アクティブなスナップ ポイントを追跡します。完全なスナップ ポイントで、ドロワーは `data-expanded` 属性を取得し、`data-expanded:` バリアントでスタイルを設定できます。

<ComponentPreview styleName="base-rhea" name="drawer-snap-points" />

## レスポンシブ

`Dialog` コンポーネントと `Drawer` コンポーネントを組み合わせて、応答性の高いダイアログを作成できます。これにより、デスクトップでは `Dialog` コンポーネントがレンダリングされ、モバイルでは `Drawer` がレンダリングされます。

## Vaull からの移行

基本ドロワーは [Base UI](https://base-ui.com/react/components/drawer)
。以前のベース ドロワーをインストールした場合は、使用方法を更新してください
。

<Steps>

<Step>依存関係を更新します。</Step>

```diff
- npm install vaul
+ npm install @base-ui/react
```

<Step>`direction` を `swipeDirection` に置き換えます。</Step>

`bottom` の代わりに `down` を使用し、`top` の代わりに `up` を使用します。 `left` および `right`
stay the same.

```diff
- <Drawer direction="bottom">
+ <Drawer swipeDirection="down">
```

<Step>`asChild` を `render` に置き換えます。</Step>

For `DrawerTrigger`, pass the trigger element to the `render` prop.

```diff
- <DrawerTrigger asChild>
-   <Button variant="outline">Open</Button>
- </DrawerTrigger>
+ <DrawerTrigger render={<Button variant="outline" />}>
+   Open
+ </DrawerTrigger>
```

For `DrawerClose`, pass the close element to the `render` prop.

```diff
- <DrawerClose asChild>
-   <Button variant="outline">Cancel</Button>
- </DrawerClose>
+ <DrawerClose render={<Button variant="outline" />}>
+   Cancel
+ </DrawerClose>
```

<Step>スナップ ポイントの小道具を更新します。</Step>

If you use snap points, rename the controlled snap point props and the sequential
スナップポイントプロップ。

```diff
  <Drawer
    snapPoints={[0.25, 0.5, 1]}
-   activeSnapPoint={snapPoint}
-   setActiveSnapPoint={setSnapPoint}
-   snapToSequentialPoint
+   snapPoint={snapPoint}
+   onSnapPointChange={setSnapPoint}
+   snapToSequentialPoints
  >
```

<Step>アニメーションとフォーカスの小道具を更新します。</Step>

```diff
- <Drawer onAnimationEnd={(open) => setDone(open)}>
+ <Drawer onOpenChangeComplete={(open) => setDone(open)}>
```

```diff
- <DrawerContent onOpenAutoFocus={(event) => event.preventDefault()}>
+ <DrawerContent initialFocus={false}>
```

<Step>Vaull のみの小道具を確認します。</Step>

`handleOnly`、`repositionInputs`、
`shouldScaleBackground` には、ベース ドロワー
API。 `disablePointerDismissal`、`modal`、`snapPoints`、
or controlled `open` state for the behavior you need.

```diff
- <Drawer handleOnly repositionInputs={false} shouldScaleBackground>
+ <Drawer>
```

```diff
- <Drawer dismissible={false}>
+ <Drawer disablePointerDismissal>
```

<Step>カスタム データ属性セレクターを更新します。</Step>

Replace Vaul's `data-vaul-drawer-direction` selectors with Base UI's
`data-swipe-direction` セレクター。

```diff
- <DrawerContent className="data-[vaul-drawer-direction=bottom]:max-h-[50vh]">
+ <DrawerContent className="data-[swipe-direction=down]:max-h-[50vh]">
```

などの Base UI プロパティを使用する Base UI は、`data-swiping`、`data-starting-style`、
`data-ending-style`。
`DrawerContent` can use `group-data-[swipe-axis=x]/drawer-popup` and
`group-data-[swipe-axis=y]/drawer-popup`。

</Steps>
