## 使用法

```tsx showLineNumbers
import {
  HoverCard,
  HoverCardContent,
  HoverCardTrigger,
} from "@/components/ui/hover-card"
```

```tsx showLineNumbers
<HoverCard>
  <HoverCardTrigger>Hover</HoverCardTrigger>
  <HoverCardContent>
    The React Framework – created and maintained by @vercel.
  </HoverCardContent>
</HoverCard>
```

## 構成

次の構成を使用して `HoverCard` を構築します。

```text
HoverCard
├── HoverCardTrigger
└── HoverCardContent
```

## トリガー遅延

について `HoverCard` で `openDelay` および `closeDelay` を使用して、カードが開くタイミングを制御し、入力グループを構築するときに
が終了します。

```tsx showLineNumbers
<HoverCard openDelay={100} closeDelay={200}>
  <HoverCardTrigger>Hover</HoverCardTrigger>
  <HoverCardContent>Content</HoverCardContent>
</HoverCard>
```

## 位置

`HoverCardContent` の `side` および `align` プロパティを使用して配置を制御します。

```tsx showLineNumbers
<HoverCard>
  <HoverCardTrigger>Hover</HoverCardTrigger>
  <HoverCardContent side="top" align="start">
    Content
  </HoverCardContent>
</HoverCard>
```
