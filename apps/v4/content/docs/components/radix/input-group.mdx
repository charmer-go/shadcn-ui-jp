## 使用法

```tsx showLineNumbers
import {
  InputGroup,
  InputGroupAddon,
  InputGroupButton,
  InputGroupInput,
  InputGroupText,
  InputGroupTextarea,
} from "@/components/ui/input-group"
```

```tsx showLineNumbers
<InputGroup>
  <InputGroupInput placeholder="Search..." />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

## 構成

次の構成を使用して、`InputGroup` を構築します。

```text
InputGroup
├── InputGroupInput or InputGroupTextarea
├── InputGroupAddon
├── InputGroupButton
└── InputGroupText
```

## 整列

`InputGroupAddon` の `align` プロパティを使用して、入力を基準にしてアドオンを配置します。

<Callout>
  For proper focus management, `InputGroupAddon` should always be placed after
  `InputGroupInput` または `InputGroupTextarea`。 `align` プロパティを
  アドオンを視覚的に配置します。
</Callout>

## API リファレンス

### 入力グループ

入力とアドオンをラップするメインコンポーネント。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` |         |

```tsx
<InputGroup>
  <InputGroupInput />
  <InputGroupAddon />
</InputGroup>
```

### InputGroupAddon

アイコン、テキスト、ボタン、またはその他のコンテンツを入力と一緒に表示します。

<Callout icon={<IconInfoCircle />} title="フォーカス ナビゲーション">
  For proper focus navigation, the `InputGroupAddon` component should be placed
  。 `align` プロパティを設定してアドオンを配置します。
</Callout>

|小道具 |タイプ |デフォルト |
| ----------- | ---------------------------------------------------------------- | ---------------- |
| `align` | `"inline-start" \| "inline-end" \| "block-start" \| "block-end"` | `"inline-start"` |
| `className` | `string` |                  |

```tsx
<InputGroupAddon align="inline-end">
  <SearchIcon />
</InputGroupAddon>
```

**`<InputGroupInput />` の場合は、`inline-start` または `inline-end` の位置合わせを使用します。 `<InputGroupTextarea />` の場合は、`block-start` または `block-end` 配置を使用します。**

`InputGroupAddon` コンポーネントには、複数の `InputGroupButton` コンポーネントとアイコンを含めることができます。

```tsx
<InputGroupAddon>
  <InputGroupButton>Button</InputGroupButton>
  <InputGroupButton>Button</InputGroupButton>
</InputGroupAddon>
```

### 入力グループボタン

入力グループ内のボタンを表示します。

|小道具 |タイプ |デフォルト |
| ----------- | ----------------------------------------------------------------------------- | --------- |
| `size` | `"xs" \| "icon-xs" \| "sm" \| "icon-sm"` | `"xs"` |
| `variant` | `"default" \| "destructive" \| "outline" \| "secondary" \| "ghost" \| "link"` | `"ghost"` | DOM 内の
| `className` | `string` |           |

```tsx
<InputGroupButton>Button</InputGroupButton>
<InputGroupButton size="icon-xs" aria-label="Copy">
  <CopyIcon />
</InputGroupButton>
```

### InputGroupInput

を `<Input />` に置き換えます。このコンポーネントには入力グループ スタイルが事前に適用されており、フォーカス状態の処理に統合 `data-slot="input-group-control"` を使用します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` |         |

他のすべてのプロパティは、基礎となる `<Input />` コンポーネントに渡されます。

```tsx
<InputGroup>
  <InputGroupInput placeholder="Enter text..." />
  <InputGroupAddon>
    <SearchIcon />
  </InputGroupAddon>
</InputGroup>
```

### InputGroupTextarea

入力グループを構築するときの `<Textarea />` の置き換え。このコンポーネントにはテキストエリア グループ スタイルが事前に適用されており、フォーカス状態の処理に統一された `data-slot="input-group-control"` を使用します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` |         |

他のすべてのプロパティは、基礎となる `<Textarea />` コンポーネントに渡されます。

```tsx
<InputGroup>
  <InputGroupTextarea placeholder="Enter message..." />
  <InputGroupAddon align="block-end">
    <InputGroupButton>Send</InputGroupButton>
  </InputGroupAddon>
</InputGroup>
```
