## 使い方

```tsx showLineNumbers
import { Label } from "@/components/ui/label"
import { RadioGroup, RadioGroupItem } from "@/components/ui/radio-group"
```

```tsx showLineNumbers
<RadioGroup defaultValue="option-one">
  <div className="flex items-center gap-3">
    <RadioGroupItem value="option-one" id="option-one" />
    <Label htmlFor="option-one">Option One</Label>
  </div>
  <div className="flex items-center gap-3">
    <RadioGroupItem value="option-two" id="option-two" />
    <Label htmlFor="option-two">Option Two</Label>
  </div>
</RadioGroup>
```

## 構成

次の構成を使用して、`RadioGroup` を構築します。

```text
RadioGroup
├── RadioGroupItem
└── RadioGroupItem
```

## Description

Radio group items with a description using the `Field` component.

<ComponentPreview styleName="radix-nova" name="radio-group-description" />

## 完全な動作については、Choice Card

`FieldLabel` を使用して `Field` 全体をラップし、クリック可能なカード スタイルの選択を行います。

<ComponentPreview styleName="radix-nova" name="radio-group-choice-card" />

## Fieldset

Use `FieldSet` and `FieldLegend` to group radio items with a label and description.

<ComponentPreview styleName="radix-nova" name="radio-group-fieldset" />

## 無効

`RadioGroupItem` で `disabled` プロパティを使用して、個々の項目を無効にします。

<ComponentPreview styleName="radix-nova" name="radio-group-disabled" />

## 無効な

について `RadioGroupItem` では `aria-invalid` を、`Field` では `data-invalid` を使用して検証エラーを表示します。

<ComponentPreview styleName="radix-nova" name="radio-group-invalid" />
