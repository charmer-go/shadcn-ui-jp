The `Attachment` component displays a file or image attachment, its media, name, and metadata, with optional actions and upload state. Use it for files and images in chat composers, message threads, and upload lists.

## 使い方

```tsx
import {
  Attachment,
  AttachmentAction,
  AttachmentActions,
  AttachmentContent,
  AttachmentDescription,
  AttachmentMedia,
  AttachmentTitle,
} from "@/components/ui/attachment"
```

```tsx
<Attachment>
  <AttachmentMedia>
    <FileTextIcon />
  </AttachmentMedia>
  <AttachmentContent>
    <AttachmentTitle>sales-dashboard.pdf</AttachmentTitle>
    <AttachmentDescription>PDF · 2.4 MB</AttachmentDescription>
  </AttachmentContent>
  <AttachmentActions>
    <AttachmentAction aria-label="Remove sales-dashboard.pdf">
      <XIcon />
    </AttachmentAction>
  </AttachmentActions>
</Attachment>
```

## 構成

次の構成を使用して添付ファイルを作成します。

```text
Attachment
├── AttachmentMedia
├── AttachmentContent
│   ├── AttachmentTitle
│   └── AttachmentDescription
├── AttachmentActions
│   └── AttachmentAction
└── AttachmentTrigger
```

複数の添付ファイルをスクロール可能な行にレイアウトするには、`AttachmentGroup` を使用します。

```text
AttachmentGroup
├── Attachment
└── Attachment
```

## の特徴

- Icon and image media through `AttachmentMedia`
- 状態のアップロード: `idle`、`uploading`、`processing`、`error`、`done` (組み込みのスタイルと進行中のきらめき付き)
- Three sizes and horizontal or vertical orientation
- A full-card `AttachmentTrigger` that opens a link or dialog while the actions stay independently clickable
- スクロール可能、スナップ エッジ フェード付き `AttachmentGroup`
- Customizable styling through the `className` prop on every part

## アクセシビリティ

`AttachmentAction` renders a `Button`, and `AttachmentTrigger` renders a real `<button>` (or your element via `asChild`). Follow the guidance below so both are operable and announced.

### Label icon-only actions

`AttachmentAction` は通常アイコンのみなので、それぞれにアクションとそのターゲットを説明する `aria-label` を与えます。

```tsx showLineNumbers
<AttachmentAction aria-label="Remove sales-dashboard.pdf">
  <XIcon />
</AttachmentAction>
```

### Label the trigger

`AttachmentTrigger` covers the card with no text of its own, so give it an `aria-label` for what activating it does.

```tsx showLineNumbers
<AttachmentTrigger asChild>
  <a
    href={url}
    target="_blank"
    rel="noreferrer"
    aria-label="Open workspace.png"
  />
</AttachmentTrigger>
```

The trigger sits behind the actions in the stacking order, so an `AttachmentAction` and the `AttachmentTrigger` never trap each other — both remain separately focusable and clickable.

### キーボードスクロール

`AttachmentGroup` は水平にスクロールします。添付ファイルがインタラクティブである場合 (トリガーまたはアクション)、キーボード ユーザーはタブで画面外の項目にアクセスします。プレゼンテーション用添付ファイルの行の場合、`tabIndex={0}`、`role="group"`、および `aria-label` を追加して、グループ自体をフォーカス可能およびスクロール可能にします。

### Meaning beyond color

`error` 状態では破壊的な色が使用されています。色だけで状態が伝わらないように、失敗の理由を `AttachmentDescription` に記録してください。

## API リファレンス

### Attachment

The root attachment container.

| Prop          | Type                                                         | Default        | Description                                       |
| ------------- | ------------------------------------------------------------ | -------------- | ------------------------------------------------- |
| `state` | `"idle" \| "uploading" \| "processing" \| "error" \| "done"` | `"done"` |アップロードの状態。スタイリングと輝きを促進します。 |
| `size`        | `"default" \| "sm" \| "xs"`                                  | `"default"`    | The attachment size.                              |
| `orientation` | `"horizontal" \| "vertical"`                                 | `"horizontal"` | Lay the media beside or above the content.        |
| `className` | `string` | - |ルート要素に適用する追加のクラス。  |

### AttachmentMedia

The media slot for an icon or image preview.

|小道具 |タイプ |デフォルト |説明 |
| ----------- | ------------------- | -------- | ---------------------------------------------- |
| `variant` | `"icon" \| "image"` | `"icon"` |メディアにアイコンまたは `<img>` が含まれるかどうか。 |
| `className` | `string`            | -        | Additional classes to apply to the media slot. |

### AttachmentContent

Wraps the title and description.

| Prop        | Type     | Default | Description                                      |
| ----------- | -------- | ------- | ------------------------------------------------ |
| `className` | `string` | - |コンテンツ スロットに適用する追加のクラス。 |

### AttachmentTitle

アタッチメント名。アタッチメントが `uploading` または `processing` のときに点滅します。

| Prop        | Type     | Default | Description                               |
| ----------- | -------- | ------- | ----------------------------------------- |
| `className` | `string` | - |タイトルに適用する追加のクラス。 |

### AttachmentDescription

ファイル タイプ、サイズ、アップロード ステータスなどの二次メタデータ。

|小道具 |タイプ |デフォルト |説明 |
| ----------- | -------- | ------- | ----------------------------------------------- |
| `className` | `string` | -       | Additional classes to apply to the description. |

### AttachmentActions

添付ファイルの最後に揃えられた、1 つ以上のアクションのコンテナー。

|小道具 |タイプ |デフォルト |説明 |
| ----------- | -------- | ------- | ------------------------------------------- |
| `className` | `string` | - |アクションに適用する追加のクラス。 |

### AttachmentAction

アクションボタン。 [`Button`](/docs/components/button) をレンダリングし、そのプロパティをすべて受け入れます。

|小道具 |タイプ |デフォルト |説明 |
| ---------- | ------------------------------------- | ----------- | ---------------------------------------- |
| `size` | `Button["size"]` | `"icon-xs"` |ボタンのサイズ。                         |
| `...props` | `React.ComponentProps<typeof Button>` | -           | Props spread to the underlying `Button`. |

### AttachmentTrigger

A full-card overlay that activates the attachment. Renders a `<button>` by default.

|小道具 |タイプ |デフォルト |説明 |
| ---------- | -------------------------------- | ------- | -------------------------------------------- |
| `asChild` | `boolean` | `false` |リンクなどの子要素としてレンダリングします。 |
| `...props` | `React.ComponentProps<"button">` | -       | Props spread to the trigger element.         |

### アタッチメントグループ

Lays out attachments in a horizontally scrollable, snapping row.

| Prop        | Type     | Default | Description                               |
| ----------- | -------- | ------- | ----------------------------------------- |
| `className` | `string` | -       | Additional classes to apply to the group. |
