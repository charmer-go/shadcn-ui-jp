## API リファレンス

### Kbd

`Kbd` コンポーネントを使用して、キーボードのキーを表示します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | `` |

```tsx
<Kbd>Ctrl</Kbd>
```

### KbdGroup

`KbdGroup` コンポーネントを使用して、`Kbd` コンポーネントをグループ化します。

|小道具 |タイプ |デフォルト |
| ----------- | -------- | ------- |
| `className` | `string` | `` |

```tsx
<KbdGroup>
  <Kbd>Ctrl</Kbd>
  <Kbd>B</Kbd>
</KbdGroup>
```
