**チャート**を紹介します。コピーしてアプリに貼り付けることができるグラフ コンポーネントのコレクション。

チャートは、すぐに使えるように設計されています。これらは他のコンポーネントとうまく連携し、プロジェクトに合わせて完全にカスタマイズできます。

[チャート ライブラリを参照](/charts)。

## コンポーネント

内部では [Recharts](https://recharts.org/) を使用しています。

`chart` コンポーネントは、構成を念頭に置いて設計されました。 **Recharts コンポーネントを使用してグラフを作成し、`ChartTooltip` などのカスタム コンポーネントを必要なときに必要な場所にのみ取り込みます**。

```tsx showLineNumbers /ChartContainer/ /ChartTooltipContent/
import { Bar, BarChart } from "recharts"

import { ChartContainer, ChartTooltipContent } from "@/components/ui/chart"

export function MyChart() {
  return (
    <ChartContainer>
      <BarChart data={data}>
        <Bar dataKey="value" />
        <ChartTooltip content={<ChartTooltipContent />} />
      </BarChart>
    </ChartContainer>
  )
}
```

Recharts はラップしません。これは、抽象概念に囚われないことを意味します。 Recharts の新しいバージョンがリリースされたら、公式アップグレード パスに従ってチャートをアップグレードできます。

**コンポーネントはあなたのものです**。

## Recharts v3 への更新

If you're updating older chart code to Recharts v3:

- CSS 変数からチャート トークンを参照する場合は、`hsl(var(--chart-1))` の代わりに `var(--chart-1)` を使用します。
- `ChartTooltip.defaultIndex` は、ツールチップの初期状態にのみ使用します。永続的なアクティブなシェイプを独自のチャート状態に維持します。
- 親 `<BarChart>` が既に定義している場合は、`<Bar>` から `layout` を削除します。
- 最初のレンダリング時に `ResponsiveContainer` が測定できるように、`ChartContainer` に高さ `min-h-*` または `aspect-*` を保持します。

## チャート設定

チャート設定では、チャートのラベル、アイコン、色を定義します。

チャート データから意図的に切り離されています。

これにより、チャート間で構成トークンとカラートークンを共有できるようになります。データまたはカラー トークンがリモートに存在する場合や、異なる形式で存在する場合でも、独立して機能することもできます。

```tsx showLineNumbers /ChartConfig/
import { Monitor } from "lucide-react"

import { type ChartConfig } from "@/components/ui/chart"

const chartConfig = {
  desktop: {
    label: "Desktop",
    icon: Monitor,
    // A color like 'hsl(220, 98%, 61%)' or 'var(--color-name)'
    color: "#2563eb",
    // OR a theme object with 'light' and 'dark' keys
    theme: {
      light: "#2563eb",
      dark: "#dc2626",
    },
  },
} satisfies ChartConfig
```

チャート設定で直接色を定義することもできます。好みのカラー形式を使用してください。


### 色の使用

チャートでテーマの色を使用するには、`var(--color-KEY)` の形式を使用して色を参照します。

#### コンポーネント

```tsx
<Bar dataKey="desktop" fill="var(--color-desktop)" />
```

#### チャート データ

```tsx title="components/example-chart.tsx" showLineNumbers
const chartData = [
  { browser: "chrome", visitors: 275, fill: "var(--color-chrome)" },

]
```

#### Tailwind

```tsx title="components/example-chart.tsx"
<LabelList className="fill-(--color-desktop)" />
```

## ツールチップ

チャート ツールチップには、ラベル、名前、インジケーター、および値が含まれます。これらを組み合わせて使用​​して、ツールチップをカスタマイズできます。

<ComponentPreview styleName="radix-nova" name="chart-tooltip" hideCode />

`hideLabel`、`hideIndicator` プロパティを使用してこれらのオン/オフを切り替え、`indicator` プロパティを使用してインジケーターのスタイルをカスタマイズできます。

ツールチップのラベルと名前にカスタム キーを使用するには、`labelKey` および `nameKey` を使用します。

チャートには、`<ChartTooltip>` コンポーネントと `<ChartTooltipContent>` コンポーネントが付属しています。これら 2 つのコンポーネントを使用して、グラフにカスタム ツールチップを追加できます。

```tsx title="components/example-chart.tsx"
import { ChartTooltip, ChartTooltipContent } from "@/components/ui/chart"
```

```tsx title="components/example-chart.tsx"
<ChartTooltip content={<ChartTooltipContent />} />
```

### 小道具

ツールチップをカスタマイズするには、次のプロパティを使用します。

|小道具 |タイプ |説明 |
| :-------------- | :----------------------- | :------------------------------------------- |
| `labelKey` |文字列 |ラベルに使用する構成キーまたはデータキー。 |
| `nameKey` |文字列 |名前に使用する構成キーまたはデータ キー。  |
| `indicator` | `dot` `line` または `dashed` |ツールチップのインジケーターのスタイル。         |
| `hideLabel` |ブール値 |ラベルを非表示にするかどうか。                   |
| `hideIndicator` |ブール値 |インジケーターを非表示にするかどうか。               |

### カラー

色はチャート設定から自動的に参照されます。

### カスタム

ツールチップのラベルと名前にカスタム キーを使用するには、`labelKey` および `nameKey` プロパティを使用します。

```tsx showLineNumbers /browser/
const chartData = [
  { browser: "chrome", visitors: 187, fill: "var(--color-chrome)" },
  { browser: "safari", visitors: 200, fill: "var(--color-safari)" },
]

const chartConfig = {
  visitors: {
    label: "Total Visitors",
  },
  chrome: {
    label: "Chrome",
    color: "var(--chart-1)",
  },
  safari: {
    label: "Safari",
    color: "var(--chart-2)",
  },
} satisfies ChartConfig
```

```tsx title="components/example-chart.tsx"
<ChartTooltip
  content={<ChartTooltipContent labelKey="visitors" nameKey="browser" />}
/>
```

これにより、ラベルに `Total Visitors` が使用され、ツールチップ名に `Chrome` と `Safari` が使用されます。
