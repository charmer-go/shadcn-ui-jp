## はじめに

これまで作成したデータテーブルやデータグリッドはすべて固有のものでした。それぞれ動作が異なり、固有のソートやフィルタリング要件があり、異なるデータソースを扱います。

これらすべてのバリエーションを1つのコンポーネントにまとめるのは適切ではありません。そうすると、[ヘッドレス UI](https://tanstack.com/table/latest/docs/overview#what-is-headless-ui) が提供する柔軟性が失われます。

そこでデータテーブル コンポーネントそのものではなく、自分で構築する方法を説明するガイドを提供することにしました。

基本的な `<Table />` コンポーネントから始め、複雑なデータテーブルをゼロから構築します。

<Callout className="mt-4">

**ヒント:** アプリ内の複数箇所で同じテーブルを使う場合は、再利用可能なコンポーネントとして切り出せます。

</Callout>

## インストール

1. `<Table />` コンポーネントをプロジェクトに追加します。

```bash
npx shadcn@latest add table
```

2. `@tanstack/react-table` 依存関係を追加します。このガイドでは **TanStack Table v9** を使用します。

```bash
npm install @tanstack/react-table
```

## プロジェクト構成

次のファイル構成を作成することから始めます。

```txt
app
└── payments
    ├── columns.tsx
    ├── data-table-features.ts
    ├── data-table.tsx
    └── page.tsx
```

ここでは Next.js の例を使用しますが、他の React フレームワークでも動作します。

- `columns.tsx`（クライアント コンポーネント）には列定義を記述します。
- `data-table-features.ts` には、TanStack Table で有効にする動作を指定する共有 `features` オブジェクトを記述します。
- `data-table.tsx`（クライアント コンポーネント）には `<DataTable />` コンポーネントを記述します。
- `page.tsx`（サーバー コンポーネント）でデータを取得し、テーブルを描画します。

## テーブル機能を設定する

TanStack Table v9 は機能ベースです。`tableFeatures()` でソート、フィルタリング、ページネーションなど必要な動作を宣言して有効にします。一覧に含めないものはバンドルから tree-shaking されます。組み込みのフィルター関数とソート関数も対象なので、列が使用するものを `filterFns` と `sortFns` に登録します（メール フィルターは `includesString` を使い、文字列列は `text` / `alphanumeric` でソートします）。

```tsx showLineNumbers title="app/payments/data-table-features.ts"
import {
  columnFilteringFeature,
  columnVisibilityFeature,
  createFilteredRowModel,
  createPaginatedRowModel,
  createSortedRowModel,
  filterFn_includesString,
  rowPaginationFeature,
  rowSelectionFeature,
  rowSortingFeature,
  sortFn_alphanumeric,
  sortFn_text,
  tableFeatures,
} from "@tanstack/react-table"

// v9 では、このテーブルで使用する機能を宣言します。登録しない機能は
// バンドルから tree-shaking されます。
export const features = tableFeatures({
  columnFilteringFeature,
  columnVisibilityFeature,
  rowPaginationFeature,
  rowSelectionFeature,
  rowSortingFeature,
  filteredRowModel: createFilteredRowModel(),
  paginatedRowModel: createPaginatedRowModel(),
  sortedRowModel: createSortedRowModel(),
  filterFns: { includesString: filterFn_includesString },
  sortFns: { alphanumeric: sortFn_alphanumeric, text: sortFn_text },
})

// Pass this as the first generic argument to `ColumnDef`, `Column`, `Table`,
// and `Row` so each type knows which feature APIs are available.
export type DataTableFeatures = typeof features
```

<Callout className="mt-4">

**注:** コア行モデルは常に含まれるため、自分で登録する必要はありません。任意機能の行モデルは `create*RowModel()` で作成して features オブジェクトに登録します。`get*RowModel` のテーブル オプションはもうありません。

</Callout>

## 基本的なテーブル

基本的なテーブルを構築します。

<Steps className="mb-0 pt-2">

### 列の定義

まず列を定義します。

```tsx showLineNumbers title="app/payments/columns.tsx" {3,5,16-17,19-29}
"use client"

import { createColumnHelper } from "@tanstack/react-table"

import { type DataTableFeatures } from "./data-table-features"

// This type is used to define the shape of our data.
// You can use a Zod schema here if you want.
export type Payment = {
  id: string
  amount: number
  status: "pending" | "processing" | "success" | "failed"
  email: string
}

// Use `accessor` for data columns and `display` for columns without one.
const columnHelper = createColumnHelper<DataTableFeatures, Payment>()

export const columns = columnHelper.columns([
  columnHelper.accessor("status", {
    header: "ステータス",
  }),
  columnHelper.accessor("email", {
    header: "メールアドレス",
  }),
  columnHelper.accessor("amount", {
    header: "金額",
  }),
])
```

<Callout className="mt-4">

**注:** 列では、テーブルの見た目の中心となる部分を定義します。表示するデータと、
その書式、並べ替え、フィルタリングの方法を指定します。

</Callout>

### `<DataTable />` コンポーネント

次に、テーブルを描画する `<DataTable />` コンポーネントを作成します。

```tsx showLineNumbers title="app/payments/data-table.tsx"
"use client"

import { useTable, type ColumnDef, type RowData } from "@tanstack/react-table"

import {
  Table,
  TableBody,
  TableCell,
  TableHead,
  TableHeader,
  TableRow,
} from "@/components/ui/table"

import { features, type DataTableFeatures } from "./data-table-features"

interface DataTableProps<TData extends RowData> {
  columns: ColumnDef<DataTableFeatures, TData>[]
  data: TData[]
}

export function DataTable<TData extends RowData>({
  columns,
  data,
}: DataTableProps<TData>) {
  const table = useTable({
    features,
    data,
    columns,
  })

  return (
    <div className="overflow-hidden rounded-md border">
      <Table>
        <TableHeader>
          {table.getHeaderGroups().map((headerGroup) => (
            <TableRow key={headerGroup.id}>
              {headerGroup.headers.map((header) => {
                return (
                  <TableHead key={header.id}>
                    {header.isPlaceholder ? null : (
                      <table.FlexRender header={header} />
                    )}
                  </TableHead>
                )
              })}
            </TableRow>
          ))}
        </TableHeader>
        <TableBody>
          {table.getRowModel().rows?.length ? (
            table.getRowModel().rows.map((row) => (
              <TableRow
                key={row.id}
                data-state={row.getIsSelected() && "selected"}
              >
                {row.getVisibleCells().map((cell) => (
                  <TableCell key={cell.id}>
                    <table.FlexRender cell={cell} />
                  </TableCell>
                ))}
              </TableRow>
            ))
          ) : (
            <TableRow>
              <TableCell colSpan={columns.length} className="h-24 text-center">
                結果がありません。
              </TableCell>
            </TableRow>
          )}
        </TableBody>
      </Table>
    </div>
  )
}
```

<Callout>

**ヒント:** `<DataTable />` を複数箇所で使う場合は、このコンポーネントを `components/ui/data-table.tsx` に切り出して再利用できます。

`<DataTable columns={columns} data={data} />`

</Callout>

<Callout className="mt-4">

**`<table.FlexRender />` と `flexRender`:** このガイドでは、テーブル インスタンスから直接利用でき、追加のインポートが不要な v9 の `<table.FlexRender header={header} />` と `<table.FlexRender cell={cell} />` コンポーネントを使用します。関数形式を好む場合（または `table` を所有するコンポーネントの外側でレンダリングする必要がある場合）は、v8 の従来の `flexRender(component, context)` ヘルパーも引き続き使用できます。その場合は単独の `<FlexRender />` もインポートできます。

</Callout>

金額セルをドル表示に書式設定し、右揃えにします。

### 列の定義を更新する

金額の `header` と `cell` の定義を次のように更新します。

```tsx showLineNumbers title="app/payments/columns.tsx" {3-13}
export const columns = columnHelper.columns([
  columnHelper.accessor("amount", {
    header: () => <div className="text-right">金額</div>,
    cell: ({ row }) => {
      const amount = parseFloat(row.getValue("amount"))
      const formatted = new Intl.NumberFormat("en-US", {
        style: "currency",
        currency: "USD",
      }).format(amount)

      return <div className="text-right font-medium">{formatted}</div>
    },
  }),

```

## 行のアクション

テーブルに行のアクションを追加します。ここでは `<DropdownMenu />` コンポーネントを使用します。

<Steps className="mb-0 pt-2">

### 列定義を更新

列の定義を更新して新しい `actions` 列を追加します。`actions` セルは `<DropdownMenu />` コンポーネントを返します。

```tsx showLineNumbers title="app/payments/columns.tsx" {4,6-14,18-45}
"use client"

import { createColumnHelper } from "@tanstack/react-table"
import { MoreHorizontal } from "lucide-react"

import { Button } from "@/components/ui/button"
import {
  DropdownMenu,
  DropdownMenuContent,
  DropdownMenuItem,
  DropdownMenuLabel,
  DropdownMenuSeparator,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu"

export const columns = columnHelper.columns([
  // ...
  columnHelper.display({
    id: "actions",
    cell: ({ row }) => {
      const payment = row.original

      return (
        <DropdownMenu>
          <DropdownMenuTrigger asChild>
            <Button variant="ghost" className="h-8 w-8 p-0">
              <span className="sr-only">メニューを開く</span>
              <MoreHorizontal className="h-4 w-4" />
            </Button>
          </DropdownMenuTrigger>
          <DropdownMenuContent align="end">
            <DropdownMenuLabel>Actions</DropdownMenuLabel>
            <DropdownMenuItem
              onClick={() => navigator.clipboard.writeText(payment.id)}
            >
              Copy payment ID
            </DropdownMenuItem>
            <DropdownMenuSeparator />
            <DropdownMenuItem>View customer</DropdownMenuItem>
            <DropdownMenuItem>View payment details</DropdownMenuItem>
          </DropdownMenuContent>
        </DropdownMenu>
      )
    },
  }),
  // ...
])
```

`cell` 関数では `row.original` を使って行のデータにアクセスできます。これを使って行のアクションを処理します。たとえば `id` を使って API に DELETE リクエストを送信できます。

</Steps>

## ページネーション

次に、テーブルへページネーションを追加します。

<Steps className="mb-0 pt-2">

### ページネーションはすでに有効

features オブジェクトには `rowPaginationFeature` と `createPaginatedRowModel()` が含まれているため、テーブルは行を自動的に 10 件ずつのページに分割します。`useTable` に追加するものはありません。ページ サイズのカスタマイズや手動ページネーションについては、[ページネーションのドキュメント](https://tanstack.com/table/latest/docs/framework/react/guide/pagination)を参照してください。

### ページネーションコントロールを追加する

`<Button />` コンポーネントと `table.previousPage()`、`table.nextPage()` API メソッドを使って、テーブルにページネーション コントロールを追加できます。

```tsx showLineNumbers title="app/payments/data-table.tsx" {1,20-37}
import { Button } from "@/components/ui/button"

export function DataTable<TData extends RowData>({
  columns,
  data,
}: DataTableProps<TData>) {
  const table = useTable({
    features,
    data,
    columns,
  })

  return (
    <div>
      <div className="overflow-hidden rounded-md border">
        <Table>
          { // .... }
        </Table>
      </div>
      <div className="flex items-center justify-end space-x-2 py-4">
        <Button
          variant="outline"
          size="sm"
          onClick={() => table.previousPage()}
          disabled={!table.getCanPreviousPage()}
        >
          Previous
        </Button>
        <Button
          variant="outline"
          size="sm"
          onClick={() => table.nextPage()}
          disabled={!table.getCanNextPage()}
        >
          Next
        </Button>
      </div>
    </div>
  )
}
```

より高度なページネーション コンポーネントについては、[再利用可能なコンポーネント](#再利用可能なコンポーネント)を参照してください。

</Steps>

## 並べ替え

メールアドレス列を並べ替え可能にします。

`rowSortingFeature` とソート済み行モデルはすでに features オブジェクトに登録されています。あとは並べ替えの状態を接続するだけです。

<Steps className="mb-0 pt-2">

### `<DataTable>` を更新する

```tsx showLineNumbers title="app/payments/data-table.tsx" {3,8,15,21-24}
"use client"

import * as React from "react"
import {
  useTable,
  type ColumnDef,
  type RowData,
  type SortingState,
} from "@tanstack/react-table"

export function DataTable<TData extends RowData>({
  columns,
  data,
}: DataTableProps<TData>) {
  const [sorting, setSorting] = React.useState<SortingState>([])

  const table = useTable({
    features,
    data,
    columns,
    onSortingChange: setSorting,
    state: {
      sorting,
    },
  })

  return (
    <div>
      <div className="overflow-hidden rounded-md border">
        <Table>{ ... }</Table>
      </div>
    </div>
  )
}
```

### ヘッダーセルを並べ替え可能にする

これで `email` ヘッダー セルを更新し、並べ替えコントロールを追加できます。

```tsx showLineNumbers title="app/payments/columns.tsx" {4,8-18}
"use client"

import { createColumnHelper } from "@tanstack/react-table"
import { ArrowUpDown } from "lucide-react"

export const columns = columnHelper.columns([
  columnHelper.accessor("email", {

      return (
        <Button
          variant="ghost"

```

ヘッダー セルを切り替えると、テーブルが自動的に昇順・降順で並べ替えられます。

</Steps>

## フィルタリング

テーブルのメールアドレスを絞り込む検索入力を追加します。

`columnFilteringFeature` とフィルター済み行モデルはすでに features オブジェクトに含まれているため、フィルター状態を接続して入力欄を表示するだけで済みます。

<Steps className="mb-0 pt-2">

### `<DataTable>` を更新する

```tsx showLineNumbers title="app/payments/data-table.tsx" {7,13,20-22,29,32,38-46}
"use client"

import * as React from "react"
import {
  useTable,
  type ColumnDef,
  type ColumnFiltersState,
  type RowData,
  type SortingState,
} from "@tanstack/react-table"

import { Button } from "@/components/ui/button"
import { Input } from "@/components/ui/input"

export function DataTable<TData extends RowData>({
  columns,
  data,
}: DataTableProps<TData>) {
  const [sorting, setSorting] = React.useState<SortingState>([])
  const [columnFilters, setColumnFilters] = React.useState<ColumnFiltersState>(
    []
  )

  const table = useTable({
    features,
    data,
    columns,
    onSortingChange: setSorting,
    onColumnFiltersChange: setColumnFilters,
    state: {
      sorting,
      columnFilters,
    },
  })

  return (
    <div>
      <div className="flex items-center py-4">
        <Input
          placeholder="メールアドレスを絞り込む..."
          value={(table.getColumn("email")?.getFilterValue() as string) ?? ""}
          onChange={(event) =>
            table.getColumn("email")?.setFilterValue(event.target.value)
          }
          className="max-w-sm"
        />
      </div>
      <div className="overflow-hidden rounded-md border">
        <Table>{ ... }</Table>
      </div>
    </div>
  )
}
```

これで `email` 列のフィルタリングが有効になりました。他の列にもフィルターを追加できます。フィルターのカスタマイズについては、[フィルタリングのドキュメント](https://tanstack.com/table/latest/docs/framework/react/guide/column-filtering)を参照してください。

</Steps>

## 表示状態

`@tanstack/react-table` の表示状態 API を使えば、列の表示・非表示を簡単に追加できます。

<Steps className="mb-0 pt-2">

### `<DataTable>` を更新する

```tsx showLineNumbers title="app/payments/data-table.tsx" {8,14-19,29-30,38,42,57-84}
"use client"

import * as React from "react"
import {
  useTable,
  type ColumnDef,
  type ColumnFiltersState,
  type ColumnVisibilityState,
  type RowData,
  type SortingState,
} from "@tanstack/react-table"

import { Button } from "@/components/ui/button"
import {
  DropdownMenu,
  DropdownMenuCheckboxItem,
  DropdownMenuContent,
  DropdownMenuTrigger,
} from "@/components/ui/dropdown-menu"

export function DataTable<TData extends RowData>({
  columns,
  data,
}: DataTableProps<TData>) {
  const [sorting, setSorting] = React.useState<SortingState>([])
  const [columnFilters, setColumnFilters] = React.useState<ColumnFiltersState>(
    []
  )
  const [columnVisibility, setColumnVisibility] =
    React.useState<ColumnVisibilityState>({})

  const table = useTable({
    features,
    data,
    columns,
    onSortingChange: setSorting,
    onColumnFiltersChange: setColumnFilters,
    onColumnVisibilityChange: setColumnVisibility,
    state: {
      sorting,
      columnFilters,
      columnVisibility,
    },
  })

  return (
    <div>
      <div className="flex items-center py-4">
        <Input
          placeholder="メールアドレスを絞り込む..."
          value={table.getColumn("email")?.getFilterValue() as string}
          onChange={(event) =>
            table.getColumn("email")?.setFilterValue(event.target.value)
          }
          className="max-w-sm"
        />
        <DropdownMenu>
          <DropdownMenuTrigger asChild>
            <Button variant="outline" className="ml-auto">
              Columns
            </Button>
          </DropdownMenuTrigger>
          <DropdownMenuContent align="end">
            {table
              .getAllColumns()
              .filter(
                (column) => column.getCanHide()
              )
              .map((column) => {
                return (
                  <DropdownMenuCheckboxItem
                    key={column.id}
                    className="capitalize"
                    checked={column.getIsVisible()}
                    onCheckedChange={(value) =>
                      column.toggleVisibility(!!value)
                    }
                  >
                    {column.id}
                  </DropdownMenuCheckboxItem>
                )
              })}
          </DropdownMenuContent>
        </DropdownMenu>
      </div>
      <div className="overflow-hidden rounded-md border">
        <Table>{ ... }</Table>
      </div>
    </div>
  )
}
```

これで、列の表示・非表示を切り替えるドロップダウン メニューが追加されます。

</Steps>

## 行の選択

次に、テーブルへ行の選択を追加します。

<Steps className="mb-0 pt-2">

### 列定義を更新

```tsx showLineNumbers title="app/payments/columns.tsx" {6,9-30}
"use client"

import { createColumnHelper } from "@tanstack/react-table"

import { Badge } from "@/components/ui/badge"
import { Checkbox } from "@/components/ui/checkbox"

export const columns = columnHelper.columns([
  columnHelper.display({
    id: "select",
    header: ({ table }) => (
      <Checkbox
        checked={
          table.getIsAllPageRowsSelected() ||
          (table.getIsSomePageRowsSelected() && "indeterminate")
        }
        onCheckedChange={(value) => table.toggleAllPageRowsSelected(!!value)}
        aria-label="Select all"
      />
    ),
    cell: ({ row }) => (
      <Checkbox
        checked={row.getIsSelected()}
        onCheckedChange={(value) => row.toggleSelected(!!value)}
        aria-label="Select row"
      />
    ),
    enableSorting: false,
    enableHiding: false,
  }),
])
```

### `<DataTable>` を更新する

```tsx showLineNumbers title="app/payments/data-table.tsx" {11,20,25}
export function DataTable<TData extends RowData>({
  columns,
  data,
}: DataTableProps<TData>) {

  const [columnFilters, setColumnFilters] = React.useState<ColumnFiltersState>(
    []
  )
  const [columnVisibility, setColumnVisibility] =
    React.useState<ColumnVisibilityState>({})
  const [rowSelection, setRowSelection] = React.useState({})

  const table = useTable({

    onSortingChange: setSorting,

    onColumnVisibilityChange: setColumnVisibility,
    onRowSelectionChange: setRowSelection,
    state: {
      sorting,

      rowSelection,
    },
  })

  return (
```
